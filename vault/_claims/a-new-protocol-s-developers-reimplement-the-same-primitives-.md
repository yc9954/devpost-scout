# a new protocol's developers reimplement the same primitives with the same mistakes, so an audited standard library is what raises the security floor for an ecosystem

Asserted by [[pollen-protocol]] — *Pollen Protocol*  
<sub>Polygon BUIDL IT : Summer 2022</sub>

**Problem** building on a social protocol where everything is a token requires reimplementing common patterns

**Mechanism** a reusable audited library of contracts for that protocol  
**Beneficiary** developers on a young protocol

**Recurs in** [[any new standard]] [[framework ecosystems]] [[hardware platforms]]
