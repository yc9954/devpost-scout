# good ideas die at hackathons for want of a data feed rather than for want of an idea, so the availability of long-tail data decides which applications can exist at all

Asserted by [[redstone-oracle-on-celo]] — *RedStone Oracle on Celo*  
<sub>Celo's Make Crypto Mobile Hackathon</sub>

**Problem** Celo builders lacked feeds for long-tail tokens and real world data like crops and livestock

**Mechanism** customisable oracle feeds including agricultural data  
**Beneficiary** developers building on non-financial real world data

**Recurs in** [[parametric insurance]] [[commodity finance]] [[supply chain]]
