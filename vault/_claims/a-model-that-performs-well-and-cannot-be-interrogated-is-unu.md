# a model that performs well and cannot be interrogated is unusable where the decision has consequences, so saliency tooling determines which domains can adopt deep learning at all

Asserted by [[xaitk-saliency]] — *xaitk-saliency*  
<sub>PyTorch Annual Hackathon 2021</sub>

**Problem** learned predictive models are opaque in analytic and autonomy applications

**Mechanism** an open toolkit of visual saliency algorithm interfaces and implementations  
**Beneficiary** practitioners deploying models under accountability requirements

**Recurs in** [[medical imaging]] [[defence]] [[autonomous vehicles]]
