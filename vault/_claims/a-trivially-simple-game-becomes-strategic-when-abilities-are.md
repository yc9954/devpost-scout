# a trivially simple game becomes strategic when abilities are added, so depth can be introduced to a universally understood format without a learning curve

Asserted by [[tactical-toe]] — *Tactical Toe*

**Problem** card game depth requires learning a large rule set

**Mechanism** adding spell-like abilities to a game everyone already knows
