# a peer-to-peer trade requires both parties to already hold the right asset on the right chain, so the trade fails on prerequisites rather than on agreement

Asserted by [[otcnexus]] — *OTCNexus*  
<sub>Chainlink Spring 2023 Hackathon</sub>

**Problem** acquiring tokens peer-to-peer requires the buyer to already be set up

**Mechanism** bridging conventional payment into peer-to-peer acquisition through an oracle function  
**Beneficiary** buyers without existing crypto holdings

**Recurs in** [[cross-border purchase]] [[currency exchange]] [[ticket resale]]
