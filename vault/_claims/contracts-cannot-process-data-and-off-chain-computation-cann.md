# contracts cannot process data and off-chain computation cannot be scheduled from them, so anything requiring both runs on a server someone must trust

Asserted by [[knn3-data-job-management-panel]] — *KNN3 Data Job Management Panel*  
<sub>Chainlink Fall 2022 Hackathon</sub>

**Problem** developers cannot process on-chain and off-chain data through contracts directly

**Mechanism** scheduling off-chain jobs from a contract and delivering results back  
**Beneficiary** developers building data-dependent contracts

**Recurs in** [[IoT]] [[insurance triggers]] [[reporting]]
