# an irreversible transfer to the wrong address is a support problem that has no support, so the recovery mechanism has to exist in the contract or it does not exist

Asserted by [[user-caring]] — *Mistransfer*  
<sub>Constellation: A Chainlink Hackathon</sub>

**Problem** players mistakenly sent assets to game contracts and there was no way to return them

**Mechanism** an automated recovery path for mistaken transfers  
**Beneficiary** users who make an irreversible mistake

**Recurs in** [[bank transfers]] [[file deletion]] [[irreversible publishing]]
