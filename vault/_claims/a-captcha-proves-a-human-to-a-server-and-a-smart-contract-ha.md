# a captcha proves a human to a server, and a smart contract has no server, so on-chain systems have no equivalent of the check every web application relies on

Asserted by [[wp-dun2zt]] — *Captchains: Chainlink-powered Captchas on demand*  
<sub>Chainlink Spring 2022 Hackathon</sub>

**Problem** contracts cannot distinguish a person from a script

**Mechanism** on-demand captchas backed by IPFS storage and oracle-delivered questions  
**Beneficiary** contract developers needing proof of human interaction
