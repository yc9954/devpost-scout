# a voice game for children fails on interface complexity before it fails on content, so the design target is the number of things a child must remember to say

Asserted by [[mighty-trivia-a-guessing-game-for-kids]] — *Mighty Trivia - a guessing game for kids*  
<sub>Alexa Skills Challenge: Kids</sub>

**Problem** existing guessing games had complicated voice interfaces

**Mechanism** a single straightforward guessing loop with hints and a leaderboard  
**Beneficiary** children using voice devices unaided

**Recurs in** [[elderly interfaces]] [[accessibility]] [[emergency systems]]
