# a game with generated content needs randomness nobody can predict or the advantage goes to whoever can, so verifiable randomness is a fairness primitive rather than a feature

Asserted by [[hobbits-of-polygon]] — *Hobbits Of Polygon*  
<sub>Chainlink Fall Hackathon 2021</sub>

**Problem** algorithmic map and character generation can be gamed if the randomness is predictable

**Mechanism** verifiable random function driving map and attribute generation  
**Beneficiary** players in games with generated content

**Recurs in** [[lotteries]] [[matchmaking]] [[resource allocation]]
