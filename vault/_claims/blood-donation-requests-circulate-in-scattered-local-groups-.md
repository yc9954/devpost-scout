# blood donation requests circulate in scattered local groups, so the match between an urgent need and a willing donor depends on which group someone happens to be in

Asserted by [[donorfu]] — *DonorFu*  
<sub>2018 Developer Circles Community Challenge</sub>

**Problem** blood requests are spread across many disconnected social groups

**Mechanism** connecting potential donors to the requests wherever they are posted  
**Beneficiary** patients needing blood and willing donors

**Recurs in** [[organ donation]] [[emergency shelter]] [[specialist equipment]]
