# every application that stores data ends up building a bespoke internal admin interface, so the same tool is rebuilt inside every product that has data

Asserted by [[fireview]] — *Fireview*  
<sub>Zero to One Hackathon by Convex Vol 2</sub>

**Problem** teams repeatedly build custom interfaces to view and edit their own application data

**Mechanism** a general interface over the application's data store  
**Beneficiary** teams rebuilding admin tooling
