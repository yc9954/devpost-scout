# a course is chosen without knowing what it plays like, and a flythrough is the only representation that answers that, so the courses with drone tours have an unearned advantage

Asserted by [[golfscape]] — *GolfScape*  
<sub>Google Photorealistic 3D Maps Challenge</sub>

**Problem** golfers book courses they cannot preview and only some courses have flythroughs

**Mechanism** generated 3D flythroughs from photorealistic map data for any course  
**Beneficiary** golfers choosing where to play and courses without video budgets
