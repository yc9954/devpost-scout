# an agent with memory is not a database with a model bolted on: the agent must decide what to remember and, crucially, retire facts that a newer one contradicts

Asserted by [[qwen-memory-agent]] — *Qwen Memory Agent*  
<sub>Global AI Hackathon Series with Qwen Cloud </sub>

**Problem** retrieval systems accumulate stale facts and keep surfacing them because nothing supersedes

**Mechanism** tool-calling memory with supersession-aware forgetting, measured on a reproducible benchmark  
**Beneficiary** anyone relying on a long-lived assistant

**Recurs in** [[clinical records]] [[legal precedent]] [[configuration management]]
