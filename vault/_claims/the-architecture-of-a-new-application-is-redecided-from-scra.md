# the architecture of a new application is redecided from scratch every time and the decisions are largely the same, so the reusable artifact is the reasoning rather than the code

Asserted by [[architecting-and-designing-a-react-native-application]] — *Architecting and Designing a React Native Application*  
<sub>2020 Facebook Developer Circles Community Challenge</sub>

**Problem** starting a new application means reassembling architecture from nothing each time

**Mechanism** a written architecture guide with a starter template  
**Beneficiary** developers starting new projects
