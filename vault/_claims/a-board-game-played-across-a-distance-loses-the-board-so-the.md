# a board game played across a distance loses the board, so the way to preserve the experience is motorising the physical pieces rather than moving to a screen

Asserted by [[chessmate-nwygvq]] — *ChessMate*  
<sub>Hack the North 2025</sub>

**Problem** playing chess with family abroad means giving up the physical board

**Mechanism** a motorised real board synchronised with a web app, with coaching and voice control  
**Beneficiary** families separated by distance and players who need accessible input
