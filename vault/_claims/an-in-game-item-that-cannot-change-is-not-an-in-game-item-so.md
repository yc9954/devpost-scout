# an in-game item that cannot change is not an in-game item, so the static NFT standard is why traditional game studios have not adopted it

Asserted by [[dna-dynamic-nft-asset-by-lync]] — *DNA - Dynamic NFT Asset by LYNC*  
<sub>Chainlink Fall 2022 Hackathon</sub>

**Problem** upgradable NFT game assets lack simplified infrastructure and game developers cannot list them

**Mechanism** dynamic NFT assets with the update mechanics handled for the developer  
**Beneficiary** traditional game studios entering web3
