# the input that makes mixed reality feel native is the one requiring no device, so designing to a single pinch decides whether the experience is picked up at all

Asserted by [[tiny-golf]] — *Tiny Golf*  
<sub>Meta Horizon Start Developer Competition</sub>

**Problem** mixed reality games depend on controllers

**Mechanism** mini golf played entirely with hand pinch gestures on a tabletop course  
**Beneficiary** people without controllers or the patience for them

**Recurs in** [[accessible interfaces]] [[training simulations]] [[design review]]
