# decentralised storage requires hosting a node, so an application that wanted to avoid infrastructure ends up operating some anyway

Asserted by [[shiro-storage]] — *Shiro Storage*  
<sub>Chainlink Fall 2022 Hackathon</sub>

**Problem** IPFS practically requires hosting a service, defeating the point for a contract-only application

**Mechanism** storage usable from a client and a contract with no services to run  
**Beneficiary** developers building without infrastructure

**Recurs in** [[serverless architectures]] [[embedded systems]] [[edge deployment]]
