# a proprietary platform's learning curve is mostly about the first working request, so a collection of ready calls is worth more to newcomers than documentation

Asserted by [[roku-dev-tools]] — *Roku Dev Tools*  
<sub>The Postman API Hack</sub>

**Problem** Roku development has a steep curve due to proprietary languages and tooling

**Mechanism** a ready set of commands and examples for controlling and debugging a device  
**Beneficiary** independent developers entering a closed platform

**Recurs in** [[embedded systems]] [[console development]] [[enterprise APIs]]
