# an identity system that lets anyone create identities cannot distinguish a person from a thousand of them, so self-sovereign identity and sybil resistance are in direct tension

Asserted by [[web3-reputation-oracle]] — *Web3 Reputation Oracle*  
<sub>Chainlink Spring 2022 Hackathon</sub>

**Problem** decentralised identity gives control and provides no defence against sybil attacks

**Mechanism** off-chain reputation computation delivered to contracts through an oracle  
**Beneficiary** protocols distributing anything per person
