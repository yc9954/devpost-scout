# an ambitious scientific simulation is blocked on the absence of differentiable primitives rather than on the science, so the reusable contribution is the layer beneath the project

Asserted by [[xitorch-differentiable-scientific-computing-library]] — *xitorch: differentiable scientific computing library*  
<sub>PyTorch Annual Hackathon 2021</sub>

**Problem** writing a differentiable quantum chemistry simulation required differentiable root finders, optimisers and ODE solvers that did not exist

**Mechanism** a library of functional scientific routines with first and higher order gradients  
**Beneficiary** researchers across differentiable simulation

**Recurs in** [[climate modelling]] [[structural engineering]] [[control systems]]
