# a document's authenticity is asserted by whoever holds it, so verification requires trusting the party with the incentive to lie

Asserted by [[certibits]] — *Certi.io*  
<sub>Celo's Make Crypto Mobile Hackathon</sub>

**Problem** document signatures cannot be independently validated by a recipient

**Mechanism** registering and validating document signatures on chain from a wallet  
**Beneficiary** recipients who need to verify a document

**Recurs in** [[diplomas]] [[contracts]] [[property deeds]]
