# loyalty points are a liability the issuer controls and the customer cannot move, so the value accrued by shopping is stranded by design

Asserted by [[thanx-finance]] — *FortunX (previously ThanX Finance)*  
<sub>TRON Grand Hackathon 2022</sub>

**Problem** decades-old point-based loyalty programmes lock value into one brand

**Mechanism** multi-brand rewards paid in a transferable token  
**Beneficiary** shoppers holding points they cannot use

**Recurs in** [[airline miles]] [[gift cards]] [[employee benefits]]
