# imagine an agent that needs to make 1,000 API calls to a paid service — that is potentially $50,000 in transaction fees alone just to pay for it

Asserted by [[flowpay-5mefh4]] — *Flowpay*  
<sub>MNEE Hackathon: Programmable Money for Agents, Commerce, and Automated Finance</sub>

**Problem** agentic usage is high-frequency and low-value per call, which is the exact shape the payment rail cannot serve

**Mechanism** payment streaming so agents negotiate at a paywall and money flows like a utility  
**Beneficiary** anyone building agents that must pay for things
