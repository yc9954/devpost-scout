# the sharpest failure of agent memory is not forgetting too much but being confidently wrong from stale memory, which fails silently at reasoning rather than visibly at retrieval

Asserted by [[quen]] — *Quên*  
<sub>Global AI Hackathon Series with Qwen Cloud </sub>

**Problem** invalidated facts remain retrievable and the agent acts on them without any signal of doubt

**Mechanism** salience-scored deltas with runtime trust decisions and verification before assertion  
**Beneficiary** anyone depending on a long-lived agent
