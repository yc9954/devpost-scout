# a tutorial teaches the API and leaves the practice untaught, so pairing a platform lesson with failing tests teaches the discipline alongside the tool

Asserted by [[messenger-platform-tutorial-tdd]] — *Messenger Platform Tutorial (TDD Approach)*  
<sub>2020 Facebook Developer Circles Community Challenge</sub>

**Problem** learners pick up a platform without any testing practice

**Mechanism** a tutorial where each lesson starts from a pre-written failing test  
**Beneficiary** developers learning a platform and a practice at once

**Recurs in** [[any SDK tutorial]] [[onboarding curricula]] [[bootcamps]]
