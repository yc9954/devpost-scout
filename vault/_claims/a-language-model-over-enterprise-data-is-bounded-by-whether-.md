# a language model over enterprise data is bounded by whether the data arrives as it changes, so change data capture rather than the model is the limiting component

Asserted by [[cdc-llm-data-architecture-with-opensource-and-fabric]] — *CDC LLM Data Architecture with OpenSource and Fabric*  
<sub>Microsoft Fabric and AI Learning Hackathon</sub>

**Problem** billions of records generated daily need a pipeline before any model can use them

**Mechanism** change data capture feeding an LLM architecture on open-source components and a data platform  
**Beneficiary** teams whose model is stale because the pipeline is

**Recurs in** [[search indexing]] [[fraud detection]] [[operational reporting]]
