# a resume is a one-way artifact that cannot be questioned, so both sides of hiring are making decisions on a document that answers nothing they actually want to know

Asserted by [[convjobs-find-jobs-the-better-way]] — *ConvJobs - Find Jobs the better way*  
<sub>Zero to One Hackathon by Convex</sub>

**Problem** the traditional hiring process frustrates candidates and recruiters equally

**Mechanism** a conversational interface over the resume so it can be interrogated  
**Beneficiary** candidates whose value is not legible on paper and the recruiters missing them

**Recurs in** [[grant proposals]] [[supplier qualification]] [[admissions]]
