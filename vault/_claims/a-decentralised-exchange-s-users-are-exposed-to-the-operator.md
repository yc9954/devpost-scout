# a decentralised exchange's users are exposed to the operator withdrawing liquidity, so trust has to be enforced by locks rather than promised

Asserted by [[electroswap-electroneum-dex]] — *ElectroSwap - Electroneum DEX*  
<sub>Electroneum Hackathon 2025</sub>

**Problem** liquidity can be pulled from a new exchange leaving users stranded

**Mechanism** built-in liquidity locking alongside trading, farming and portfolio views  
**Beneficiary** users of a new exchange

**Recurs in** [[escrow]] [[crowdfunding]] [[deposit schemes]]
