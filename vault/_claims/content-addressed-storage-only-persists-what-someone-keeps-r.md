# content-addressed storage only persists what someone keeps requesting, so an asset that is rarely viewed quietly disappears from the network that was supposed to preserve it

Asserted by [[nftstorage-helper]] — *NFTStorage Helper*  
<sub>Chainlink Spring 2022 Hackathon</sub>

**Problem** infrequently requested IPFS content is dropped from nodes and slows or vanishes

**Mechanism** retrieving user-generated metadata and images and pinning them locally and to a service  
**Beneficiary** holders of assets stored on a network that forgets

**Recurs in** [[archives]] [[scientific data]] [[legal records]]
