# a configuration format that experts struggle to explain to each other is a usability failure rather than a documentation one, so the fix is a visual representation

Asserted by [[chainlink-job-spec-viz]] — *Chainlink Job Spec Viz*  
<sub>Chainlink Spring 2022 Hackathon</sub>

**Problem** clarifying how a custom job specification worked was difficult even between informed parties

**Mechanism** a drag-and-drop visual builder generating the specification  
**Beneficiary** node operators and the people they explain configurations to

**Recurs in** [[CI configuration]] [[query builders]] [[workflow definitions]]
