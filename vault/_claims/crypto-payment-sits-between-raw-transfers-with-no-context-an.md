# crypto payment sits between raw transfers with no context and contract protocols too expensive to deploy and audit, so ordinary commerce has no middle option

Asserted by [[coal-programmable-commerce]] — *Coal - Programmable Commerce*  
<sub>MNEE Hackathon: Programmable Money for Agents, Commerce, and Automated Finance</sub>

**Problem** accepting payment means either metadata-free transfers or costly custom contracts

**Mechanism** a commerce layer with revenue splits and a single API and no contracts to write  
**Beneficiary** businesses that want to accept stablecoins without engineering
