# an agent bank distributes payments to five, ten or fifty participant banks, each maintaining their own spreadsheet and each calculating their own expected share independently

Asserted by [[syndicate-ledger]] — *Syndicate Ledger*  
<sub>LMA EDGE Hackathon</sub>

**Problem** a single payment is reconciled against as many independent private calculations as there are participants

**Mechanism** one shared real-time ledger replacing the parallel spreadsheets  
**Beneficiary** every participant currently reconciling by hand

**Recurs in** [[insurance syndicates]] [[royalty splits]] [[joint ventures]]
