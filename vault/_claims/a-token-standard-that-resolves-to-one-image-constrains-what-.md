# a token standard that resolves to one image constrains what a token can represent, so the expressive limit of the ecosystem was set by a function signature

Asserted by [[multiplace-multi-nfts-mnfts]] — *Multiplace & Multi-NFTs (mNFTs)*  
<sub>TRON Grand Hackathon 2022</sub>

**Problem** existing NFT standards return a single URI to one image

**Mechanism** a multi-asset token standard with a marketplace supporting it  
**Beneficiary** creators whose work is not a single image

**Recurs in** [[documents]] [[music albums]] [[3D assets]]
