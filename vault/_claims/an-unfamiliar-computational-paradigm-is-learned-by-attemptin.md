# an unfamiliar computational paradigm is learned by attempting a posed problem in it, so a challenge with a defined task is a better entry than a tutorial

Asserted by [[cansofcom-challenge]] — *CanSofCom Challenge*  
<sub>Hack the North 2022</sub>

**Problem** quantum computing is inaccessible without a concrete task

**Mechanism** implementing error correction and a variational classifier against a set challenge  
**Beneficiary** the team learning and the challenge setter

**Recurs in** [[new research fields]] [[unfamiliar languages]] [[specialist hardware]]
