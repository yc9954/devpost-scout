# environmental monitoring is built assuming stable operating conditions, so it degrades precisely in the emergencies it exists for, and the fix is automated ingestion that tolerates stations dropping out

Asserted by [[ukraine-radiation-monitoring-dashboard]] — *Ukraine Radiation Monitoring Dashboard*  
<sub>Elasticsearch Agent Builder Hackathon</sub>

**Problem** radiation and meteorological stations overlap partially and report unreliably under unstable conditions

**Mechanism** unified station data with orchestrated ingestion and alerting  
**Beneficiary** people living near monitored sites during instability
