# a collective playing one character through daily votes turns a game into a shared social ritual, so the format's appeal is the coordination rather than the game

Asserted by [[daily-dungeon]] — *Daily Dungeon*  
<sub>Reddit Games and Puzzles Hackathon</sub>

**Problem** role-playing games are played in small private groups

**Mechanism** a subreddit acting as one character with the top comment deciding each day  
**Beneficiary** large communities wanting a shared game

**Recurs in** [[collaborative fiction]] [[civic decision-making]] [[education]]
