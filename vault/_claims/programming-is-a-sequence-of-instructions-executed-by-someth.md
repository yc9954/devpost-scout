# programming is a sequence of instructions executed by something else, so a puzzle where the player writes the character's moves is teaching the actual concept rather than a metaphor for it

Asserted by [[rabbit-coder]] — *Rabbit Coder*  
<sub>Facebook Hackathon: AR</sub>

**Problem** programming concepts are introduced through syntax rather than through control

**Mechanism** an AR puzzle where the player codes the character's movement  
**Beneficiary** beginners learning control flow
