# validating a mailing list by sending to it is the test that causes the damage it was meant to detect, so verification has to happen off the sending path

Asserted by [[manaclean]] — *manaClean*  
<sub>Chainlink Spring 2023 Hackathon</sub>

**Problem** high bounce rates in marketing campaigns exhaust sender reputation

**Mechanism** email list cleaning without using the sender's own SMTP, paid via Chainlink adapters  
**Beneficiary** small senders without deliverability infrastructure

**Recurs in** [[phone number validation]] [[address verification]] [[API health checks]]
