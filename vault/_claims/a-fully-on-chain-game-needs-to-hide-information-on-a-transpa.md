# a fully on-chain game needs to hide information on a transparent ledger, so the design problem is secret state rather than the game

Asserted by [[treasure-hunt-zo2b3y]] — *Treasure Hunt*  
<sub>Privacy4Web3 Hackathon</sub>

**Problem** a fully on-chain game cannot hide the secret it is built around

**Mechanism** a treasure hunt using a confidential chain to store secret state  
**Beneficiary** players and designers of on-chain games with hidden information
