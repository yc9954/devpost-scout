# automated trading through API keys gives the broker multiple routes to the user's funds, so the delegation model rather than the strategy is the risk

Asserted by [[yanda]] — *Yanda*  
<sub>Celo's Make Crypto Mobile Hackathon</sub>

**Problem** malicious brokers can access user funds through the API keys automated trading requires

**Mechanism** on-chain execution making the trading transparent and the funds inaccessible to the operator  
**Beneficiary** users delegating trading authority

**Recurs in** [[managed accounts]] [[payment authorisation]] [[cloud access]]
