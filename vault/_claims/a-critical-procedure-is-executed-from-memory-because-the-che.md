# a critical procedure is executed from memory because the checklist lives outside the system doing the work, so steps are missed under exactly the pressure the checklist exists for

Asserted by [[jira-runbook]] — *Runbook for Jira*  
<sub>Codegeist 2021</sub>

**Problem** release and QA runbooks are maintained separately from the issues they govern

**Mechanism** customisable runbooks attached to the issue itself  
**Beneficiary** teams executing repeatable high-stakes procedures

**Recurs in** [[surgical checklists]] [[aviation]] [[incident response]]
