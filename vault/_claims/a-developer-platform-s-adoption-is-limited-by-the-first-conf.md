# a developer platform's adoption is limited by the first configuration a newcomer must write, so a visual builder is an onboarding mechanism rather than a convenience

Asserted by [[functionsgui]] — *Hamslink*  
<sub>Chainlink Spring 2023 Hackathon</sub>

**Problem** using a platform's compute functions requires code most newcomers cannot write

**Mechanism** a zero-code visual tool for building and testing the functions  
**Beneficiary** developers entering an unfamiliar platform

**Recurs in** [[CI configuration]] [[cloud functions]] [[data pipelines]]
