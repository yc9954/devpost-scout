# exoplanet detection is a classification problem over public archives and the bottleneck is expert review of candidates, so explainability decides how much of the archive can be used

Asserted by [[stellar-insight-labs]] — *Stellar Insight Labs*  
<sub>Frostbyte Hackathon</sub>

**Problem** detecting planets from subtle brightness changes requires expert vetting of candidates

**Mechanism** explainable machine learning over public exoplanet archives  
**Beneficiary** astronomers with more data than review capacity

**Recurs in** [[seismology]] [[radio astronomy]] [[medical screening]]
