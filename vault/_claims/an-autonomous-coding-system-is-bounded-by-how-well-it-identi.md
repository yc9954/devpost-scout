# an autonomous coding system is bounded by how well it identifies the problem rather than by how well it writes the fix, so the measurable advance is in problem identification

Asserted by [[concave-frxwcz]] — *concave*

**Mechanism** an open-source autonomous engineering platform measured at 50 percent better problem identification than the best open-source alternative
