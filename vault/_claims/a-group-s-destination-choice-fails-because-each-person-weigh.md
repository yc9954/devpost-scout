# a group's destination choice fails because each person weighs different attributes, so the decision problem is preference aggregation rather than recommendation

Asserted by [[pickle-savnjb]] — *Pickle*  
<sub>Disrupt SF Hackathon 2018</sub>

**Problem** a friend group cannot decide where to travel together each year

**Mechanism** matching across three hundred travel attributes for the whole group  
**Beneficiary** groups trying to agree on a shared trip

**Recurs in** [[team offsites]] [[family decisions]] [[group purchases]]
