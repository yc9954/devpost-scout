# projects tell users to run a container to simplify distribution and thereby make the container a dependency, so the simplification imposes a heavier requirement than the software

Asserted by [[dockerc]] — *dockerc*  
<sub>TreeHacks 2024</sub>

**Problem** distributing software is hard and relying on containers complicates it for users

**Mechanism** turning a container into a single distributable executable  
**Beneficiary** users who should not need a container runtime
