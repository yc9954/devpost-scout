# writing code without using a profiler is like driving a car with no dashboard

Asserted by [[civo-x-pyroscope]] — *Civo x Pyroscope Continuous Profiling*  
<sub>Civo Hackathon 2021</sub>

**Problem** performance regressions are introduced in changes and observed in production, because profiling is not part of the review

**Mechanism** an interactive performance profile attached to each proposed change  
**Beneficiary** reviewer who cannot see the cost of a change

**Recurs in** [[energy usage]] [[cost review]] [[accessibility regressions]]
