# a large population of agents makes selection the user's problem, so the scarce function becomes routing and shared context rather than more agents

Asserted by [[aigency]] — *Aigency*  
<sub>One Trillion Agents Hackathon</sub>

**Problem** users cannot manually select the right agent or carry context between them

**Mechanism** a caching and orchestration layer with a scheduler, shared memory and usage metering  
**Beneficiary** users facing an unmanageable number of agents

**Recurs in** [[app stores]] [[service marketplaces]] [[API ecosystems]]
