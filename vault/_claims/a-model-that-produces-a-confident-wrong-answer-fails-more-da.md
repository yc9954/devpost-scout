# a model that produces a confident wrong answer fails more dangerously than one that fails visibly, so teaching refusal is a capability rather than a limitation

Asserted by [[failure-aware-ernie]] — *Failure-Aware ERNIE*  
<sub>ERNIE AI Developer Challenge</sub>

**Problem** language models produce answers that sound correct when they are wrong

**Mechanism** safety-focused fine-tuning teaching the model when not to answer  
**Beneficiary** anyone relying on a model in a consequential setting

**Recurs in** [[medical advice]] [[legal guidance]] [[autonomous systems]]
