# integration between tools is written repeatedly as bespoke code because the generic case requires a person who can code, so the connection is gated on engineering capacity rather than on the protocol

Asserted by [[jira-hook-ninja]] — *Jira Hook Ninja*

**Problem** many applications must communicate with Jira over webhooks and each integration is built by hand

**Mechanism** no-code connection of any webhook-supporting application to ticket creation  
**Beneficiary** teams whose integrations wait on developers
