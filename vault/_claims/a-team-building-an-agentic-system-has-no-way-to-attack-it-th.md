# a team building an agentic system has no way to attack it the way an adversary would, so the defence is written against imagined attacks rather than attempted ones

**Problem** no reliable way to adversarially test one's own LLM system and existing tools are too narrow

**Mechanism** an agent that simulates jailbreaks, prompt injections and adversarial attacks and reports  
**Beneficiary** teams deploying agentic LLM systems
