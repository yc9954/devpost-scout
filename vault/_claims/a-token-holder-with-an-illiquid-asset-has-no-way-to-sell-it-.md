# a token holder with an illiquid asset has no way to sell it fairly, so verified randomness turns an unsellable item into a distributable one

Asserted by [[nifty-wheel]] — *Nifty Wheel*  
<sub>Chainlink Spring 2022 Hackathon</sub>

**Problem** users cannot sell tokens on secondary markets without a buyer for that exact item

**Mechanism** permissionless vending machines using verifiable randomness  
**Beneficiary** holders of illiquid tokens

**Recurs in** [[collectibles]] [[event tickets]] [[allocation of scarce goods]]
