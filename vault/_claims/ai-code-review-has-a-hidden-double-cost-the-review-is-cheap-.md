# AI code review has a hidden double cost — the review is cheap and every claim it makes is unverifiable, so your team pays again to re-check it

Asserted by [[gitlab-awj9q1]] — *Evidence-First Reviewer*  
<sub>GitLab Transcend Hackathon</sub>

**Problem** generated review output shifts the work from finding issues to validating assertions, which can cost more than the original review

**Mechanism** back every claim with a runnable query, the rows it returned and an explicit evidence scope  
**Beneficiary** team re-checking an AI reviewer
