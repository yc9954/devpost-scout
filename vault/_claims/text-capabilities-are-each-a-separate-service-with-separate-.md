# text capabilities are each a separate service with separate integration, so an application needing four of them pays four integration costs for one feature

Asserted by [[textly-api]] — *Textly API*  
<sub>The Postman API Hack</sub>

**Problem** implementing correction and analysis in a blog application meant assembling many services

**Mechanism** one API covering grammar, spelling, sentiment, summarisation, prediction and translation  
**Beneficiary** developers adding language features to an existing product
