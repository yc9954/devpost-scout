# decentralised alternatives to common services fail on requiring a wallet first, so the adoption barrier is the prerequisite rather than the service

Asserted by [[shiro-share]] — *Shiro Share*  
<sub>Chainlink Fall 2022 Hackathon</sub>

**Problem** instant file sharing has popular centralised options and unusable decentralised ones

**Mechanism** file sharing that works without a wallet and supports one if present  
**Beneficiary** people who want decentralised storage without the onboarding
