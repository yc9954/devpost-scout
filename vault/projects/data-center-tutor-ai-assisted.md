## Body

Data Center AI Buddy Inspiration I have been engaged with a data center migration program. During the course of this program, many infrastructure components are setup in the compute/storage/Network/Mainframe area. Often I wondered that it will be nice to have an assistance/tutor who can explain some infra components with friendly explanation along with images. PartyRock provided the platform to create an AI assisted Data Center Tutor/Buddy. What it does Data Center AI Buddy/Tutor makes it fun to ask data center related questions. It provides simple explanation for the technical components. you can ask broad questions like what is a data center? or you can ask more specific questions like what is a mainframe? or what is a UCS, or what is a Pure Storage etc. How we built it I built it using PartyRock, four key components. 1) it has a text area to ask question 2) it has an AI assisted response using Claude Instant AI model 3) it has an image generator using Stable Diffusion XL 4) it has a chat bot for interactive chat for data center related questions. Challenges we ran into PartyRock made it easy to create. No coding involved, hence did not really run into any challenge. Accomplishments that we're proud of Very proud of the accomplishment of creating this app. while in the past, I have used google to find answers to similar question, it is nice to have a Data Center AI Buddy/Tutor ready to get answers for technical questions related to data center with simple explanation. What we learned learnt how to effectively used Claude Instant and Stable Diffusion XL model to create application that provides user answers both in text summary and visual way by presenting an image along with the response.
