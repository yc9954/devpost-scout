## Body

Registration for service provider Login User customized route submission screen Regular routes suggested by google maps Customized route by user and customized route string Upload page for user's customized string to render on map Inspiration Solving problems for the rural population and coming up with some innovate idea concerning transportation was our main inspiration. What it does It let users customize their routes from an origin to a destination and then submit this customized route to a virtual transport marketplace. Interested parties like transport service provides, ride sharing services and private transport companies can subscribe to these submission and then contact the user in need and proceed accordingly. How we built it We used html/css/js front-end and php with mysql with as our back-end. Challenges we ran into WE HAD VERY LITTLE TIME. We learned about it late night on Saturday from a partner representative and thought we can present a MVP and a solid idea. Accomplishments that we're proud of We came up with a MVP on such a short notice. What we learned A lot or almost everything relating to public services has tons of data available free online. Google maps integration and php. What's next for FindMyWay This is just a MVP.
