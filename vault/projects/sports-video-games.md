Overview This workspace contains API's for sports, video games data, and messaging/social media integration. See Inspiration below for ideas that you can build with this workspace. Developers can use OpenAPI(Swagger) definition provided in this workspace for API generation in your application. Mock servers are provided, you can utilize them to test API's without subscribing to external services.
