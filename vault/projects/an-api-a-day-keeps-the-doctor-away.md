## Body

An API a day keeps the doctor away. When thinking about an API to use for The Postman API Hack, didn't you wish there was an API that would do just that ? Introducing, "An API a day keeps the doctor away", a postman collection that helps you get suggestions of unique APIs you have never heard of before. Maybe it will result in your next big idea! In this demo collection, we have two API calls, one to actually get a random unique API, and one demo request that can help send you a personal slack message with a fresh new API you might have never seen before.
