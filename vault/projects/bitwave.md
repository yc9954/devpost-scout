Bitwave Inspiration We grew up playing retro games fast, fun, and unforgettable. But today’s Web3 games often lose that spark of simplicity and instant fun. We wanted to bring that nostalgic joy into the blockchain era where every high score, every win, and every collectible actually belongs to the player. What it does • Play classic-inspired arcade games instantly • Earn VESU tokens based on performance and achievements • Claim, trade, and showcase on-chain collectibles How we built it Frontend: React + TypeScript + Vite + Tailwind Backend: CAVOS - DOJO gaming - starknet contracts Challenges we ran into Integrating on-chain rewards without breaking game performance Accomplishments that we're proud of Launched a working MVP playable directly in the browser Fully integrated Starknet reward claiming flow Designed a mobile-first UI What's next for Bitwave Add more retro-inspired games (Tetris, Space Invaders, DOOM) Launch global leaderboards and weekly tournaments <div
