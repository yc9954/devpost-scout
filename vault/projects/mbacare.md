## Body

MBAcare - Union of Technology + Healthcare Inspiration The Idea came to us because of the fact that there are lot of accidents , illness or health realted problems that happens to people everyday and people loose time to find beds in a hospital. So we came up with a solution that people can find out the availability of the beds nearer to them What it does This is a all purpose medical app for a person. User can go directly into the landing page and there are lot of options to choose from for him. He can find out the nearest hospital which has bed available so that he can directly go there and it can be easy for him. How we built it We built it using the language that was focused during the workshop mostly on HTML. We have customised it using CSS and there are certain features that we have used vanilla javascript for that. We have used firebase to store the database of the person. We have then deployed it in the vercel. Challenges we ran into There were some issues with the location functionality , which took us some time to do. Accomplishments that we're proud of We have made a realtime database to store the credentials of a patient. We have added location feature in the app to make it more accessible. What we learned During this hackathon we have learnt the integration of firebase, deployment of the application and to integrate google maps with the frontend. What's next for MBAcare We want to shift the whole project to modern day tech stack to attain more functionalities.
