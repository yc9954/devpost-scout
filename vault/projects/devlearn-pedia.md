## Body

Inspiration As an intern I didn't know what I needed to know, I googled a lot and asked around. What it does Devlearn-pedia provides list of topics with simple briefing for things an intern/entry-level developer should know. Senior developer can also come and search for things here. They can also contribute. How we built it I used mock server to hard code the list of topics and then simple called them as Get requests individually. Challenges we ran into Figuring out how mock APIs work in Postman Accomplishments that we're proud of I am proud of this idea, I think this can not only help developer learn and use this collection as encyclopedia. But it can turn into a platform for open source contribution as well by senior developers. What we learned Postman and creative ways to use it. What's next for Devlearn-pedia To make it an open-source collection where developer can contribute more topics alongside explanation for them. <div
