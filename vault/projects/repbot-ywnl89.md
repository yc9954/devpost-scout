## Body

RepBot Inspiration We wanted to make workouts smarter and more engaging by providing real-time feedback and tracking. What it does RepBot is a Flutter app that uses pose detection to automatically count reps, track exercises like push-ups and squats, overlay a skeleton for form, and provide AI-based progress analysis. How we built it Built with Flutter and real-time pose detection, with AI logic for feedback and a local database for tracking workout history. Challenges Detecting poses accurately in real time and optimizing performance on mobile devices were the biggest hurdles. Accomplishments A fully functional app that tracks reps, analyzes form, and motivates users through progress insights.
