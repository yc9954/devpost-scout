## Body

Interface of our application Inspiration: We met with obstetricians, midwives, and maternal health specialists to note the role of easy, accurate information among women during pregnancy. The need for a tool that would assist them keep track of symptoms and understand when to report to a healthcare provider was key in the maternity world. We were inspired by the growing understanding of pregnancy as a holistic experience that encompasses physical, emotional, and social aspects. This led us to design an app that addresses multiple facets of the pregnancy journey. The advancement of mobile technology and AI-driven personalization inspired us to create an app that could provide tailored advice and insights based on each user's unique pregnancy journey. What it does: It assists pregnant women in keeping track during their pregnancy via various features provided such as :- symptoms tracker, weekly guidance, community support, education library along with emergency and appointments section. How we built it: We built it using the following technologies- React.js (front end) Next.js/Node.js (backend) TypeScript (JavaScript) Tailwind CSS (to enhance the design along with speed) Lucide React (for icons) Challenges we ran into: While deploying our project we faced certain issues but later resolved. Accomplishments that we're proud of: Building this app, successfully linking various websites for our education library and deploying this project successfully along with my teammates. What we learned: we got our hands on experience in creating app using react.js and node.js and learnt about various less in use libraries and commands. What's next for MummaCare (Application): Planning on providing more resources. Being able to call directly via application.
