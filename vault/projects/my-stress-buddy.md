## Body

Inspiration Our idea comes from discovering that many people have stress issue and some of them unaware what they can do to relieve their stress correctly or seek help when they need to. Hence, we decided to develop a website that can help people. What it does It is a website for helping people to find help and reduce their stress. Helpful information are provided to help users to overcome their stress problem. How we built it We build it using HTML 5 an CSS3. The website is hosted using GitHub. Challenges we ran into We ran into challenges such as lack of idea and information for writing articles that can guide people to relieve stress. Accomplishments that we're proud of We are feeling proud of being able to provide online meeting support features on the website, and it is easy to use too. What we learned While developing the website, we learn many programming knowledge on developing the website and learn about stress problem in health. Another skill we learn is that we learn to host webpage online using Github Pages. What's next for My Stress Buddy We will continue to collect feedback to improve My Stress Buddy website.
