## Body

Inspiration Experimenting building chat applications using Azure SignalR Service with real time translation. What it does Portal Chat is a chat application that improves the overall chat experience by removing language constraints. Portal Chat provides real-time language translation so users can send and receive messages in their language of choice. How we built it We built the chat client using Angular. The real time translation was built using Azure Cognitive Service Translation and the chat functionality was built using Azure SignalR Service using Azure Functions. Challenges we ran into We run into challenges setting up the chat functionality since its was our first time using Azure Signal Service. Accomplishments that we're proud of Building a chat application. Building an application that uses real time translation services. What we learned Azure SignalR with Azure functions, Azure Cognitive Services, deploying angular apps to Azure Static Websites.
