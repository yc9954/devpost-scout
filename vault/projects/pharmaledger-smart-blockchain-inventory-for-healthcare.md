home page dashboard list of medicines chat assistant stock manageent for admin only access medicine transparency external verification Inspiration Counterfeit medicines, lack of transparency, and inefficient inventory management are serious challenges in the healthcare supply chain. These problems can lead to unsafe drugs reaching patients, medicine shortages, and financial losses. PharmaTrack Lite was inspired by the need for a secure and trustworthy system that ensures medicine authenticity and transparent tracking. What it does PharmaTrack Lite is a blockchain-based smart inventory and supply chain management system for healthcare. It records every stage of a medicine’s lifecycle—from manufacturing to distribution and sale—on an immutable ledger, ensuring transparency, traceability, and trust. How we built it We built PharmaTrack Lite using blockchain technology to securely store transaction records. Smart contracts handle inventory updates and verification, while a web-based dashboard allows pharmacies and administrators to monitor stock and track medicine movement in real time. Challenges we ran into Understanding how to map real-world pharmacy operations to blockchain workflows was challenging. Balancing security, performance, and usability while keeping the system simple for end users required multiple design iterations. Accomplishments that we're proud of We successfully developed a functional prototype that demonstrates transparent medicine tracking using blockchain. The project highlights how decentralized technologies can solve real-world healthcare problems. What we learned Through this project, we learned about blockchain architecture, smart contract development, and designing scalable systems with social impact. We also improved our teamwork and problem-solving skills during the hackathon.
