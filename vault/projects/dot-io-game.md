# DOT.IO GAME

## Body

Inspiration I am a slither.io player, and I play it a lot because it’s fun and highly competitive. That’s why I created a game with a similar core concept, designed so Snapchat users can play it, with a leaderboard showing friends’ rankings. What it does It delivers a competitive DOT.IO-style experience inspired by slither.io, where players compete against AI opponents using simple, intuitive controls. The game is designed for Snapchat users, allowing them to play directly on the platform, collect points, and compete through a leaderboard that shows friends’ rankings, creating a fun and competitive social experience. How we built it Building the game took a lot of time—from UI design, character design, and map creation, to spending many hours on programming. In the end, the result was very satisfying. I’m looking forward to creating a second version where all players are real, so you can play together with your real friends on Snapchat. <div
