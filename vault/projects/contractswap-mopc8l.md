ContractSwap homepage Inspiration ContractSwap came as an idea after seeing the rise of NFT/DAO's groups, we saw how these groups wanted to purchase NFT collections and after doing some research we found out that there were no tools available that simplified this process, so we decided to create ContractSwap to safely transfer smart contracts between parties What it does ContractSwap allows people to trade smart contracts between parties securely by working as an escrow, let's say that "TEST_DAO" wants to purchase an NFT collection, in order to fully capture all the features and rewards of this collection it will need to do so through a contract transfer as buying all the NFTs in a collection will not give any power to the DAO for things like royalties, management of the NFT's, etc. So traditionally this can only be achieved through low-level coding, meaning that the person doing so needs to have programming knowledge to some extent. Now with ContractSwap we build a dApp that allows you to do this without any programming knowledge and also introduces the ability to add cryptocurrencies as a payment for the exchange of the contract. How we built it ContractSwap core functionality is placed in its smart contract, this smart contract had to be built from the ground up with a brand new design as we believe this is the first dApp that accomplishes the task at hand, we meticulously tested it in multiple environments to make sure this is safe for anyone to use and that it accomplishes what it is meant to. ContractSwap also features an upgradeable smart contract meaning that we can easily be updating the smart and bring new features to it. Challenges we ran into Although we have knowledge in software development, the whole project has been a challenge from learning a lot of new technologies to building the front-end of the app, as well as learning solidity from 0, we decided to take responsibility to make the project a great as we could, overall we are proud to say that this project has been built with pure love for the space and that we accomplished most of what we set out to. What's next for ContractSwap In the future, we envision contract swap as an open marketplace to trade smart contracts rather than just being a tool to be able to do so. We also envision educating more people on smart contracts and web3 so we as a whole can be more aware of the capabilities and functionalities of what's possible in the space. <div
