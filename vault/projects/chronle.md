## Body

Logo Inspiration I was inspired by the fascinating connections between historical events and how they relate to each other in time. For example, did you know that the Wright brothers' first flight happened just 66 years before humans landed on the moon? Or that woolly mammoths were still alive when the Great Pyramid of Giza was being built? I wanted to create a game that would help people discover these historical connections while having fun. What it does Chronle is a daily puzzle game that challenges you to arrange historical events in chronological order. Each day brings a fresh set of events with images, and you have 6 moves to get them in the right order. There are stats to track your progress and a leaderboard to see how you rank against other players. How I built it I built Chronle using a modern tech stack that includes Next.js for the web app, Supabase for the database, and Devvit for the Reddit integration. The game features smooth drag-and-drop interactions, beautiful animations, and a clean, intuitive interface. I focused on making it easy to grasp and use while keeping the gameplay engaging and challenging. Challenges I ran into One of the biggest challenges was making sure the historical events were accurate and interesting while keeping the game balanced. I also had to figure out how to make the drag-and-drop interface feel smooth and natural on both desktop and mobile devices. Another challenge was creating a system that generates new, interesting puzzles every day while maintaining a moderate difficulty curve. Accomplishments that we're proud of I'm glad I could create an app for the Reddit developer platform. I'm also glad to see the app in a working and sharable state. What we learned I learned that people love learning about history when it's presented in a unique format I also discovered that the key to a great puzzle game is finding the right balance between challenge and accessibility. Having gestures incorporated into the game was a great way to make it more intuitive and increase engagement.
