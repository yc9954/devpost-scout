## Body

Inspiration Inspired by the inventory management puzzle sub-genre, my goal was to create a fun daily game where players solve puzzles and create unique content. How to Play ✋ Pick up items — Drag and drop items onto the grid to start packing. 🧩 Make it fit — Carefully arrange every item until the grid is completely filled. 🎉 Get fully packed! — Complete levels to earn tickets to spend in the workshop! Community Workshop The community workshop is a place where users can create items and vote on the items they'd like to see in future games. To create an item, choose a block shape, upload an image and give it a name. Contests run each week, with the top-voted items added to the item pool. What's next for Fully Packed I hope to grow a community of engaged daily puzzlers, with addictive puzzles and fun contests. One planned feature is to support user generated puzzles to allow players to create their own puzzles with custom art and share them with the community. Play today at r/FullyPacked . <div
