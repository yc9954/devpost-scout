## Body

It has emoji chat,sending gifs,videos,files , replying to their message, creating a thread, pinning a message , react to their message Inspiration: The main inspiration of this project hits me when my uncle who is a doctor shared his difficulties in medical sector which he faced due to lack of centralized and dedicated platform for them. What it does: It’s a Full Stack complete Real Time Chat Application but way different than others , It’s primarily made for a centralized and dedicated platform for hospital staff (doctors, nurses,staff members etc) to have a perfect connection through this real time chat application using which they can chat with other doctors, can send reports, files, and can even send videos along with emojis, threads chatting, specific replying, authentication and comprises of many more features . How I built it: This web-application is built by using React, Node.JS, Express and many other exciting libraries. Challenge I ran into: During the development, the major challenge faced was - Challenge: To make this web app completely above than others and giving user/doctor a complete different and enhanced way of interacting than in other normal chatting apps Solution: we tackled by creating features like uploading gifs,files (pdf,doc), videos, emojis, creation of thread, feature like reacting to a message and many other inclusions. Accomplishments that I'm proud of: Creation a centralized, dedicated, really helpful for healthcare, fully enhanced and different chat application along with the exclusive features in a very short time is what makes me a bit proud. What I learnt: I got to learn the skill of handling various APIs and its data and perfecty integrating it in my web app. What's next for MediChat18: Planning to create some official channels for connecting doctors from all over India to get on a common portal so that a strong network is established among Indian doctors which would help them to share knowledge,updates and can build new connections!!
