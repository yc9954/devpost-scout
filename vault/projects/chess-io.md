## Body

Main Menu Game Developer Mode Win photo Inspiration This platormer game is inspired by one of oldest and best known games in the world - chess. Chess was played even 1400 years ago. Even enemy movements in this game are inspired by chess, rooks are moving in line, knights are jumping and bishops are moving diagonally. What it does In chess community, one of favorite check-mates are check-mate by pawn. So, main character in this game is black pawn and his goal is to get to white king. To do that, he needs to avoid other chess-pieces, rooks, bishops and knights. There are also some books to collect but, be careful, once you fail the current level, every book gained in previous levels is lost. MOVE USING ARROWS, AND JUMP USING SPACE! (Also You can restart level using SPACE, without need to use mouse and click button) How we built it It is built using python and pygame library, and figures are designed using Photoshop. Challenges we ran into Biggest challenge was to make it entertaining, but old at same time. We achieve it by unique design, using retro-style arcade game sounds and making it able to play using only keyboard. Accomplishments that we're proud of Best part of this game is "Developer Mode" that, beside created levels, gives user a opportunity to modify and create his own, unique levels. What we learned We learned how to use pygame library, and also expended or knowledge of python and Photoshop. But, most important thing, was to teach my own mind to be productive and disciplined in creating something. What's next for CHESS.IO After "developer mode", we can also add more characters with different abilities. Instead the pawn, there will be bishop which could shoot an arrow at enemies or knight that could double-jump. Also, we could add spells, that will give a figure special power, when are collected. <div
