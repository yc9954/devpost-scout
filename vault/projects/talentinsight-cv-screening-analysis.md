## Body

Overview of the App Inspiration This application was inspired by my collaboration with HR professionals, where I often assist in screening CVs. The CV screening process can be time-consuming, especially with a large number of applicants. It's also challenging to ensure candidates fit the job responsibilities, requirements, and existing company culture. Some HR professionals struggle to determine if a candidate's skills match job requirements due to their limited knowledge, especially in technical roles. For instance, distinguishing between .NET Core and .NET Framework can be confusing. The Q&A chatbot in this program aims to assist HR professionals in clarifying such queries. What it does This application aims to facilitate HR professionals and users in the CV screening process to make it more effective. The application matches candidates' skills with job requirements, providing summaries and recommendations for HR/users. How we built it HR or users simply input the candidate's skills or work experience and the requirements of the job opening. The application automatically generates a summary and recommendations. Challenges we ran into The challenge we face is how the application can access a candidate's LinkedIn profile or how to upload a candidate's CV to the application in PDF format. Accomplishments that we're proud of The application can think like a discussion or brainstorming partner. And several users showed interest in this idea when the application overview was posted on LinkedIn. What we learned From this application, I also learned how AI aids humans in thinking, gaining insights, and making decisions about something. And this certainly makes things easier because the application can act as a partner. Additionally, what we learned is that in the future, creating applications will become easier because once the problem information is provided, solutions will be automatically generated. What's next for TalentInsight: CV Screening & Analysis Future iterations of the application may involve incorporating company culture or core values to assess candidate fit. Additionally, integrating personality type assessments and other information aims to enhance the application's accuracy. Furthermore, we seek to support multiple languages, including Indonesian, to broaden the application's usability.
