## Body

Inspiration During Kiroween, I wanted to create a fun, interactive project that combines AI text generation with a Halloween theme. I was inspired by the idea of giving users a daily boost of motivation and a playful tool to generate creative idea names, all wrapped in a spooky, magical interface. I learned how to leverage Kiro's vibe-coding to generate dynamic textual outputs and integrate them seamlessly into a web interface. The biggest challenges were creating a polished UI with Halloween animations while keeping the core functionality intuitive and responsive. What I Built KiroMotivate is a web app that offers: Daily Motivation Generator 🔮 – generates short, uplifting sentences Idea Name Generator 🕷️ – creates spooky or random names for projects, with a dedicated random generator button Fully themed for Halloween: dark backgrounds, glowing neon text, flickering titles, and ghostly animations All functionality runs locally or in the browser, demonstrating Kiro’s vibe-coding capabilities while keeping the experience fun and interactive.
