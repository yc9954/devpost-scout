What it does It scans images of cells to detect if the cell is infected with malaria or not, either when connected to a standard microscope in the lab during diagnosis or when the image of a cell is scanned from almost any surface. How I built it I got the malaria cell images data-set from Kaggle I examined the images i got and separated them into different categories for training, testing and for validation 3.I setup my Microsoft Azure environment by registering and signing up for azure services. I logged on to my Microsoft Azure portal, and created a resource for the project. I then logged on to link where I loaded my images and trained my classification model or image recognition system. I exported my trained model for deployment into Android as an android application by exporting the model for further development in Android studio using Java programming language to build the application. I developed the android application and generated the signed apk for it, so as to test it and make it available for use. Challenges I ran into Signing up for Azure account and getting it verified Exporting the trained model from Azure Custom Vision to Android studio Understanding the original sample code after importing models from Azure custom vision.
