# GRID Stats with visionOS

> This is an app that leverages Apple's new visionOS, enabling users to see statistics with an Apple Vision Pro headset. It is programmed using Swift and uses the SwiftUI.

[Devpost](https://devpost.com/software/grid-stats-with-visionos) · hackathon [[GRID Esports DataJam 23]]

**stack** swift

## Body

Introduction Apple's announcement of their new Vision Pro has been all the rage recently among many in the Apple community and Apple have been very enthusiastic in getting those who develop apps or programs within the Apple ecosystem to try out their new visionOS, which is the operating system used to develop apps for the Vision Pro. With the latest development, this project is a helpful starting point when it comes to integrating eSports data with both virtual reality and Apple's Vision Pro. With this program, users can see important statistics relating to their achievements and those of their teammates within their Apple Vision Pro. Statistics appear on something known as a "window" within the context of visionOS. Users can scroll and browse the leaderboard to see how they perform relative to others. This was built using Apple's programming language Swift, its latest framework called SwiftUI (as opposed to UIKit) as well as extracting data from GRID eSports files in .jsonl. In the real world, however, data would most likely be extracted from a server.
