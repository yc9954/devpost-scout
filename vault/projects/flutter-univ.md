Splash Screen Start Screen Play Screen Result Screen Project Story Inspiration This project was inspired by the connection between sustainability and the ocean. Specifically, it focuses on the issue of ocean plastics and how they threaten the habitats of marine life. To raise awareness about this issue, the idea of creating a game that utilizes smartphone features was born. The game concept involves avoiding ocean plastics by tilting the smartphone, engaging users in a fun and educational experience. Additionally, incorporating a feature to add information to Google Wallet was considered, allowing users to be reminded of the importance of the ocean at any time. Challenges Faced Implementing Google Wallet for the first time was challenging due to our unfamiliarity with the process. Integrating Flutter Flame with the smartphone's tilt sensor for game controls proved to be difficult. Lessons Learned Utilizing Google's services allowed for a relatively easy implementation of Google Wallet features once we became familiar with the process. Gained a deeper understanding of the impact of ocean plastics on marine life. Through this project, we aimed to increase awareness of the ocean plastic problem while overcoming technical challenges to develop an educational and enjoyable game. <div
