## Body

Demo Inspiration The rise of healthcare sector is not a mystery, As population rises so does the importance of a proper healthcare system. This inspired us to help people and deliver a simple but effective solution to them. What it does Appointment management - Book, reschedule, cancel and view appointments. Insurance management - Manage your Health insurance, policies and claims. Locating Nearby doctors - Locate nearby doctors using your zip code. Symptom analysis and Disease prediction - Recognizes symptoms and offers diagnosis. Calorie management - Calculates calories in your meal , calculate calories burned and calories required to meet your body transformation goal. How we built it We built it using Kore.ai xo platform The backend was built with Node js The Database is managed using MongoDB Deployment channels include website, Kore Messenger, Telegram and Whatsapp Used an expert system for Symptom analysis Challenges we ran into API integration Looping the nodes Live agent Transfer Integrating Google Maps Api Voice integration Accomplishments that we're proud of Multilingual Support Integration of Infermedica API an expert system for symptom analysis. Usage of Intelligence functions like amend entity , manage interruptions and sentiment analysis. Conversation friendly customer experience. What we learned ]- Usage of Kore.ai platform for user friendly conversational experience. How to integrating an expert system to the bot Learnt different types of ML engines inside the bot Different validation system such as confusion matrix What's next for Anya In the near future we are planning to integrate the bot with a smart watch which can monitor the user and provide additional real time information to enable new functionalities.
