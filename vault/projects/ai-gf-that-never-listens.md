## Body

Inspiration The inspiration for "AI GF that never listens" came from my desire to create an interactive and humorous chatbot with a sarcastic, playful personality. I wanted to build a unique experience where the AI responds unpredictably and dynamically, with mood changes based on the conversation. Honestly, this is probably as close as most of us CS students will get to having a girlfriend lol. What it does The project is a chatbot that simulates a playful, sarcastic "girlfriend" persona. It responds to user input with varying moods—such as happy, annoyed, or angry—and provides humorous, sassy replies. The AI’s mood and profile image change according to the conversation's context, creating a fun and dynamic interaction. How we built it Frontend: Built using HTML, CSS, and JavaScript to create an interactive and visually appealing chat interface. Backend: Developed a Flask server to handle user inputs, manage mood transitions, and generate responses via an AI model. Mood System: Integrated a dynamic mood system that changes the AI’s personality based on user input. AI Model: Used Llama 3.1 8B model from Nebius AI to generate playful and sarcastic responses based on the user's messages. Challenges we ran into Response Naturalness: Maintaining a balance between sarcasm and natural-sounding responses was a challenge, ensuring that the AI’s tone stayed consistent and engaging. Mood Transitions: Implementing smooth and realistic mood transitions based on the conversation flow required fine-tuning. Asynchronous Communication: Handling asynchronous communication between the frontend and backend, especially with real-time interactions, was tricky at times. Errors: A LOT of errors. Accomplishments that we're proud of Successfully integrating mood-based responses, picture updating and dynamic personality changes in the chatbot. Creating an engaging, playful user experience with personalized interactions. Implementing a smooth communication flow between frontend and backend using Flask and JavaScript. What we learned How to manage a Flask project. How to make dynamic changes to HTML/JS with Flask. How to work with a team on GitHub. How to integrate AI APIs into projects. What's next for AI GF that never listens I will improve AI’s personality and mood management to make interactions even more dynamic and engaging. I'll add more features like voice input, buttons for interaction, and more personalized responses. I will probably make an app for mobile devices. <div
