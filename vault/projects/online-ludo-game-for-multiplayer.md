## Body

Ludo Game Launch UI Ludo Home Page Inspiration Multiplayer Ludo game which very popular among youngster in world , Play in free time with friends and family. What it does This application allow player to create a game , share game id with another player to join Ludo game with game id. Up to 4 player can play this game turn by turn. How we built it It is build with Python Flask, Socket.IO, and modern web technologies to allow user to play via mobile or web. Challenges we ran into It was very difficult to communicate between player and sync real time. This game give option to turn by turn through dice and play with your choice of game id. Each player have different color card to play. It is automatic enable other player chance once dice play by previous player. Accomplishments that we're proud of it was really nice to see real time Ludo player version which allow multiplayer in a game over internet. Where player can join from any where in world. What we learned Here we learned uses of AI code builder IDE promptly , with in 48 hrs of thoughts in display in reality. It is help me a lot debug, test and learn new language faster then ever. What's next for Online Ludo Game for Multiplayer I would like to create different and customize version of Ludo game in future to attract player.
