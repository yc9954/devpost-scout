account page login page feed mobile-view register page Admin dashboard organization-detail page organization dashboard page post-detail home page Inspiration Many non-profit organizations struggle with visibility and trust when raising funds. Inspired by the need for a transparent and accessible fundraising platform, we built Fund-Raising to connect organizations with potential donors while ensuring credibility. What it does Fund-Raising allows non-profits to register, showcase their initiatives, and provide verified banking details for offline donations. Users can browse campaigns, engage with organizations through likes and comments, and support causes they believe in. How we built it We developed Fund-Raising using the MERN stack (MongoDB, Express.js, React, Node.js) . The backend manages authentication, user roles, and fundraising campaigns, while the frontend provides an intuitive interface for users and organizations. Redux Toolkit handles state management, and MUI,shadcn enhances the UI/UX. Challenges we ran into Implementing a dynamic form structure for different user roles. Ensuring secure authentication and role-based access control. Managing image uploads for organization verification. Handling efficient state management for a seamless user experience. Accomplishments that we're proud of Successfully built a secure and scalable fundraising platform. Implemented an intuitive UI for organizations and users. Developed a verification system to ensure non-profit authenticity. What we learned Advanced state management using Redux Toolkit. Best practices for authentication and authorization in MERN. Optimizing API requests for better performance. What's next for Fund-Raising Adding an analytics dashboard for organizations. Enhancing the user experience with better search and filtering.
