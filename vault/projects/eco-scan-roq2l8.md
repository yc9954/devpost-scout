## Body

Inspiration The inspiration behind Eco-Scan came from the pressing need to improve recycling practices for PPE and minimize contamination in waste streams. Ansell has recently acquired Kimberly-Clark's PPE business and is looking to innovate in recycling practices that their customers use. The following solution presents a multi-pronged approach with varying solutions that should be implemented on the Point of Use and a Manufacturing solution at the end that can also ease this problem. What it does Eco-Scan is a smart recycling bin system designed specifically for PPE disposal. The system is a combination of behavior-based and technology-based solutions. It uses an integrated RFID/barcode scanning system, dynamic QR codes, audio-visual prompts, and color-coded labeling to guide users in correct disposal practices. The system ensures that only verified PPE items are discarded, minimizing contamination and increasing sorting accuracy . Users are also rewarded through gamification, earning points for correct disposal, which can be redeemed for incentives. How we built it Eco-scan is a plan for the implementation of practices and technology, leading to successful contamination-free disposal. Eco-Scan proposes a combination of low-cost hardware and intelligent software: RFID/barcode sensors detect and verify brand-specific PPE items before allowing access to the bin. A dynamic QR code display enables gamified user tracking and rewards. Image recognition software adds a verification layer to differentiate gloves from other PPE items. Audio-visual prompts (e.g., LED indicators, audio messages) reinforce correct behavior, and a color-coded bin system visually separates different PPE types. All components are connected to a central app for tracking and real-time user engagement. Problems we faced Initially, our thought process was to go and have just an image recognition software that can sort the items, but we realized that it is hard to implement that, as many brands have similar-looking PPE thus leading to confusion in the segregation of brands. Along with that Humans are the biggest variable as to ensure compliance you need positive and negative reinforcement which you get by using behavioral practices. Accomplishments that we're proud of We’re proud of creating an intuitive system that blends technology and user-centered design to enhance recycling practices. The successful integration of multiple verification layers—such as RFID, QR codes, and image recognition—ensures high accuracy. Additionally, our gamification approach has shown the potential to increase user engagement and compliance with recycling standards. What we learned There should be behavioral , and technological components as only by combining both can we achieve better reliability. With the Audio-Visual display and the positive reinforcement via the gamification system, the individual will be accustomed to properly recycling plastics according to our preferences. Lastly, we gained insight into using low-cost components creatively to build scalable and effective systems. Ideas for the future Along with these solutions, Ansell can also improve PPE sorting by directly embedding visual and material markers onto Ansell-branded items. This includes: Brand Logos & Color Coding : For easy brand identification in image recognition software, small, unobtrusive logos or color-coded design elements specific to each PPE type (e.g., distinct patterns or colors for Kimtech and KleenGuard). Holographic Tags & Microprinting : Specialized holographic tags or microprinted logos placed on item edges or seams, detectable by scanners and cameras but minimally visible to users. These markers enable reliable, automated recognition by image recognition software, ensuring brand authenticity and enhancing sorting accuracy. What's next for Eco-Scan We can build Eco-Scan to be a proper functioning solution with the help of Ansell by Employee Training : Develop seminars and training materials for the employees. Technology Integration : Developing the app and the other recognition software so the idea can be implemented. Data Analytics : Develop data analytics to track recycling patterns and optimize disposal locations based on user activity.
