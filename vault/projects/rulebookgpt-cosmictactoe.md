## Body

Inspiration Inspired by how frustrating it can be sometimes to learn a new game to play with friends, and how annoying it can be to read through rulebooks! What it does RulebookGPT lets you upload a rulebook of a board game as a PDF and talk to it in natural language! CosmicTacToe is a stylized one-shot tic-tac-toe game! How we built it The entire UI was generated with bolt.new. We did some backend work with Netlify cloud functions for Mistral OCR integration and ElevelLabs chat. Challenges we ran into Some challenges with audio file handling, natural language search. Accomplishments that we're proud of We think we came up with some fun names for our submissions and got some great domains. We think the overall interaction is relatively smooth and were delighted we got the voice reply feature working on short notice. What we learned Learned about some amazing technologies like ElevenLabs Voice, Mistral OCR. What's next for RulebookGPT & CosmicTacToe We're going to polish up RulebookGPT, create a public gallery and allow for community contributions, and possibly try to generate games from the rulebooks directly, allow the responses to embed more visual elements and even more conversational interaction with embodied tutor agents to help visually explain the games. <div
