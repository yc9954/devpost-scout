## Body

Inspiration Providing a Open Learning Platform to NGO's who can use it to teach students of all ages and different specializations. What it does Allows anyone to access an ocean of courses free of cost and registration hassles. Enables kind instructors to add courses and upload valuable content to the website. How we built it We built a Web-Application using: React NodeJS and ExpressJS MongoDB We researched a whole lot of websites and Education Portals to get UI ideas. Challenges we ran into Dynamically updating the Video Cards for displaying the content to users. Positioning the elements and carousel to enhance the appearance of the website. ## Accomplishments that we're proud of #### Successfully created a fully functioning website without any dangling strings! On tangible terms, the code is neatly documented and organised during the development process Used version control to not messup during execution of the application What we learned We learned a lot on how to create a simple yet attractive frontend.
