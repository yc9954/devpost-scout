## Body

Inspiration As Android engineers we are always looking for easy ways of generating API model classes from a given Postman Collection. Now we can!!!!1! What it does It authenticates a postman user in this postman collection and request the users postman collections to use this postman collection to generate Kotlin data classes for that selected postman collection. ;-D TL;DR: Generate Kotlin Classes for Postman Collection. How we built it Ktor Backend on Heroku Kotlin Poet for the class generation. JSON as UI Postman Collection ;) Challenges we ran into Creating UIs for Postman is hard. Postman Collection Api Token was hard(ish) to find. Creating UI with Postman Finding the public workspace link, we sent an invite, hope it works though ... :( Accomplishments that we're proud of IT WORKS™ (kinda, don' make mistakes though) Kotlin Classes generation is possible via Postman Collection Adding Postman Collections is PHUN! What we learned Kotlin Classes generation is possible via Postman Collection Adding Postman Collections is PHUN!
