## Body

I have a dream to create end-to-end interactive learning app including assessment. My dream came true. Just Input the topic you want to learn. It will provide point wise explanation. After learning the topic, ask any questions in an interactive chatbot. And test user skills in interactive chatbot. Just built using prompt engineering and by adding few additional widgets.
