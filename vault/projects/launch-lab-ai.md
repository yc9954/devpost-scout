launch-lab-ai Inspiration The idea for Launch Lab AI was inspired by how students struggle to manage their learning efficiently. Many rely on platforms like YouTube or Google, but these platforms do not provide personalized guidance or structured learning paths. We wanted to create something that acts like a personal AI mentor—a system that not only provides answers but also guides students step by step. The goal was to make learning simpler, smarter, and more engaging. What it does Launch Lab AI is an intelligent learning assistant that helps students: 📚 Generate personalized study plans 🤖 Get instant answers to questions using AI 📝 Take adaptive quizzes based on performance 📊 Track progress and identify weak areas ⏰ Stay consistent with reminders and schedules It acts like a virtual tutor that understands how each student learns. How we built it We built Launch Lab AI using a combination of web technologies and AI logic: Frontend: HTML, CSS, JavaScript for interactive UI Backend: Python (Flask) / Node.js for handling logic Database: Firebase / MongoDB to store user data AI System: Rule-based + API-powered chatbot for answering questions We also used basic algorithms to personalize learning. For example: Difficulty Level= Total Questions Correct Answers ​ ×100 This helps the system adjust quiz difficulty dynamically.
