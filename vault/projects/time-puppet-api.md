## Body

Header Image Inspiration "How to add 2 hours to local time in " I think you have searched the above query at least one time in your life. I have searched it dozens of times. In some languages, it is really easy to manipulate time, but in some languages, it is really hard. That's why I created Time Puppet - The time manipulator API. What it does Time Puppet is a REST API that allows you to manipulate time. It will take the necessary parameters and then output the date and time you need in a matter of just sending an API request. How we built it Time Puppet is created by using Node JS and Express Framework, hosted in Heroku Platform, and Tested using Postman. Challenges we ran into Choosing a language and Framework to write the API was a tough issue Designing APIs using API Design Standards was a bit harder Accomplishments that we're proud of Creating an API that will help most of the developers to use when they need to manipulate time.
