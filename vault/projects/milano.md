Asset Marketplace Listing Home Template Preview LP Template Preview About Template Preview Inspiration The Food & Restaurants category in the HubSpot Asset Marketplace only has two themes listed, so this is a seriously underserved category. Milano seeks to be the top Food & Restaurants theme by providing a vibrant starting point for food-oriented businesses. What it does Milano is theme that can be installed for any HubSpot CMS site. A custom video banner module is included that will allow users to include custom background videos, which will help entice prospective customers. It has generated a Google PageSpeed score of 98 - this theme will help restaurant owners get more visitors by helping boost search result rankings. Key Features Video banner module that can be used for looping background videos 8 custom templates Free-to-use stock photos included Animated text transitions upon scroll Specially designed for cooking class websites, food magazines, recipe guides, and restaurants. How we built it Built upon HubSpot's boilerplate starter theme, Milano incorporates HubSpot's native HubL as well as standard HTML, CSS, and JS. The theme also fully incorporates Drag and Drop Areas, Drag and Drop Area Sections, Branding Settings Inheritance, Module and Theme Style Fields. Challenges we ran into Incorporating the video banner module was tricky at first, and also figuring out how to pass values to variables for use in changing various colors in section modules was a bit bewildering initially, but repeatedly consulting the documentation helped. Accomplishments that we're proud of This is the first theme for HubSpot that I've built from scratch. What we learned I cut my teeth on two other websites for clients in the past that were built on HubSpot, so that allowed me a leg up on the learning process. I thoroughly enjoyed the documentation provided on the HubSpot Developer site that allowed me to get started with my first theme from the ground up. What's next for Milano I'd like to incorporate more templates within the theme as well as a few custom module ideas that have never been utilized in other themes on the marketplace. <div
