## How they structured the write-up

- inspiration: we find it difficult to consistently get memes that are relevant to real-life situations.
- what it does: we input text, and the system finds memes that are closely related to the given text.
- how we built it: using python and its libraries such as torch and transformers.
- challenges we ran into: we faced difficulties in building both the frontend and backend. hosting the python code as a backend was challenging, so we couldn’t complete that task.
- accomplishments that we're proud of: we managed to create a foundational code that retrieves memes based on input text.
- what we learned: we learned how to use python and its various libraries for machine learning and text processing.
- what's next for meme gen ai: we will soon work on integrating the frontend and hosting the python code as a backend.
