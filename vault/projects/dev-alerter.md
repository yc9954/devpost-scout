## Body

Inspiration When I work on new technology, I get hunger of resources. I browse through multiple websites to get resources related to the technologies I'm working on. Most of the contents will be unwanted and I waste lots of time in this. So I created this workspace which collects resources such as jobs, blogs, hackathons, news related to the technology and post it in the slack. What it does Dev alerter is a collection of apis to alert the user about hackathons, jobs, events, conference, blog and developers related news and post those resources to the slack How we built it I used many apis such as dev.to, hacker news, github jobs etc to collect these resources and post these to slack using slack webhookurl Challenges we ran into Chaining all the request and formatting the raw data into the format the slack requires was challenging and needed more scripts to do so Accomplishments that we're proud of This collection might help few developers who're just like me, spending a lot of time to get resources. This small contribution to the developers community is what I'm proud of What we learned I learned almost everything about postman such as monitors, mock servers, workspaces, collections and a lot about webhooks What's next for Dev alerter More advance algorithms and more apis will be used to give best search results for users <div
