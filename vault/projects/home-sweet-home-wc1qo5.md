Inspiration While Renovating rooms , I have always felt the need to curate a design style that reflects myself , Now, getting such a customization within a time frame was difficult . So, at that time I felt the need to automate this process What it does This generative AI app, takes in input from the user as to which specific room they want to customize and then it asks the user about their personality traits and based on those traits it generates recommendation of various designs and styles and an overall home decor along with an Image showing the recommended features. How we built it We have built the app using PartyRock, an Amazon Bedrock Playground. The main thing is that we have incorporated Prompt Engineering to get to see the results as desired Accomplishments that we're proud of We have successfully built a fully functional Generative AI app that responds and creates designs based on the personalities of a person What we learned Generative AI, Prompt Engineering,Designing What's next for HOME SWEET HOME There ' s more to our App , we want to scale this app to a larger market and integrate this app's featues to the home decor induatries' websites to gain more value. <div
