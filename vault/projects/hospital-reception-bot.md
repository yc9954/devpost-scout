## Body

Carousal to show multiple option to user Sentiment Analysis Update Data using API Get API Call Deploy in different channel Inspiration Traveling is my passion as well as the same for a lot of people. I think a chatbot is such an automation to give the user the best experience in planning any travel to any part of the world and having a great time. What it does It books a flight, hotel and suggest a few good tour package to our user. How we built it We designed the chatbot flow first. We used Kore platform for designing our bot. We have integrated our bot with 3rd party databases through rest API call. Challenges we ran into The list is long. Initially we were not able to update our data which was already present there in the database. We were not able to send sms to our user using Twilo. The voice message feature was not working. Accomplishments that we're proud of The persona of our bot is quite interesting. It's full of meaningful images and gif to provide a good user experience. Our bot records all the user input in the backend(In Book Flight Flow) & we can even manage those data(Like- see those data, update or delete later) What we learned API calling integration How to work with webSDK in our local system and make some change locally. How to host our bot in multiple channel. What's next for Travel Planner Bot This bot can be used by any travel domain websites. We are continuously thinking about incorporating new functionality to our bot, like Payment gateway incorporation Live Agent Support etc. Telegram Link of the bot: http://t.me/TripPlanerBot We have uploaded webSDK in github which is as of now only be accessible locally, we had enabled Calendar template there and also incorporate a code which will trigger the bot to autoopen after 5 seconds of reloading the webpage. In telegram channel the bot is not functioning well, as some of the carousal and rich content is not yet supported by all the channel I believe. Initially we decided to make a bot in some other topic, then we chose this topic.
