## Body

Turn Based Snakes and Ladder Start Screen Win Screen Inspiration Snake and Ladders is a game everyone grew up playing. We wanted to reimagine this classic board game as a social, Turn Based experiance that friends can enjoy together using fun Bitmoji. What it does This is a turn-based two-player Snake and Ladders game where players invite a friend and take turns rolling the dice. Bitmoji avatars move across the board, climbing ladders and sliding down snakes, with fun animations and expressive sound effects for every action. I would like to add as every time user starts a new game user get a different snakes and ladders arrangements How we built it The game was built in Snap Lens Studio using turn-based game logic, Bitmoji components, Custom Scripting with tween and behaviour scripts, and interactive UI. Sound effects were carefully added to enhance feedback for dice rolls, movement, wins, and setbacks. Challenges we ran into Handling turn-based flow between two players, managing game states, and ensuring smooth transitions and timing between moves were the main challenges. Balancing visuals and performance was also important. Accomplishments that we're proud of We successfully created a playable multiplayer experience that feels intuitive and engaging, combining Bitmoji, sound, and classic gameplay into a polished AR game. What we learned We learned how to design reliable turn-based multiplayer mechanics, improve game feel through audio feedback, and build social-first AR experiences.
