Login Home Profile - Orders Profile - Favourites Profile - Food preferences Profile - Addresses Profile - My Cookbook Recipes dashboard Recipe review Create recipe Groceries dashboard Cart Order Offers Help Chatbot What inspired us to build Finger Dine: Every one of us have a chef inside who loves cooking new dishes. In the process of cooking, we often end up wasting excess quantities of ingredients bought for the dish. We stock them up hoping to use them again but that rarely happens and the ingredients we stocked up, eventually go to waste. Our approach to solution: To avoid the ingredients wastage, we have developed Finger Dine, an application that delivers ingredients in precise quantities required for a recipe. As we use up all the ingredients delivered, there will be no wastage at all. How we built Finger Dine: Finger Dine is an application built using Pega to deliver meal kits and groceries at your door step. Finger Dine UX is designed with Pega Cosmos. Order management of recipes and groceries/posting new recipes in Finger dine is achieved with Pega's case management, routing and get next capabilities. We've also leveraged Pega's web chatbot feature to implement Finger Dine bot which assists customers with basic information. For easy searching of recipes/groceries even with any typos, we've leveraged Pega's elastic search capabilities. For the payment processing simulation, we've integrated with third party payment gateway which is Razorpay. Challenges we ran into: Integration with third party to achieve payment simulation Achieving cart/wish list functionalities Implementing chatbot Beautifying UI/UX Achieving customer registration with email OTP verification Accomplishments that we're proud of: We've tried to design Finger Dine as close as possible to real time delivery applications in the market in considerably less amount of time. What we learned: We've got to experience what all it takes to build an application from scratch that includes each one of us playing roles of business analyst (to groom and gather all the requirements), design architect (to come up with the design and application architecture), developer (to implement all the requirements) and quality analyst (to certify all the features included) together as a team.
