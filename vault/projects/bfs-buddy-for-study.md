## Body

Inspiration Student life is fast, stressful, and often overwhelming. I wanted to build something simple — a tool that helps students focus, break tasks into smaller steps, manage their time, and take care of their mind. No logins, no data collection, no complexity. Just a calm space to get things done. What it does BFS – Buddy For Study is a lightweight productivity toolkit that runs entirely in the browser. It combines four core tools: 1. Task Splitter Breaks any assignment into small, actionable steps to reduce overload. 2. StudySprint A clean 25-minute focus timer with post-session reflections saved locally. 3. FocusRoom A distraction-free dark theme screen for deep concentration. 4. CarePack Random micro well-being tips to reset between study sessions. Everything runs client-side — fast, private, and anonymous. How I built it HTML, CSS, JavaScript for structure, design, and functionality LocalStorage for saving reflections Modular JS components across /components and /utils SVG logo and minimal dark UI theme GitHub Pages for hosting and deployment No backend, no frameworks — intentionally lightweight for accessibility. AI Tools I used and how ChatGPT (OpenAI) Helped structure the feature flow and UX Assisted with modular JavaScript and debugging Supported designing the UI theme and layout choices Guided repository structure and documentation AI was used only for guidance and reasoning — not as a backend or API. Challenges I ran into Converting multiple ideas into one simple, unified tool Maintaining minimal UI while keeping the app useful Managing JS modules cleanly without a build system Ensuring mobile and desktop responsiveness Deploying smoothly through GitHub Pages Accomplishments I'm proud of Built the entire project solo Designed four working tools inside one interface Clean, distraction-free UI without external libraries Fully deployed and public application Properly structured, readable GitHub project What I learned Practical front-end modular JavaScript Effective use of LocalStorage UI/UX decisions that reduce cognitive load How to turn ideas into working prototypes Clarity > complexity in productivity design What’s next for BFS Optional backend for syncing tasks across devices AI-powered intelligent task planner Customizable themes PWA (installable mobile app) version Expand CarePack with more evidence-based wellness content <div
