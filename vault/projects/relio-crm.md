Kanban tasks Property view Contact view Using REAPI to view property data REAPI Autocomplete plus data Initial map view Filtered search Inspiration Helping real estate agents and brokers close deals. With Relio CRM a broker can spend less time on a database and more time making phone calls with ease knowing all the records he needs are only a few clicks away. What it does This is Relio CRM and it’s a tool based for commercial real estate brokers. I’ve worked with Real Estate quite a bit and noticed a short coming in CRM’s and the way data is handled. Using Excel and multiple applications isn’t a way to hold data. So why not have your data in one place? With Convex, this not only makes the data real time, it makes it easy for brokers to see their agents and colleagues communication and interaction with clients as well so there is no overlap in communication. How I built it NextJS, Shadcn + Tailwindcss, Convex BaaS, Convex Auth, Resend, Mapbox API, Apollo API, RealEstateAPI, Google API, OpenAI and Stripe Challenges we ran into There was a few things that were challenging beside all the APIs used. With Convex, a lot of the challenges I was facing using MongoDB were cured. The included websocket is a life saver. Accomplishments that we're proud of It was a challenge having to complete this in a little over 30 days but it was an awesome time. Being able to pull data from an API and have it create an embedding real time where anyone in my database can use it is amazing. What's next for Relio CRM I think at this point the sky is the limit. I think I'll be focusing on cleaning up the user experience and making sure I'm streamlining processes as well as providing more tools with AI.
