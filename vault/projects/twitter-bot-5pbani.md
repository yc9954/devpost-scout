## Body

Inspiration Nowadays Twitter bots can do interesting things, so I decided to do something with the Twitter API and that's why I made this Twitter Bot. What it does Twitter Bot can Like, Retweet, and reply to tweets. It can also tweet an inspirational quote and a joke. How we built it I built it using postman and javascript. Challenges we ran into I didn't know about the OAuth 1.0 and postman monitors. So, I figured out those things how it works. Accomplishments that we're proud of First time I learned something on the go. Usually, I learn and then make some projects on it. But this time I learned about postman on the go and simultaneously started building a project that's what I'm most proud of. What we learned I learned about postman monitors and how to set up API keys securely in the environment variable.
