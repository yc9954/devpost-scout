Landing page Chat interaction Another chat interaction Showcase of the sidebar Testimonial About the Project What Inspired Us HuzzHub was inspired by the viral pickup line trends and Chill guy memes that flooded our TikTok For You pages. These moments sparked the idea to create an AI assistant with a personality that combines humor and charm. "Chill Guy," our mascot, embodies the essence of these TikTok trends, delivering witty responses and meme-worthy pickup lines to elevate users' social interactions. What We Learned Throughout this project, we gained invaluable insights into: Integrating Google's Gemini API into real-time applications. Designing visually appealing and responsive interfaces using Tailwind CSS and Material-UI. Managing data effectively with Firebase Firestore for real-time capabilities. Overcoming technical challenges like handling animations, audio integration, and seamless user interactions. How We Built It HuzzHub was brought to life through a combination of innovative technologies: Frontend : Developed using Next.js and styled with Tailwind CSS and Material-UI for a modern, responsive interface. Backend : Powered by Firebase Firestore to manage real-time data interactions. AI : Leveraged the conversational capabilities of Gemini LLM . Hosting : Deployed effortlessly on Vercel , ensuring fast and reliable performance. Challenges We Faced Creating HuzzHub wasn’t without its hurdles. Some of the notable challenges included: Fine-tuning the AI model to deliver on-brand and humorous responses. Designing a user interface that was both functional and visually engaging. Handling asynchronous operations like audio playback and API calls without compromising performance. Debugging unexpected runtime errors that arose during development. The Story Behind HuzzHub The journey to building HuzzHub started with seeing viral pickup line videos all over our For You pages on TikTok. This sparked a shared vision to make social interactions less daunting and more fun. From brainstorming quirky features to fine-tuning every detail of the app, the process was a blend of creativity and technical problem-solving. With every obstacle overcome, HuzzHub grew closer to becoming the ultimate meme-powered AI assistant, offering users a chance to unlock their full potential in a hilarious and unique way.
