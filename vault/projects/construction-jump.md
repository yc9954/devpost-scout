## Body

Inspiration Game is inspired by Spy School. What it does Platformer game where the player can play against npcs. Unlock boosts, lives, checkpoints by completing quests. How we built it Built with Worlds Desktop Editor and GenAI. Challenges we ran into Challenges were figuring out how to rotate npcs to move forward, jumping, and spawning. Optimizing the game for mobile. Accomplishments that we're proud of Adding npcs to have a more interactive game for the players What we learned Learned how to optimize the game for a better user experience and how to make npcs move throughout the levels.
