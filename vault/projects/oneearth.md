## Body

Whole collection Inspiration There are different language, different religion, diverse range of culture. A common being can stick to any one of those but a developer must consider all those things and develop the product. After all the product is made for everyone in this world. What it does oneEarth is a collection of apis to get almost all the information a developer needs to build a cross-country application. It gives info on currency, language, trends, festivals etc. How we built it We built this using wide variety of api's to gather every information about a country. Challenges we ran into: Searching for the correct api's and finally chaining all those api's as a separate collections were challenging Accomplishments that we're proud of This collection will help the developers a lot to reach global audiences and provide better services to their customers. Our contributions for the developers community makes us proud What we learned we learned a lot about api's and the authorisation needed to use those api's. Learnt how easy is to work with api using postman What's next for oneEarth More API's will be added to get even more information about a country <div
