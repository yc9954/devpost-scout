## Body

Inspiration Inspired by the need to have one single point of authentication for dApps, Pifpy is a Decentralized Identity Database, your profile in the blockchain What it does It allows you to secure a unique user name and store an avatar as PFP (profile picture) you can also transfer or sell your name/avatar for money How we built it We built Pifpy using NodeJs and plain vanilla HTML, JS and CSS in the browser. For interaction with contracts we used Hedera Hashgraph SDK and for wallet connection we used HashPack and HashConnect tools Challenges we ran into It was extremely frustrating at the start as both Hedera and HashConnect SDKs didn't have a bundled library so trying to build a minified bundle was a total pain, once that hurdle was jumped it was a smooth ride into the sunset. Demos and docs were very helpful for both Hedera and HashConnect Accomplishments that we're proud of Working with contracts in Hedera was very easy and allowing people to have a presence in the blockchain and make money of it was an important achievement What we learned We learned Smart Contracts using Hedera HashGraph SDK, also HashConnect as an important tool for signing contracts in the browser What's next for PIFPY - Profiles on the blockchain After MVP, Pifpy will move to the second phase of creating an active marketplace in order to become sustainable. Charging a small fee for every profile will keep the cash flow and motivation high <div
