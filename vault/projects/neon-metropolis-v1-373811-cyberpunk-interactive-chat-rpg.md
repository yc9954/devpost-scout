## Body

Inspiration ✨ We are huge fans of cyberpunk genre and we wanted to create an immersive and interactive chat RPG that lets players explore a dystopian city full of neon lights, hackers, megacorps and cyborgs. We were inspired by classic games like Blade Runner, Deus Ex and Shadowrun, as well as movies, books and comics in the same genre. What it does ⚙️ Neon Metropolis v1.373811 is a text-based adventure game that uses natural language processing and generative models to create dynamic dialogues and scenarios. The players can choose their own character, background, skills and equipment, and then embark on various missions and quests in the city. The game adapts to the player's choices and actions, creating a unique and personalized experience. How we built it 🛠️ We used partyrock.aws as our cloud platform to host our backend services and our frontend web app. We used (LLM) Large-language model Claude, Claude-Instant, Jurassic-2-Ultra to generate the game content and dialogues, and we fine-tuned it with our own custom dataset of cyberpunk stories and tropes. For the visual and image generation we used Stable diffusion XL as our (LLM). Challenges we ran into 🚀 One of the main challenges we faced was to make the dialogue system coherent, consistent and responsive. We had to balance between using pre-defined scripts and using generative models to create natural and diverse dialogues. We also had to deal with the limitations of the models, such as repetition, contradiction and irrelevance. We solved these problems by using various techniques, such as custom prompts, filters, re-ranking, post-processing and fallback mechanisms. Another challenge we faced was to design a compelling game world and a branching storyline that can accommodate different player choices and actions. We had to create a rich and detailed setting, a variety of characters, quests, items and events that can make the game world feel alive and interactive. We also had to ensure that the game logic is consistent and robust, and that the player feedback is clear and meaningful. Accomplishments that we're proud of 🏆 We are proud of creating a fun and immersive chat RPG that showcases the power of natural language processing and generative models. We are proud of using cutting-edge technologies like(LLM) Large-language model Claude, Claude-Instant, Jurassic-2 Ultra to create realistic and dynamic dialogues with the game characters. We are proud of building a complex and branching game world that can offer different experiences to different players. What we learned 🧠 We learned a lot about natural language processing and generative models, especially how to use them for dialogue generation and text summarization. We learned how to fine-tune, evaluate and deploy these models on partyrock.aws platform. We also learned how to design and develop a chat RPG game, from creating the game world, the story, the characters, the quests, the items, the events, to implementing the game logic, the user interface, the database and the web app. What's next for Neon Metropolis v1.373811 🏗️ We plan to continue developing Neon Metropolis v1.373811 by adding more features, content and polish to the game.
