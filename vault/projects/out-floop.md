## Body

Inspiration The idea was to create a puzzle, the goal of which was immediately obvious. What it does It uses physics to simulate how a ring would behave if inserted into a bended wire. How we built it Unity provided the physics and interaction system while Maya's curve tool was used to create the wire. Challenges we ran into In Unity you cannot just rotate a physical object(wire) and expect the other objects(ring) to automatically calculate the new physics interactions. Accomplishments that we're proud of Creating a camera based rotation system which ensures the ring behaves in a real-world fashion.
