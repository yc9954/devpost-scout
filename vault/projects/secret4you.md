HIPA - Splash screen HIPA - Home NFT listing HIPA - NFT description HIPA - Create a NFT HIPA - Profile, purchases HIPA - Favorites empty state HIPA - Favorite screen HIPA - Profile screen Inspiration After research about NFT market, only in 2021, this market had a growth of ≅ 137%, showing us that has a big opportunity to participate in a possible large market, mainly because has just some apps focused on that with the objective to promote an excellent usability and user experience. What it does HIPA is a marketplace focused on usability and user experience, making easiest and accessible process of NFT sale for everyone. Besides that we support a social cause to include women in programming. How we built it After realize a benchmarking with the biggest players on market, we saw the possibility to create a design totally focused on simplicity and user experience. Our next step was create the SWOT Matrix (strengths, weaknesses, opportunities and threats) of our MVP by making a brainstorming with the group to take ideas and suggestions to the project. We consolidate all ideas and we group all of it by using MOSCOW method (must have, should have, could have, won't have) to define what will have in the MVP development. Within defined features, it was realized the interface prototype using Figma, taking 3 principles of emotional design defined by Donald Norman, such as: Visceral Behavioral Reflective At app development we used: Expo with React Native, a multi platform tool to develop for iOS and Android. NestJS to backend, because is a consolidated framework with pretty good documentation. Celo integrations Challenges we ran into Integration with Celo and Wallet Connect We didn't find a lot of content with all of that integrations, besides some points not clean on documentation: Correct environment to use Celo Development Kit on mobile applications, like web3 and crypto libs; Integration with external wallets; It has to have Valora App installed to Celo integration works; Activity attribution We had to divide what professional will hold a task, with a deadline, being self-managing members Team Organization and Time division We had to conciliate task delivery time with all personal activities. We gather all day after work, with good communication with all members, realizing pair programming, and constant code review. Understand NFT ecosystem, how to create an NFT, about taxes, about seller and buyer vision For half the team, the NFT ecosystem was unknown, so we realized an immersion to understand how works the main activities in this market, for instance: How it was the experience to use applications that already are developed; How to create and sell an NFT; How it is the seller and buyer understanding; What're the necessary integrations to connect a wallet and have your NFT on choose network Accomplishments that we're proud of A fully functional MVP; Create an app faithful to prototype and design experience; Impact society with a relevant social cause; Professional Development; Code that follows good development practices; Methodologies followed, like code reviews and pair programming; What we learned Integrate a project to a crypto wallet; Opportunity to participate in all process in a project, from planning to development; Opportunity to learn about the NFT market, business rules, and benchmarking.
