## Body

Inspiration My cousin and I finally had some free time and wanted to watch a movie. However, it took us 30 minutes to find a movie we wanted to watch, and we ate all our popcorn before the show started. That's why we created FlixFinder to see a movie enjoyable for specific genres or categorical needs without scrolling. What it does FlixFinder is a Chrome extension that asks the user three multiple-choice questions: movie or show, genre, and sub-genres. After viewing what the user inputs, Flixfinder will find the best possible movie or a random choice of potential movies that match the user's criteria. How we built it We built FlixFinder with a combination of HTML and CSS for the frontend visuals and UI of the extension while using JavaScript for the backend code. Challenges we ran into Since Chrome Extensions are new to us, we had a little trouble getting the application running, but after some trial and error, building the extension was a smooth ride. Accomplishments that we're proud of The extension looks very sleek and the UI works exactly as intended. What we learned We aren't super familiar with Chrome extensions, but working on FlixFinder gave us a lot of experience and helped us learn about libraries and JavaScript code we didn't know before.
