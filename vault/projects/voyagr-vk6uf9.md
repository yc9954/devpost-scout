Our main logo Promo Baner A Promo Baner B Inspiration We started this project because we’ve seen how the e-travel industry constantly pushes people into making rushed decisions. Many booking platforms use psychological tricks—like countdown timers, “only one room left” warnings, or sudden price jumps—to create a sense of urgency that pressures users into booking right away. This often leads to frustration, as travelers end up endlessly searching different websites, trying to make sure they’re actually getting the best deal. Instead of making travel planning easier, these tactics turn it into a stressful and time-consuming process. With this project, we want to highlight these issues and explore ways to make online booking more transparent and user-friendly. What it does Our project is an innovative voice-controlled system designed to search for hotels and APIs based on user preferences. Instead of relying on traditional input methods like a keyboard and mouse, it leverages advanced voice interaction to guide users seamlessly through the search process. The system dynamically asks specific questions to gather the necessary details, ensuring a highly personalized and efficient experience. By integrating ElevenLabs Conversational AI, our project delivers natural and responsive voice interactions, making it intuitive even for those unfamiliar with complex search interfaces. Whether users are looking for accommodations or API services, the system streamlines the process through interactive, real-time dialogue, enhancing accessibility and ease of use. How we built it Our project is an innovative voice-controlled system designed to search for hotels and APIs based on user preferences. Instead of relying on traditional input methods like a keyboard and mouse, it leverages advanced voice interaction to guide users seamlessly through the search process. The system dynamically asks specific questions to gather the necessary details, ensuring a highly personalized and efficient experience. We built the system using the following technologies: Main Structure: Utilized ElevenLabs Conversational AI to create natural, responsive voice interactions that guide users intuitively through the process. Backend: Developed using Python for robust, efficient logic and PostgreSQL for reliable data storage and management. Frontend: Built with Lovable, ensuring an easy-to-use interface that is both functional and visually appealing. Hosting: Deployed the entire project on Vercel, ensuring fast, seamless hosting with optimized performance. By combining these technologies, our project delivers a streamlined, voice-driven experience for searching hotels and APIs, enhancing both accessibility and user interaction. Challenges we ran into Our problem was finding an efficient way to pass the information returned by the robot to the database, ensuring that the data was correctly formatted, validated, and securely stored, while also addressing performance and scalability concerns to handle large volumes of information in real-time. Accomplishments that we're proud of We are really proud that we finished the project, especially since we got through some tough spots. On top of that, we picked up some cool new technologies along the way, which was pretty awesome. It’s been a great learning experience, and I’m pumped to see how we can use all this in future projects.
