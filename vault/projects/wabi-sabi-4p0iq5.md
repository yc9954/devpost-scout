Welcome Slide Game Slide Inspiration With the current environment, we wanted to create a web game that can express the current issue. Therefore, we created Wabi Sabi to showcase the current environmental issue, pollution. What it does Users are able to go against each other to defeat an evil sorcerer, Kenji, who releases harmful pollutants when he is alive. Users are able to navigate and swing their swords using the keys. How we built it We built it using HTML, CSS, and Javascript. Challenges we ran into The challenge we ran into was coding the martial warrior to swing his sword and cause damage to the evil sorcerer, Kenji. Accomplishments that we're proud of We're proud of accomplishing this game as it took a very long time to create. What we learned We learned new strategies and were able to understand more about HTML, CSS, and Javascript.
