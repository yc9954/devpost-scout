We aimed to create a dynamic, fast-paced experience that would be fun, competitive, and accessible to a wide range of players. What it does Color Switch is a survival-based multiplayer game where players compete to be the last one standing and win the crown. The core mechanic revolves around a timer that, when it runs out, selects a random color. All tiles that do not match the selected color disappear, so players must quickly move to the correct colored tiles to avoid falling into the void. In addition to this, players have access to two special abilities: Push, which can be used to knock other players, and Boost, which gives them a quick impulse to move across the platform. Additionally, the game offers an experience system that allows you to rank up, from Bronze all the way to Grandmaster. What's new This summer update brings a range of exciting new features and improvements to Color Switch , making the game more dynamic and engaging than ever: 6 brand new game modes: Normal, Speed, Gravity, Obstacle, Miniature, and Chaos, each offering unique gameplay mechanics and challenges. Daily Rewards: Players can now log in daily to claim exclusive rewards and boosts. Community Events: Special in-game events that bring the community together with custom challenges and rewards. Game Mode Voting System: Players can now vote on the next game mode, adding a layer of community-driven choice. 2 new parkour areas (3 total): More skill-based challenges for players to enjoy in the lobby. Photo Zone: A dedicated space where players can take photos and change the background to capture memorable moments. Summer-themed environment redesign: The entire lobby and world have been updated with a fresh summer aesthetic. More Missions: Expanded mission system with new objectives and rewards. New Cosmetics: Additional skins for Push ability variations. TECHNICAL IMPROVEMENTS Tile mobility has been improved for better performance Dynamics have been optimized by 15% UI synchronization issues when joining an ongoing game have been fixed Number of players Minor bugs fixed This update brings not only more content but also deepens the social and competitive aspects of the game. How we built it Color Switch was developed using multiple tools and platforms: Horizon Worlds Desktop Editor for building the world Visual Studio Code (VSCode) for scripting the game logic Blender for creating and implementing 3D models and textures Photoshop for UI design and texture work Challenges we ran into One of the main challenges we faced was synchronizing the UI between players, especially when they joined in the middle of a game. We also had to adapt quickly and efficiently to new feature releases and updates, integrating them smoothly into our existing systems. Accomplishments that we're proud of We're especially proud of: Creating engaging community events Making the game fully cross-platform (Mobile, VR, and Web) Successfully implementing all six game modes Developing a unique photo zone where players can change backgrounds and capture memorable moments What we learned Throughout the development of Color Switch , we learned how to effectively manage cross-platform compatibility, design gameplay that remains fun under multiple modes, and create a social environment within a game through community-driven content and features. We also deepened our knowledge in syncing multiplayer elements and optimizing performance across devices.
