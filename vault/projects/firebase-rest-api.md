## Body

postman collection Inspiration Postman's interactions with API fascinates me and I wanted to create a collection for developers who are looking for a fast way to build applications based on Firebase REST API. Firebase is used by millions of developers around the world to create fast and scalable mobile and web applications. What it does A collection that contains Firebase REST API (Authentication and User management) How I built it I used Firebase REST API documentation to create a collection on my Postman Desktop Application which I then imported to a public workspace. Challenges I ran into I was used to working on the desktop application only, so, I had to learn how to create an online workspace to which I imported my collection. Accomplishments that I'm proud of Creating a Firebase REST API collection for web and mobile developers. What I learned Postman online workspace and how to export and import a collection. What's next Adding other features of firebase REST API such as messaging. <div
