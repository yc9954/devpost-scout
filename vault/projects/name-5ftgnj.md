Pixel art has also seen a recent resurgence in gaming so we decided to combine the two into a fun project that we wouldn't normally have the chance to create otherwise! What it does Project Pæmon allows users to hatch their own "pæmon" using a short questionnaire. These questions help define the Pæmon's name, design, background, personality, stats, and special abilities. Once completed, Project Pæmon uses openAI and stable diffusion to generate a customized pixel art pæmon based on the user's choices. The experience is different for each pæmon you create! How we built it Frontend: Next.js for a seamless, interactive user experience. Backend: OpenAI (GPT-3.5) and Stable Diffusion for AI-powered generation. Styling: TailwindCSS for a retro GameBoy-inspired UI. Music: Beatoven.ai for custom background tracks. Deployment: Hosted on Vercel for reliable performance. Challenges we ran into Remote Collaboration: Coordinating across time zones required thoughtful planning and asynchronous communication. Balancing Nostalgia and Innovation: Ensuring the project felt retro while incorporating modern techniques.
