## Body

Inspiration AIconomics was inspired by a passion for economics and technology. My experience with FBLA, attending the National Conference, and a desire to make economics engaging and accessible for everyone motivated me to create this platform. Leveraging Artificial Intelligence, I aimed to bring interactive and personalized learning experiences to students and professionals alike. What it does AIconomics combines AI-powered tools with structured resources to make learning economics and financial literacy interactive. AI Assistant: Answers questions on economics and finance. Learning Hub: Provides structured lessons on topics like Supply & Demand and Behavioral Economics. Competitions: Connects users to global contests like FBLA and Hultz Prize. How we built it Frontend: Designed with CSS, HTML, and JavaScript for a responsive and intuitive interface. Backend: Integrated the Gemini API to power the AI assistant. Deployment: Vercel for fast global access. Challenges we ran into Using the Gemini API was particularly challenging since it was my first time working on a project that involved Artificial Intelligence. Understanding its functionality, managing API calls, and fine-tuning responses required a lot of trial and error. Accomplishments that we're proud of Building a user-friendly platform that makes complex topics accessible. Successfully integrating AI to create an interactive experience Designing our website to have a modern look What we learned How to effectively integrate AI for personalized learning experiences. User feedback is invaluable for refining and enhancing platform features. What's next for AIconomics Expanding into multilingual support to reach a global audience. Developing a mobile app for enhanced accessibility. Adding advanced features like voice recognition and interactive simulations.
