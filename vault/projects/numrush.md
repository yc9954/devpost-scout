## Body

GIF Avatar selection GIF Game mode selection GIF Gameplay Inspiration Pokemon GO. This game was game changer and I believe keeps very high position in AR games niche. Making players use their phones to move and not just lay on the sofa to play the game is really great and this is something that was inspiring me for long time. What it does NumRush places 8 numbers around the player and one in the center. It has 3 game modes: 1 minute mode : After that you need to find the number from the game filed, then look again on center to see next number, run to it, repeat. Do as much as possible in 1 minute! Math mode : instead of just a number in center, you see equation to solve to find out what is the correct number to run to. No Fails mode : here you need to be fast but still very accurate. If you step on wrong number - you are eliminated! How we built it Sync API helped a lot making this game fun and challenging, because it was cool to play with friends! After coming up with idea, prototype was built to test mechanic, then added Networking layer to play this game with friends. Firstly the idea was to have two game modes: Single player and Multiplayer, but then I removed single player as it was confusing and bad UX. Challenges we ran into The most challenging was to find enough time to make it 😅 Avatar selection and synchronising time for players was tricky, also creating logic to generate random equation taken some time, but at the end it worth it :) Accomplishments that we're proud of Allocating 2-4 hours per day 10+ days in a row! Usually I just spend one night when I start and then try to finish whatever I can in the last 2 days of the Hackathon. Here I planned my work, started much earlier and was progressing day by day. This is the biggest accomplishment for me <3 What we learned Marathon > Sprint. Making step by step every day is much more beneficial and healthier than making leaps every weekend. Sync API is great and definitely my favourite API in Lens Studio right now. Always use version control no matter what! What's next for NumRush More avatars, adding new game modes, global ranking, finding the way to collect players feedback, fixing bugs and a lot a lot more :) <div
