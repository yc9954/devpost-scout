Inspiration What it does A decentralized multi chain IDO platform for the Blockchain. ZSales brings together investors and project creators in the Cryptosphere. Some features we are considering include IDO Launchpad Crypto token minter Built in referral system Token vault Automatic liquidity provider for different DEXes Tiered System for our token holders Support for team vesting How we built it ZSales is currently built to target a few EVM compatible blockchains. Our frontend DAPP has been revamped and is now built in Angular. What we learned We have had to rebuild the whole DAPP in react as it seems there is more support for web3 projects in the react ecosystem than in Angular's.
