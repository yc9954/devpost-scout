About Metro Munch 💡 Inspiration Hey! I'm HardyWest, and I've been building in Horizon Worlds since December 2021. I created Metro Munch because I noticed how many people these days have side gigs like DoorDash or Uber Eats. I thought, "Why not make a game that's not only fun but also teaches people how to hustle smart?" Plus, it's exciting seeing players compete while having fun! 🛠️ How I Built It I built this game using the Horizon Worlds desktop editor and VS Code. My wife and son were my dedicated testers, and I leveraged AI to help with complex coding challenges. The game includes: A system that spits out realistic delivery orders Navigation to help you find your way around A clean UI that works on both mobile and VR Stats tracking so you can see how you're doing Support for Desktop, Mobile, and VR players Sound effects and visuals to make it feel alive 📚 What I Learned This project taught me valuable lessons about: This project taught me a ton! I had to figure out: How to keep track of everything happening in the game Making sure the UI looks good no matter what device you're using Setting up payouts that actually makes sense Making the game fun but not too easy 🎮 Technical Details Core Systems: Order System: Creates deliveries with different difficulty levels Navigation: Helps you find your way around the city Stats: Keeps track of your progress UI: Makes everything easy to understand on any device 🚧 Challenges The biggest headaches were: Making sure the game runs smooth on Desktop, Mobile, and VR Creating navigation that actually helps instead of confusing people Finding the sweet spot between fun and challenging Making everything update smoothly in real-time Balancing the game economy to keep it rewarding 🚀 Future Plans I've got some cool stuff planned: More types of deliveries and missions Better ways to interact with other players More detailed progression In-world purchases to spice things up Special events that keep things fresh This project represents the exciting intersection of real-world experiences and gaming. Taking something familiar like food delivery and transforming it into an engaging game has been incredibly rewarding. I'm thrilled to see players enjoying this unique gaming experience! <div
