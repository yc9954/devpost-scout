## Body

Inspiration Working during Corona and having minimal external contact, I yearned for few lighter moments many times. This hack tries to bring smiles to developers' face. What it does Using postman monitors, we tried to run a series of api calls everyday, which posts a programmer joke everyday to slack. How we built it We used official-joke-api.appspot.com api to get programmer joke for every call. This is routed to slack using slack APIs. We used Postman monitors to run the tests everyday Accomplishments that we're proud of This was a good fun hack, where we learnt how to work with postman collections <div
