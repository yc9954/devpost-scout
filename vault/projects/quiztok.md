## Body

🤔Have you ever wondered what Tiktok Live is for? 🛍️Is it just a place for ecommerce brands to promote their products? ⭐Or just a place for random users to promote themselves? “Well…I don’t really use Tiktok Live that much, to be honest, it’s kinda useless.” - typical Tiktok user. Well, Quiztok is the solution to these questions! Introducing Quiztok - a system that allows users to create custom activities and run them during their TikTok LIVE streams - plus additional features that reward the winners with badges. ✅Quiztok’s main goals: Create an engaging form of ‘two-way’ engagement between streamers and viewers Help influencers build more diverse communities and foster their personal brand Foster longer user retention time on TikTok Live What it does QuizTok allows users to build activities and then run them live with an audience. The host can also create a badge that is awarded to whoever wins the quiz. Currently, it only includes quiz activities, but the system is extensible to other activity types such as Q&A. Tech stack Next.js Tailwind Firebase Cloud Firestore Challenges we ran into running low on time balancing development with other time commitments learning new technologies (particularly on the backend) Accomplishments that we're proud of building a whole (kind of) streaming system and being able to run an activity on it mimicking TikTok UI where we could handling a reasonably complex user flow in a short timeframe What's next for QuizTok QuizTok is extensible to support different question types or even whole new activities. Users could vote on questions they want the streamer to answer in a Q&A, or the creator could take part in audience-generated challenges.
