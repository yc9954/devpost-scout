## Body

Mode selection Inspiration I wanted to create a solution that helps individuals build sustainable habits in their daily lives. Observing how people often overlook energy usage, water conservation, and waste reduction inspired me to develop a platform that calculates personal environmental impact and encourages eco-friendly behavior. What I Learned Through this project, I learned about: Developing interactive web applications using Python and Flask Collecting and processing user input for personalized recommendations Creating AI-based habit suggestions and reminders Data visualization to display environmental impact metrics Designing gamification elements to motivate consistent sustainable habits How I Built It Green Habit Calculator is a web platform where users can: Enter daily activities to track energy, water, and waste consumption Receive a personal sustainability score Get AI-generated recommendations to improve eco-friendly habits Participate in challenges and earn badges to reinforce positive behavior The backend is built with Python and Flask , while the frontend uses HTML, CSS, and JavaScript . SQLite is used for storing user data, and AI models generate personalized tips. Charts and dashboards visualize progress and impact over time. Challenges Faced Calculating accurate sustainability scores from diverse user inputs Integrating AI suggestions meaningfully without overwhelming users Creating an intuitive, engaging interface for all age ni groups This project combines technology, data-driven insights, and behavioral design to help users adopt and maintain sustainable habits effectively. <div
