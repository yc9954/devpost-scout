## Body

Inspiration I was inspired by the old premium mobile game - Kami - an elegant, smart and polished puzzle game. What it does It's a 2d puzzle that challenges you to mix colors and strategize your moves to effectively place correct colored tiles on target slots. How we built it I created a custom C++ game engine that is focused on web builds - having as small build size as possible. Challenges we ran into The engine itself if still very young so there was a lot of engine refactors and new feature implementations - not just the development of this game. Accomplishments that we're proud of This is the first commercial product this game engine has produced and so far, I'm proud that the build size is small and the game itself is stable and performant. What we learned I learned how to work on Devvit projects to communicate with data in Reddit and utilize it for an effective game experience (ie, knowing whether a player has solved the puzzle already).
