## Body

Decentragram Website Metamask connect and sign Inspiration The main inspiration behind building Decentragram using blockchain is decentralization and censorship-resistant . Nowadays, we can see current social media platforms are owned by a single entity, so data manipulation can be possible. What it does Using Decentragram dApp users can share images and also they can earn crypto tokens if another user gives tip to their image as a reward. All the image metadata will be stored on the IPFS - Inter Planetary File System so no centralised server is required. How we built it Decentragram is built using solidity, react, javascript and IPFS . smart contracts are written using solidity, website frontend is built using react and javascript. Images metadata will be stored on IPFS. Challenges we ran into During project development I get some errors in code and solving these errors is really challenging. Also IPFS integration process is very challenging without NFT.Storage. I'm new to react and learning and applying is little intimating. Accomplishments that we're proud of Finally created a working application . Successfully uploaded and retrieved images from IPFS . Successfully added the functionality for giving tips on images .
