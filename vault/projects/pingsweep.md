## Body

GIF GIF Pingsweep is a real-time attention dashboard that pulls together every ping, mention, and tag across Slack, email, Jira, GitHub, and Docs into one view. Built with React and KendoReact, it features a live notification feed with FLIP animations, animated donut/area/bar charts that react as data streams in, an attention load gauge, and a weekly heatmap — all in a dark mission-control UI. It helps you instantly answer: "Where am I needed right now?" <div
