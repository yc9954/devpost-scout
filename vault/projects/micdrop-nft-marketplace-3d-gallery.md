MicDrop NFT marketplace and 3D gallery Inspiration We were inspired by the rising popularity of NFTs and the need for a platform that combines NFT marketplace functionality with an immersive 3D gallery experience. Our goal was to create a space where artists and collectors can showcase and discover NFT artworks in a visually stunning and interactive environment. What it does MicDrop NFT marketplace & 3D Gallery is a platform that revolutionizes the way NFTs are experienced. It allows artists to mint and list their unique digital artworks as NFTs, while collectors can browse, purchase, and showcase these artworks in a captivating 3D gallery setting. The platform provides a seamless and engaging experience for both artists and collectors to connect, explore, and celebrate the world of digital art. How we built it We built MicDrop NFT marketplace & 3D Gallery using a combination of Spheron network, Biconomy, Mantle layer 2, and front-end frameworks like React.js and Next.js . The backend infrastructure was developed using the Spheron network for NFT data storage as well as decentralized hosting of the Spheron network, to ensure efficient handling of NFT transactions and data management. For the front-end, we utilized modern web development frameworks to create a visually stunning and user-friendly interface using React.js & Next.js. The integration of 3D gallery features involved leveraging powerful graphics libraries and rendering engines to provide an immersive and interactive experience. overall, the project was deployed on Mantle Layer 2 testnet and hosted using the Spheron network while taking storage SDK use also of Spheron network. For the User authentication we used Biconomy's Social Login feature for a better login experience for the users. Challenges we ran into we ran into many complications ranging from incompatibility errors to crashing of code files while running npm commands Accomplishments that we're proud of we are proud to use high-speed and easy deployment service and storage for dApps made by Spheron network, as well as using the Social login feature usecase by Biconomy, and deploying on the best L2 Mantle testnet. What we learned we learnt to build like a team in rapid prototyping stages for this project, learnt a lot about the Koii network, Biconomy, Mantle L2, Spheron network offerings and different use-cases. What's next for MicDrop NFT marketplace & 3D Gallery Looking ahead, we have an exciting roadmap for MicDrop. We plan to enhance the platform by incorporating social features, allowing artists and collectors to connect and engage with each other. We aim to expand our partnerships with renowned artists and galleries to bring exclusive collections and exhibitions to our users.
