## Body

Inspiration Wanna learn your frontend development and also keep track of your designs? Do you wanna integrate a design you created before? CodeCloset is for you! This website will help you practice your frontend skills and also save the designs you feel are pretty or you might want to use it in your work later. A Closet of codes built by you for you! What it does🔍❓🆕 It is a MERN stack web-based application that allows users to create html/css codes and save it for further use in their work. Users can login using Google or manually sign up and get started with creating beautiful codes and preview in real-time in preview box and save it with a title. How we built it🏗🔧🔨⚙🧰 Frontend React CSS Backend NodeJS Express.js Database MongoDB Domain codecloset.design Challenges we ran into🧨🏃‍♂️ I was unfamiliar with Auth0 but I tried it anyway and it made the user authentication much easier with very little lines of code. Working on client-side interface was a bit challenging. Accomplishments that we're proud of Completing the project in time!!! Also the features that I wanted to integrate with the pretty UI is something I am proud of. :) What we learned🧠 Learned how to integrate Auth0 and a lot of React.
