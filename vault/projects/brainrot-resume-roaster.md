We wanted to create something lighthearted yet impactful—an app that could roast resumes with brutal honesty while delivering hilarious feedback. The goal was to combine the chaos of meme culture with a useful tool for self-improvement. What it does Resume Roaster takes your resume (in PDF format), runs it through AI, and delivers scathing, sarcastic, and darkly humorous critiques. It's like having your resume reviewed by a stand-up comedian with zero filters. From calling out generic buzzwords to hilariously mocking weak descriptions, it’s a mix of brutal honesty and laugh-out-loud feedback. How we built it Frontend : Built with React.js and styled with TailwindCSS for a vibrant and chaotic Gen Z vibe. Backend : Powered by Node.js and Express, with Multer handling file uploads. AI Integration : Google Gemini API generates the witty and savage roasts dynamically. Deployment : The frontend is deployed on Vercel, and the backend runs on Render. Challenges we ran into CORS Issues : Handling secure communication between the frontend and backend required some tweaks. Prompt Tuning : Crafting the perfect balance of humor and constructive feedback in AI responses was tricky. Accomplishments that we're proud of Successfully integrating AI to generate dynamic, witty responses. Creating a visually appealing and fun Gen Z-themed user interface. Delivering a project that matches the chaotic energy of the Brainrot Hackathon while being functional and entertaining. What we learned How to effectively integrate file uploads and AI-driven responses. The value of balancing humor and functionality in a creative application. What's next for Brainrot Resume Roaster Add More AI Models : Support for multiple roasting styles (e.g., professional, Gen Z, meme-based). Customization : Let users choose the level of roast intensity. Enhance Feedback : Include actionable tips alongside the savage critiques.
