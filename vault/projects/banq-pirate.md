## Body

Transfer Money Dashboard Login Page Inspiration We saw the Desjardin challenge as an interesting issue to tackle. The idea of making a banking system that becomes interactive and alive made us choose this challenge for our first ever hackathon. What it does Banq Pirate is a mobile banking system where it adapts to the environment! From going rogue during the night, to jungle mode when you're moving through thick leaves, Banq Pirate makes exchange easier, not only for Indiana Jones, but also people with sight troubles. How we built it We created an Android app with Android Studio. Made in Java and XML. Used Android camera sensors, Google Hand Gesture Recognition, and ElevenLabs AI Voice. Challenges we ran into It was hard to put the standalone technologies into a cohesive app. Implementing different APIs and communicating between different softwares required heavy documentation et patience. Accomplishments that we're proud of It was able to run without crashing!!! We have our desired features. What we learned How to call API in different ways. Inheritance classes.
