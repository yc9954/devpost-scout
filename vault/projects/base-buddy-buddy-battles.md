ETN Buddy Buddy Platinum Pass NFT Inspiration I found a lot of inspiration from ETN chain and Electroswap, making honest and working utility is my main goal and what drives me, and also got a lot of inspiration from my partners and the community here. What it does Buddy is only the mascot of a community with different tools and possibilities for our holders and the whole ETN network. Giving utility and fun to the whole ecosystem is our main goal, always being accessible and having a smooth experience. Our website has a really easy to use image creation tool with Buddy and Electroneum stock images, designed for being easy to use and allowing people create images or memes from any device. Buddy Battles is a platform where people can have fun using their tokens to try and earn more. A new system of gameplay available to any token using it, right now only the first mode Simple Battles is available but we are working on the graphics for a code-finished platforms game with a timer where anyone can try to join the ranking in order to get the best rewards. The battles also benefit the token team, Buddy team and a burn system that makes any token using them deflationary, and benefiting all the community. Staking system where we are distributing part of all the project earnings (token taxes, nft collection earnings) to be distributed among the holders (with bonuses for the Buddy Platinum Pass Holders!!). Utility NFT collection Buddy Platinum Pass !! with exclusive benefits and more rewards for all the owners. other utility for all ETN projects We want to contribute to the ecosystem and help other teams, so we are also working in our airdrop tool where you can easily distribute tokens to a lot of different wallets just by creating a CSV with 1 wallet per line, saving tons of fees by bundling transactions. Also working on making the reflections system available for any other token that wants to implement it too, as well as a direct reflections system without staking. How we built it Solidity contracts, React for the frontend, Unity for the game, decentralized and public usage (that's why we love blockchain), and a lot of time and love! Challenges we ran into A lot of technical errors while building the platform and fine tuning it, also big economical challenges for paying designers, marketing... Running out of money is never easy. Just keep going step by step and working hard for it. Accomplishments that we're proud of Having the first meme with a running dapp in Electroneum, few months ago. Keep going each day, developing, crafting strong relationships and partnerships. What we learned Being honest is the most important thing. When something doesn't go as expected just try again and again until it goes better, learn from errors , change for avoiding them next times and keep going no matter what. Making relationships and being kind and helpful will get back at some point. What's next for ETN Buddy Open staking and reflections systems for other tokens creating their own rewards systems. Unity platforms game with 13 levels, an onchain built ranking and automatic rewards distribution, (designs left) Always keep going on! Our future goals are a lot, we want to keep developing even being difficult and so time and money consuming. We could see a Buddy mobile app bringing people to Electroneum, we want utility, we want fun, we want all the ecosystem upgrading together!! <div
