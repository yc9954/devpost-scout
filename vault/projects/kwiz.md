Random set of questions Modified multiple API parameters Inspiration Are you a tech Wiz? Is your tech knowledge hot or not? Be on top of your tech game, see how much you really know about it! We’ve probably all got books on our shelves or our to-do lists that we’d love to brush up on ‘if we got the chance’. So many of us barely scratch the surface when it comes to the full capability of the tech we use. It’s time to explore this a little further. There are a number of ways out there to brush up and stay sharp on tech concepts and coding practices. We wanted to create a collaborative environment along with some fun and rewards. Determine whether you or your team members have increased overall technical proficiency as part of routine evaluation while having fun. Find out and test your knowledge of the things you use. What it does Kwiz (Postman Collection) lets you test your knowledge wide variety of technical topics. Create your own or get a random set of questions for a specific topic. You can also choose the difficulty level. Build custom quizzes to challenge your team. Learn while having fun. Create quizzes with any combination of choices: Category Difficulty Number of questions Tags (matching multiple category) How we built it QuizAPI.io, Javascript, HTML, Bootstrap, CSS, Postman Challenges we ran into Parsing the JSON and displaying it in proper format was a bit challenging and later using handlebars methods to visualise this was a bit tricky. Accomplishments that we're proud of Using Postman Visualizer What we learned Test scripts, Visualizer, Using built-in authorization helpers. What's next for Kwiz Make it open for contributions to more topics. Build a PWA where the quizzes can be scheduled based on the required topics. How to Use 1.Make a Fork of this Workspace. 2.Request an API Key in QuizApi.io 3.Create an environment with API_KEY variable. 4.Send a request. 5.Modify parameters of API as needed. For example: For specific topic like "category"=Docker; level of difficulty etc. Buckle up! <div
