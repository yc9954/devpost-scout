## Body

Inspiration I was wondering how much weight my vehicle could tow and I search the web high and low and could not find any solid answers. After more searching I was able to find some API endpoints that could grab this info via the vin. What it does Uses a variety of endpoints to get all the data you would ever need for a vehicle. How we built it Searching the web for open API endpoints and centralizing for other devs to use! Challenges we ran into Finding open API endpoints that were useful. Accomplishments that we're proud of Leveraging these endpoints to build something easy for user to find data on their vehicle.
