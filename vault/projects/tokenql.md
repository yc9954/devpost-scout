Title Data Description Inspiration How Do I Get All the Tokens? What it does TokenQL is a cross chain indexer that acts as a data layer for all ERC-20, ERC-721 and ERC-1155 tokens, using standard web2 tools such as graphql and RESTful APIs. This will provide a base layer data source for all defi, gamefi, dashboards, wallets etc. How we built it TokenQL goes through every transaction in the blockchain and indexes all token standards. More info here https://medium.com/coinmonks/how-do-i-get-all-the-tokens-21ff1607d189 Why it's being built https://t.me/Evmoshackathon/618 Challenges we ran into Collecting this type of data takes weeks/months to complete. The challenge is to have enough time to collect all data before the end of the hackathon. Accomplishments that we're proud of We already have users in the hackathon using this data source for their project. This was done organically in the telegram chat. What we learned There is no token indexer for EVMOS. This is possibly because the chain is new. This data layer will open doors for many dapps to build on.
