## Body

Inspiration Complex crypto whitepapers overwhelm investors. FinSight uses ERNIE 4.5 AI to instantly decode technical details, risks, and tokenomics into beautiful, actionable insights. What it does Upload any crypto whitepaper → Get instant AI analysis with executive summary, technical deep dive, risk matrix, tokenomics breakdown, competitor comparison, and interactive visualizations. How we built it Backend : Python FastAPI + Novita AI API (ERNIE 4.5 VL Thinking model) Frontend : React TypeScript Vite with zed.dev-inspired animations AI Pipeline : PDF extraction → Custom ERNIE prompts → Structured JSON → Dynamic visualizations Challenges we ran into Optimizing ERNIE prompts for comprehensive crypto analysis Handling large PDF files with multimodal AI limits Creating smooth fluid animations while maintaining performance Accomplishments that we're proud of Real-time multi-stage processing animations (PDF→ERNIE→Risk→Tokenomics) Advanced risk matrix and competitive positioning visualizations Modern fintech UI with glassmorphism, mesh gradients, and spotlight effects What we learned ERNIE 4.5 excels at structured financial analysis with proper prompt engineering.
