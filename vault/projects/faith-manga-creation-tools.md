## Body

Inspiration As a webcomic/manga creator, I wanted to explore what AI could do as things like script writing and panel layouts/storyboarding can be tedious for some and take a sizable amount of time. I've tried to include real considerations in my experience of webcomic, manga and film creation to establish effective shots, camera angles and composition to tell your story. What it does There are a suite of tools which can be used whether you have a basic idea or you want an idea generated for a challenge or you need some inspiration. Story Generator - This takes an idea and generates a plot around it Title Generator - Using the plot created, it generates Title ideas for the story to intrigue readers Blurb Generator - A short description of the story to try and draw in readers and a requirement for publishing work online. Script Generator - Breaks down the plot into script format and allows users to edit as they wish Panel Breakdown - Creates a description of how the panels will look on the page and what is in each panel. Panel Description - This lets users query from the panel breakdown and Faith describes what the shot looks like, where characters are and what they are doing to help users layout panels with balance and impact. Character Generator - Asks users questions and then generates a profile and image for them gain inspiration. How we built it Using partyrock to generate windows in 2 columns, the left side column for a users' own idea and a right side column for if the user wants to generate an idea. This allows a tutored workflow depending on what the user wants. Each feature can be used independently after a plot has been generated to not overload the application and allow flexibility. Challenges we ran into With lots of widgets, the app was really slow so I added user input points for each feature to only trigger on user input which allowed a more step by step approach and made user interaction better. Accomplishments that we're proud of AI apps are new for me so I'm proud of the results I have and how many features I could squeeze in using partyrock What we learned Using exact language is key to have Claude function as I wanted. Lots of amendments were needed! What's next for Faith - Manga Creation Tools I'd like to use it in my own work and share it to the creative community. I think it could help a lot of creators who are new to comics/manga creation cut through the tedious work and get to artwork which is what most people enjoy the most. <div
