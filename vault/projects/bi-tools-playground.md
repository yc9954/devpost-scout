## Body

Inspiration A possibility to easily test interconnectivity and interactivity between APIs of more than one BI tools inspired me to create this dedicated Postman Workspace. What it does The primary objective of the workspace is: To create a collection of APIs for each of the BI tool present in the market, thereby making it a one stop reference. Test, connect and create workflows of APIs utilizing more than one BI tool. How we built it Postman API BI Tools (viz. Zoho Analytics, Dataiku DSS and ClicData) API reference doc of respective tool. Challenges we ran into I found it initially tough to understand authentication process for each of the tool and applying it in Postman. Accomplishments that we're proud of An overall journey from 'Zero' knowledge about API to a realization of the power of API. What we learned APIs What's next for BI Tools Playground Inclusion more and more BI tools collection.
