problem solution welcome THANK YOU SO MUCH FOR THE OPPORTUNITY ARCZ RoadMapR We’re teens (13–18) fed up with every hackathon platform treating us like we don’t belong. No global team-ups, no way to flex our wins, no AI that actually helps finish projects. So we built the one we always needed. What it does? RoadMapR is the ONLY hackathon platform made 100% for teens aged 13–18. Instant global team finder + live chat Smart matching by skills + timezone Dope profile with trophies 🏆, win streak, skill graph AI Roadmap Maker: drop your squad size & skills → auto splits tasks, deadlines, milestones Host school or global hackathons in minutes Strictly no adults. Teen energy only. We built the whole thing in pure prototype mode — no real database, no backend headaches, just raw speed and vibes 🔥 Claude Sonnet 4.5 wrote 40% of the code. We fed it ideas, copy-pasted, fixed bugs with AI again, and shipped it in days. * Real (and only) tech we used: * Frontend: HTML + React.js + JSX + JavaScript + Tailwind CSS + Shadcn/ui Backend: None (everything runs in the browser) Global chat (prototype): Pure in-memory + localStorage (data resets on refresh — it’s just for demo!) AI Roadmap Maker: Direct calls to Claude Sonnet 4.5 API (live in browser) Auth & fake user data: All localStorage + dummy JSON Deployment: Netlify + GitHub (push to main → instantly live) Challenges we ran intoLag-free global real-time chat Making the AI roadmap actually useful (not just fluff) Keeping the platform 100% safe & moderated Building a full-stack app while surviving school ** Accomplishments that we're proud of ** First-ever platform exclusively for 13–18-year-old hackers AI Roadmap Maker helps teams finish 3× faster Established a good base for our team What we learned When you build for your own pain, you ship crazy fast Real-time apps are hard but worth it Teens will grind harder than anyone if you give them the right stage What's next for RoadmapR Global leaderboards & badges School scout zone (top unis can discover winners) Mobile app drop School partnerships worldwide Become the default resume for every teen builder before they hit 20 🚀 Built by teens.
