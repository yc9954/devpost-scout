HomePage Predefined Prompts Tone Selection Image Upload Analysis MyDog8it 🐶📝 - Your AI Excuse Generator 💡 Inspiration Who hasn't needed a quick excuse when things don't go as planned? 🤷‍♀️ From missed deadlines to last-minute cancellations, "MyDog8it" offers a playful nod to the classic "dog ate my homework" excuse, revamping it for the modern age with AI. 🚀 We, students from random majors, having been to 0 to 1 hackathons only, are bringing a bit of fun to the mundane with excuses for every occasion! 😂 🎯 What it does MyDog8it uses AI to generate tailor-made excuses on demand. 🤖 Users can specify the tone—serious 😐, humorous 🤪, or desperate 😱—and the context like work 💼, school 🏫, or personal engagements 🎉. Our AI then crafts a believable (or outrageously funny) excuse that users can deploy wherever necessary! 🎲 🛠️ How we built it 💻 Frontend : Built using React , Next.js , and Tailwind CSS for a responsive, visually appealing UI. 🔍 TypeScript : Ensured type safety and improved code reliability. 🌈 Animation : Enhanced interactivity with Framer Motion for smooth animations. 🤖 API : Used Groq's API and Pear AI for efficient excuse generation. 🎨 Icons : Integrated Lucide React for scalable and customizable icons. 🔤 OCR : Leveraged Tesseract.js for optical character recognition, adding advanced functionality. ☁️ Hosting : Deployed on Netlify for fast, seamless updates and scalability. 🏋️ Challenges we ran into Striking the right balance between believability and humor in our excuses was challenging. 🎭 We iterated through various models and fine-tuned our AI to ensure that it doesn't just generate excuses but does so in a way that can actually be used (or just for a good laugh). 🤹‍♀️ 📣 Tracks Aiming For ⭐️ PearAI (YC24) prize ⭐️ best overall yay :3 ⭐️ most likely meme startup ⭐️ (WBUOT) would blow up on tiktok ⭐️ (LAKOG) lowkey actually kind of good ⭐️ codedex i wanna learn stuff prize ⭐️ most cvrvey website ⭐️ best "come with me to my hackathon" vlog ⭐️ Bill Zhang's x Retell Best Conversational AI Prize ⭐️ (IJAG) I’m Just A Girl ⭐️ i laughed.
