## Body

Inspiration We wanted to build an app that relates to a wide audience. We all love food. That's when the idea for the Delicious Food Recipe Generator was born. What it does The user can provide a few basic ingredients (e.g. cheese, garlic) and dietary requirements (e.g. gluten-free) and the app will generate a delicious recipe with an image of the dish. The user can also ask questions related to the dish. How we built it We used multiple widgets in the PartyRock. The LLM generates a recipe based on user inputs. An image-generation model creates a compelling picture based on the recipe. The chatbot widget allows the user to ask questions about the dish. Challenges we ran into The units in the recipe were inconsistent. We had to force them to be expressed in grams. The temperature had to be enforced to degrees Celcius. Accomplishments that we're proud of I get hungry when I use the app! 😋 What we learned How to use the PartyRock platform for basic demos of generative AI applications.
