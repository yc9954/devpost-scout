## Body

Inspiration Trade multiple assets and not worry about blockchains, different protocols and with the help of AI so it just finds the best route to complete my intent. What it does It is able to place trade positions on Gains.Trade protocol a decentralised platform to trade forex, crypto, etc. How we built it Building the smart contract function call to interact with Gains.Trade protocol and letting AI decide when to call them. Challenges we ran into Using Bitte.ai's unique transaction signing mechanism to create function calls. Usually libraries take care of this but I had to separate this feature which meant to manually building smart contract functions. Accomplishments that we're proud of 1st Ai Agent to be able to trade forex pairs.
