## Body

Meme Generator We all want to share memes across social media. Instead of searching for them all over the internet how about generating our own memes😜. This collection contains API's from ImgFlip which can be used to generate our own memes. Inorder to generate your own memes you need to create an account at ImgFlip to access their endpoints as we need to include the username and password for every request. This collection contains two REST API's which we can use to make memes from a wide variety of images.
