## Body

Image of running program Inspiration While researching issues for our project, we became aware of the growing global food crisis as a result of climate change and conflicts. We decided to build a easy to view website to better display this issue, as the visuals help represent areas disproportionately affected by this crisis to better inform others of this issue. What it does Our website displays a Choropleth map with color-coded countries from green to red showing the intensity of hunger according to the global food index. All countries with color are clickable and redirect to websites with more information about the food crisis in the location with the option to donate. How we built it We used JavaScript and HTML to create a color-coded map with plot.ly and pop-ups with links. The website is hosted on codepen.io, Challenges we ran into We pretty much had to learn how to use plot.ly as we were coding our website as we both lacked the Javascript knowledge to do most of what we wanted. We also ran into a challenge while looking for donation websites, and had to enter the 100+ URLs by hand, though we managed to finish the website at the end. Accomplishments that we're proud of We're pretty proud of finishing our project since this is our first hackathon. We aren't the most experienced with coding, especially under strict time limits, so we are quite proud of the project we managed to create. What we learned We learned that it is better to prepare further in advance for hackathons and know what format you want to create your project in before starting. We also gained deeper knowledge of Javascript and how to work collaboratively as a team. What's next for Help Hunger Map If given more time, we would like to make the website look prettier and have more information about world hunger. We would also like to add more information on what caused the hunger in each location, as well as more donation sites for each location. Lastly, we would probably move our website from codepen to a more well known hosing service, such as squarespace or wordpress. If possible, we would also like to include automatic updates on the hunger crisis. <div
