## Body

Example dialog Inspiration 💭 Parenthood circulates about the little new life - with all right, but does it have to imply that all your talk is now about when did she eat? How much has he slept today? Wouldn't it be a great release to quickly log such daily activities - and see patterns on what works best? And, the main motivation, every parent should have access to guidance to increase the chance of good health for parent and child. 🌿 What it does ✅ The virtual assistant has 5 main tasks at the moment: Is this normal? - Ask about the baby's condition and quickly get an answer about whether this seems normal or not. How to FAQ - Browse tips and tricks about basic baby care, how to feed, get to sleep, how to calm down, and more. Give me motivation, please! - This is where to go when alone and in need of motivation, Junior will present silly baby memes and motivational parent quotes and texts. Report food/sleep - Enter food and sleep activities throughout the day in simple forms. Report graphs - Show summaries of the logged food and sleep. How we built it 🛠️ Dialog Tasks. Data tables, Data views. Digital forms. Web widgets with custom Javascript code. Knowledge base. Intent training. Is this normal? - Knowledge base , questions starting like is it normal . How do I..? - Presents common questions in widgets , Knowledge base , questions starting like how to . Give me motivation, please! - widget with carousel, alternated with text messages stored in a Data Table. Report food/sleep - Digital form , Bot Actions with Services of type Data. Data is saved to Data Tables and read from Data Views. Report graphs - Reading data with Services and display with widget in dialog messages. Challenges we ran into ⛓️ Figuring out where the problem was if the bot suddenly couldn't handle the messages. Accomplishments that we're proud of 🙋‍♀️ Combining intent, digital forms, data, and UI widgets to create functions that can have real value. What we learned 🔬 I learned how to work with the Kore.ai platform and its capabilities. Now I have a better understanding of how to combine different features to create a dialog flow. What's next for Virtual Junior - the Parenthood chatbot ⏭️ Add Entity logic around which baby it is, and which parent you are. Extend with more channels to interact with the Junior, e.g. a convenient way to share some logging capabilities with your family/babysitter. Translation capabilities Add questions that couldn't be answered to a data table that a professional admin can go through and add to the knowledge base with answers. With this process, the user can receive an answer a bit later. Let a friend or family member provide with motivational text that will populate when the parent needs motivation.
