query_engine documentation dashboard Inspiration The limitations of centralized databases—high vulnerability to attacks, lack of transparency, and single points of failure—drove us to create btSQL, combining BTFS security with the familiarity of SQL. What it does btSQL integrates traditional SQL databases with decentralized storage via BTFS, offering a scalable, secure, and auditable database management system while maintaining a user-friendly SQL interface. How we built it We developed a frontend dashboard for database management, integrated BTFS for decentralized storage, and built a backend API for database operations. The system allows SQL queries, API access, and secure interactions via the BitTorrent network. Challenges we ran into The biggest challenges included ensuring seamless SQL interaction with decentralized storage and optimizing query performance over distributed networks while maintaining security and scalability. Accomplishments that we're proud of We successfully integrated BTFS with SQL, providing a cost-effective, transparent, and decentralized storage solution. Completing the basic query engine and frontend dashboard is another key accomplishment. What's next for btSQL We plan to integrate a query optimization engine, conduct comprehensive testing, and focus on scalability to enable more robust production-level integrations and collaborations with the Web3 community. <div
