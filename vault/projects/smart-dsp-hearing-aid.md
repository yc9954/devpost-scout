## Body

block diagram from altair embed audio output with filtering and techniques Inspiration Hearing loss affects millions worldwide, including newborns and the elderly, often limiting communication and quality of life. We aimed to create an affordable, efficient, and accessible solution using modern digital signal processing. What it does The Smart DSP Hearing Aid enhances speech clarity while reducing background noise in real time. It uses customizable audio profiles to adapt to individual hearing needs, ensuring clear, comfortable listening. How we built it We used Altair Embed to design the real-time DSP algorithms and Altair Composer for visualization and simulation. MATLAB was employed for initial audio signal analysis, filter design, and performance testing before embedding into the model. Challenges we ran into Achieving low-latency processing for real-time hearing aid use. Balancing noise reduction with natural sound quality. Designing filters adaptable to various environments. Visualizing real-time audio processing results effectively. Accomplishments that we're proud of Successfully simulated real-time noise filtering using Altair tools. Created an adaptable system for multiple hearing profiles. Developed a low-power, cost-effective model suitable for practical use. What we learned Practical application of DSP in healthcare devices. Integrating simulation tools like Altair Embed & Composer for hardware-ready designs. The importance of balancing algorithm efficiency and user comfort. What's next for Smart DSP Hearing Aid Miniaturizing the design for wearable use. Adding Bluetooth connectivity for smartphone control. Expanding to AI-driven automatic sound environment adaptation. Conducting real-world testing with target users. <div
