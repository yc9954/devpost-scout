## Body

JurisGuide – Project Story and Kiro Usage Project Story: JurisGuide is an AI-powered platform designed to simplify legal guidance and mediation for users worldwide. Our goal was to create a seamless experience where users can understand legal procedures, sign up, log in, and interact with an AI mediator to resolve disputes. The project focuses on building a user-friendly front end, smooth authentication flow, and AI-backed mediation logic that can guide users through legal scenarios efficiently. How Kiro was Used: We relied entirely on Kiro, an AI IDE, to bring our project to life. We started by giving Kiro the complete idea of our project. Kiro then automatically divided the project into smaller tasks and generated code for each step in a structured, modular way. Some highlights of Kiro’s contributions: Landing Page and Authentication: Kiro created a streamlined landing page along with sign-up and login pages. It initially linked the front end to Supabase for backend functionality, which we later removed due to some errors, but the front-end flow remained fully functional. Spec-to-Code: By providing high-level specifications for each module, Kiro translated our ideas into working code, handling both front-end layouts and the AI mediation logic. Automation with Hooks: Kiro’s built-in automation (hooks) handled repetitive tasks like generating templates, scaffolding pages, and linking components, which significantly sped up development and reduced manual errors. Using Kiro allowed us to focus on refining the project concept and user experience, while it handled the detailed coding work.
