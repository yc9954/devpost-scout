## Body

Inspiration The inspiration for creating the project is to facilitate the access of people who do not have the knowledge in cryptocurrencies, to have access to this market, in a safe and reliable way. What it does Through the PIX payment method, which was created by the central bank, being the best means of value transfer in Brazil, working 24/7, we were able to make our platform do an automatic cryptocurrency purchase as soon as it receives a PIX transfer from a customer, making it easy for anyone to access the cryptocurrency market. It is worth saying, PIX is a payment method used by 100 million people and 7 million companies in Brazil. How we built it We create the application in two parts, the backend is an API built with Javascript, and the frontend is an application built with Flutter, and the communication happens with HTTP calls. Challenges we ran into We had several challenges, among them choosing which database to use (postgres or mysql) and how to organize the routes for the frontend to communicate with the API. Accomplishments that we're proud of Our application works, the frontend has a beautiful design, and, the backend has registration, login, purchase and balance management of the cryptocurrencies. What we learned We learned more about MongoDB, express, postman and JWT, flutter and dio. We exchanged many ideas and knowledge with each other.
