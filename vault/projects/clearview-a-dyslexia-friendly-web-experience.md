AI Chatbot Add Tasks Reader Page 2 Calendar Reader Page 3 Reader Page ClearView Project Story Overall information of the project ClearView is a web application that pioneers in giving an advanced reading and learning environment for those in this world who are suffering from dyslexia and hence struggle during reading. Tied up with sophisticated access and ease of use, ClearView application that will permit or enable users to have their perfect reading scenario set up. ClearView arose from passion and desire to make reading accessible and enjoyable to all, though especially for dyslexic people. Realizing how conventional text formats may sometimes create obstacles, we set out to develop a tool that did more than break through these-which may trigger a love for learning. What We Learned Special needs: during this development came to learn about general reading difficulties: Accessibility is Key : Font type, size, spacing-it's the little things that matter. Design Thinking- User-Centered Design : It is through users that contributions about design features make all the difference. Integration of Technology : APIs provided from Google and OpenAI increase ClearView's functionality, hence allowing personalization in certain respects. How We Built the Project We developed ClearView with some of the latest technologies in web development: Front-end : HTML5, CSS3 and JavaScript for responsive and intuitive UI. API's : Integrating Google and OpenAI APIs for text to speech amongst other content personalisation features. Principles of Design : Simple, easy to use, so the user would easily navigate and personalise it. Challenges Faced There were quite a few challenges while developing ClearView: Feature Full vs. Simple : It needed to be feature-rich but simple, which took quite a while in planning and user testing. API Integrations : API integrations were not free from their own set of compatibility and data handling issues. Accessibility Compliance : Tests for and changes in accessibility to cater to all kinds of users. Conclusion ClearView is our hope to tear down the fences of Dyslexia in education and reading, a commitment to letting the users take their learning journey into their ownership by offering each user, according to their needs, the best reading experience possible, particularly for those who might be disadvantaged. <div
