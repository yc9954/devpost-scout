## Body

front page Inspiration Cricket is a game of numbers, stories, and debates. We wanted to create a platform where fans and analysts could dive deep into player stats, compare legends, and build their dream teams with real data. What it does Spodex lets users compare cricket players, build custom dream teams, view leaderboards, and explore detailed player profiles. It visualizes stats from multiple formats (ODI, T20I) and makes cricket analytics interactive and accessible. How we built it We used Python for backend data processing and React (with Vite) for the frontend. Player and match data is stored in CSV files, processed by custom scripts, and served via API endpoints to the frontend for visualization. Challenges we ran into Cleaning and unifying data from different sources and formats. Designing intuitive UI for complex stats. Ensuring fast performance with large datasets. Integrating backend and frontend smoothly. Accomplishments that we're proud of Built a full-stack analytics platform from scratch. Created interactive tools for player comparison and team building. Developed a clean, modern UI for cricket fans. What we learned The importance of data validation and cleaning. How to design user-friendly interfaces for data-heavy applications. Best practices for API design and frontend-backend integration. What's next for Spodex Add more advanced analytics and visualizations. Expand to include Test match data and historical records.
