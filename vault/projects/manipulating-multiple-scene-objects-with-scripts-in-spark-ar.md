## Body

Inspiration For this project, I was inspired by the community. I learned a lot on the Spark AR Community Facebook group and I wanted to share some of what I have learned What it does This tutorial shows how to create and manipulate multiple scene objects by taking advantage of the power of scripts in Spark AR Studio. I used code snippets to show how different parts of the code work and interact with each other and shared the final result at the end. This tutorial shows how to use Dynamic Instances which is a brand new feature released on version 102 of Spark AR Studio, which gives creators more creative freedom How I built it I build the project using Spark AR Studio and Visual Studio Code as my code editor, the process of building the effect is thoroughly explained in the tutorial itself. To create the tutorial, I used Visual Studio Code, which allowed me to see the markdown as I wrote Challenges I ran into Trying to convey with words what was happening in the project was difficult, luckily markdown supports images as well as gifs which I could use to give the reader some context. Accomplishments that I'm proud of I am happy with the way the content turned out and I hope many in the community will have their first shot at using scripts with this tutorial. Scripts are a powerful tool and anyone should be able to learn how to use them. What I learned. I learned a lot about how to create educational material as this was my first ever tutorial, I look forward to creating many more in the future. What's next for Creating and Manipulating Objects with Scripts in Spark AR The tutorial will be expanded as the community shares feedback or asks for more in-depth explanations of some concepts. This will probably the first in a series of tutorials for Spark AR.
