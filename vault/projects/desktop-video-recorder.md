## Body

Inspiration I often faced to need to record video for UiPath workflow, and I hoped If I could record video via UiPath easily. This is a reason why I made this activities package. What it does This activities package provides function to record desktop video via UiPath with FFmpeg. How I built it This activities package was built by Visual Studio 2017. Challenges I ran into At first I tried to use OpenCV to record desktop video, but its performance was not enough. In the end, I decided to use FFmpeg and it worked good.
