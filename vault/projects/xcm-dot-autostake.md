# XCM DOT Autostake

> Autostake your DOT from any Parachain using XCM

[Devpost](https://devpost.com/software/xcm-dot-autostake) · hackathon [[Polkadot Hackathon- North America Edition]]

## Facets


**stack** javascript, metamask, polkadot.js, react, solidity, substrate, xcm

## Body

Project Vision XCM DOT AUTOSTAKE Autostake your DOT from any Parachain using XCM Using XCM DOT AUTOSTAKE: The project solves the current problem of a user having to manually manage their DOT asset holdings on multiple parachains if they wish to stake DOT for Liquid DOT in the Acala Ecosystem. The project achieves the following: A simple UI walks the user through the process of autostaking DOT from any parachain onto Acala for LDOT. Unstaking LDOT Back to DOT is also facilitated. The UI also provides the user with the ability to transfer a wide selection of assets between Parachains and Relay Chains on the Polkadot Ecosystem. The project makes extensive use of the Cross Consensus Messaging Format (XCM). Further Information Two kinds of vertical message-passing transport protocols have been used in the project: Upward Message Passing ( UMP ): This allows parachains to send messages to their relay chain. Downward Message Passing ( DMP ): This allows the relay chain to pass messages down to one of its parachains. In addition, the project has used Horizontal Relay-routed Message Passing ( HMRP ): This allows the parachains to parachain messaging on the same relay chain.
