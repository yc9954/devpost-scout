## Body

Inspiration We were given the prompt "A matter of time" from the Ubisoft Game Dev challenge and thought about the weird ideas our neighbouring groups were coming up with. What it does Hack the Bomb is a scavenger hunt game where the player goes around the E7 building solving puzzles and getting codes to defuse the bomb. How we built it Built using the Unity game engine and programmed with C#. Modelling was done on Blender. Challenges we ran into We struggled to find means of collaborating in Unity. We were all inexperienced with Unity and faced challenges with getting familiar with the game engine. Accomplishments that we're proud of We are all proud of developing a game with Unity, something we have never done before. What we learned We learned how to use C# and Unity to create a game with functional movement and game logic.
