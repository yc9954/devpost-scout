## Body

Inspiration Building something that takes full advantage of the Lenstudio hand-tracking feature. What it does Pixel builder is an Augmented reality game/art tool where you get to use your hands in AR to build 3d pixel art. How we built it To build this lens I made use of lens studio's hand-tracking feature for gesture detection and physics collisions. I made heavy use of the scripting engine to make the game work such as using used prefabs to instantiate game objects. Accomplishments that we're proud of What makes this lens really intuitive is that it makes use of hand tracking for every single interaction such as pressing buttons confirming virtual dialogs, showing the level's build reference, and of course picking up blocks and placing them. What we learned I learned a lot about Lens studio and hand tracking What's next for Pixel Builder Well, I really wanted to add the connected lens feature to let users build together in the same space or remotely but due to time, I was unable to for this hackathon. I plan to add more levels in the game mode and the ability to export the 3D pixel art in create mode so that it can be used in other 3d programs.
