## Body

Inspiration Phones have become a central piece of everyone's everyday lives. This has had both good and bad effects, and as ironic as it is, I wanted to touch on this in the form of a video game. What it does It is a game that exemplifies the consequences of staying on your phone for too long rather than doing chores and tasks that are crucial to life. It takes into account the fact that humans need entertainment, so the game challenges the user to balance their entertainment level with the chores they need to complete. How we built it I built it using the Unity 2D & 3D Engines in C#. I also used Photoshop and paint.net for art, and Audacity for audio. Challenges we ran into I underestimated the amount of time some of the things I wanted to do would take, and as a result I did not get to create as much as we wanted to. I also ran into some minor issues/bugs with Unity crashes. Maintaining productivity with messy scripts (as there were quite a few scripts in the game) was difficult over the course of this hackathon. Accomplishments that we're proud of This game helped me improve my scripting efficiency and understanding of game flow in Unity. I also gained more experience in both the 3D and 2D game engines because the game creatively combines both together. What we learned Every time I work on a project, I get a little better at setting realistic goals. I definitely got better this time but there is still a long way to go. Additionally, this was my first time mixing 3D and 2D together into one game to create a more appealing visual effect. What's next for boredom. More levels/completion! More mechanics to make the game more interesting and appealing to users as well. UI improvements were something I also really wanted because UI makes a large difference in games. <div
