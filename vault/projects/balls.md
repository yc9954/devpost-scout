## Body

Search for a song Song Results Spotify Song Visualizer By Wesley, Wonhak, Tiffany, and Julien Inspiration We were inspired by Spotify Wrapped - which shows your top song from the year from its first stream to its 100th stream. Seeing our listening stats so meticulously displayed on the app inspired us to further elaborate this feature. How it works This project allows you to input any song title with its respective artist, it then returns the song/album cover, along with its audio features. How it was built This was built using Spotify's Spotipy , which is a lightweight Python library for the Spotify Web API so we could extract music data provided by the platform.
