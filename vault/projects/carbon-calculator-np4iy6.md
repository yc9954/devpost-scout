## Body

Front page of application The rising threat that climate change poses inspired us to create an application that can be used to see how much carbon dioxide is produced to create clothes that people wear. The application we created takes user input, which comes from three dropdown menus, related to the type of clothes someone is wearing, their material, and their size. We built the application by first creating three dropdown menus that can be used to select the type of clothes being worn, the material of the clothes, and the size. Then those numbers are used in a formula that estimates the carbon dioxide released while those clothes are being made. While making the application, our group ran into several challenges which managed to almost completely stop our progress. One of the biggest challenges was that one of our group members got sick. Some of the technical issues we had to deal with while creating the application would be taking the information from the dropdown menus and the user interface. One of the biggest accomplishments that we are proud of would be getting a good user interface that has a theme that supports the idea of our application. Some others would be creating a working formula that gives a good idea about the carbon release. After completing this project, we got a basic idea of how programming languages like HTML, CSS, and Javascript work. We also learned about some of the challenges of sharing the work that comes from dealing with a project in a small amount of time. An example would be the challenge of getting all the code from different people to be compatible.
