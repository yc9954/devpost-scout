# love ya

## Body

Project Description: This project was created not intentionally to solve any problems but just to have fun and try out Adobe Aero Geospatial. I wanted to build something feeling warm and inviting, so I chose Valentine's Day as the theme and created three user scenarios that connect users with local businesses. Issues that I ran into: I noticed some issues about Aero Geospatial during project development. Initially my 3D models were made in Cinema4D, but the texture and color were not displayed correctly in Aero. To resolve this, I had to import the files into Blender, recolor the models and export them as GLB files to make them compatible with Aero. Additionally, Aero Geospatial lacks the capability to create 2D interfaces that adhere to the viewport, so I had to use Adobe After Effects to showcase those interactions.
