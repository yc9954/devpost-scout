George Washington Inspiration Our team has always been intrigued with the use of word clouds as a method to learn new concepts and understand the most important ideas in such concepts. Our teammate, Josh, needed to teach the entire class about the history of India for a class presentation. The deep history and rich culture made it difficult for him to explain everything. Josh used a wordcloud to talk about the major aspects of Indian life and society which helped the entire class understand. The rest of the team was with him during this class and thought this technique was truly useful. What it does Using Postman API, you can send a request with any key term and it will take key term concepts from the Smithsonian database and create a word cloud. How we built it We used Postman's world class API builder to guide us to create this.
