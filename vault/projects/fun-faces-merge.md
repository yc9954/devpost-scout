## Body

Inspiration Fun Faces Merge was inspired by classic merge games and my passion for creating playful, expressive characters. I wanted to build a lighthearted experience that feels fun, colorful, and satisfying, especially for quick play sessions on Snapchat. What it does Fun Faces Merge is a casual merge game where players combine funny face icons to unlock new and more expressive faces. ** **The game focuses on simple mechanics, smooth animations, and visual feedback that keeps the experience fun and engaging. How we built it The game was built using a mix of 2D assets and custom UI design. I handled the full process, including UI layout, merge logic, animations, scoring, and camera transitions.
