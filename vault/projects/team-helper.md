Diagram of how it's useful for your team. An example of what it has. Inspiration When creating apps to help the team, we've had to visit the same API over and over again. It would be nice to have a collection of the services that we use to help our project manager, designers, devops, and fellow developers. Challenges we ran into The services that we use aren't always the same. While a service like github actually uses the graphql body, a service like monday uses graphql but in form-data which is a bit tricky.
