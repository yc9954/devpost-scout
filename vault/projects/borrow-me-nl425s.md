Be a lender Page Home Page sign up/login page Be a borrower page Item borroing page Inspiration During my last semester of the foundation year, I thought of this project. I consulted my teacher, and he said to make something that solves a real problem. That’s when BorrowMe came to mind — a problem I personally faced at university, For example, one time I needed an iron for an important presentation, but I didn’t want to buy one to use just once or twice. I borrowed one from a friend, but there were items she needed that I didn’t have, and vice versa. I realized this is a common issue among students. As that's I had this idea for a long time, and when I heard of this hackathon, I immediately locked in and I decided to create a website made by a student, for students, to make students' lives easier — and that’s how BorrowMe was born. What it does BorrowMe is a trusted community platform for XMUM students. There are two main roles: Lenders : students who own items. They post items on the website, set an hourly price, and specify a deposit. Borrowers : students who request items. I act as the middleman — handling transactions, approving item submissions, and returning deposits to borrowers. How I built it I used Wix.com as the main platform. Wix has a built-in database, drag-and-drop interface, and the flexibility to add extra code when needed, which made it ideal for this project. Used ChatGPT to generate the coding for the lender page. Because Wix Velo is a JavaScript platform that allows me to run code for customized features Also, ChatGPT to teach me how to use Wix and walk me through the steps Challenges I ran into I’m not very strong in coding, so creating the lender page required extra effort. I managed it with the help of ChatGPT and some refinements. Choosing the perfect color scheme was also a challenge — I consulted my family and friends to make the design simple and user-friendly. Accomplishments that I'm proud of I’m proud that I thought of this idea and made it a reality. I also learned how to use Wix to build a fully functional website, which is a skill that will benefit me in the future. What I learned I learned to trust myself — if I want something to happen, I can make it real by working hard. I also gained valuable experience building a website from scratch on Wix. What's next for BorrowMe I’m looking forward to officially publishing BorrowMe at XMUM. Currently, I’m refining a few bugs. I also plan to add an AI feature that suggests items for borrowers based on a description of what they need. If I can’t implement it before the hackathon deadline, it will be added before the official launch. * Example of the AI feature: * a user types “I need to iron my clothes for a presentation,” and the system suggests irons available nearby. <div
