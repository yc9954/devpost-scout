Dino - sneaker model in builder Draco - sneaker model in builder Fast- sneaker model in builder My Collection - storage for favourite styles Tokyo - sneaker model in builder Substaince - sneaker model in builder We love sneakers. For us, it’s the greatest combination of design and utility in one line with architecture and automotive design. So, for this Lensathon, we decided to make something about digital collectables. And it quickly turned from a short weekend experiment into the ultimate “What if” project. Lens Studio has a template where I can try my sneakers on my feet, but what if I want to look it up closer, or what if I want to rotate it freely? So, we brought on a few more features. Now you can hold a digital sneaker in your hand, check it in world space or in the virtual shop front. For the lens, we needed the actual sneakers models. So we thought: What if we design our own? After tonnes of explorations, sketching, modelling and polishing, we got a couple of good ones. It felt like we are developing a real sneakers line :) we even came up with the logo and the name. We called it - "AnyWhere" because you can go with digital sneakers literally Anywhere. It was so cool to design our own sneakers; What if we can share this experience with others? Lens Studio was always for creators, and Snapchat was more for consumers. We wanted to give the full power of self-expression to Snapchaters. We started adding customization options, and it quickly went out of control :) Now you can style your sneaker up to your vision. Then we thought: What if we make them like smartwatches - like smart sneakers? So we added options with holograms, which show date, time, users profile name and even weather and location. We started spending more time in the lens and thought that users might spend some time styling sneakers too, and it would be so pity to lose progress or preciously designed items. What if you can collect your sneakers? Thankfully, Lens Studio had a feature for this as well. So we quickly figured out how to use Persistent Storage, and now you can have a small collection of the perfect digital sneakers. Then we thought, what if we can add even more magic moments? We kept adding nice small touches like - sneakers levitating when you’re smiling or spinning when you tilt your head until we felt that it was perfect. Of course, it will never be perfect enough, and we still have a lot of "What if’s" on our todo list: What if we can add exclusive features available only for tokens? So you can build super unique digital footwear by adding more personal touches or even shaping the sneakers model. What if we could improve the realism with features like ray tracing or ML environment matching? What if we could add integration with bitmoji? What if users would like to exchange their custom digital footwear, like gifts? Maybe we can create our own digital fashion line? :) …and many more <div
