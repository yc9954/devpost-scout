Follow page Page shows challenges that user can take Page shows challenges that user can take Sign up page Sign in page Main page EcoActionTracker: Project Reflection Inspiration The growing concerns about climate change and environmental sustainability inspired us to develop EcoActionTracker . We realized that while many people want to lead eco-friendly lives, they often lack the tools to track and measure their environmental impact. Our goal was to create an intuitive platform that empowers individuals to take control of their eco-friendly habits, making sustainable living more accessible and actionable. What We Learned This project was a valuable learning experience for our team. We deepened our understanding of: Web development techniques , focusing on responsive design and user experience. Data management using local storage to ensure user privacy. Collaborative development , including version control with GitHub and efficient task distribution. Additionally, we learned how to balance aesthetics with functionality, creating a platform that is both visually appealing and easy to navigate. How We Built It Frontend Development: The website was built using HTML, CSS, and JavaScript . We focused on creating a clean, responsive design that offers a seamless user experience across devices. Data Handling: To prioritize user privacy, all user data is stored locally in the browser using local storage , avoiding the need for external databases. Team Contributions: Himanshu Joshi , an AI/ML student, was responsible for building the website and designing the user interface. His expertise ensured the platform was functional, intuitive, and visually engaging. Anand Gupta , an ECE student, contributed by sourcing high-quality images and visuals, enhancing the overall look and feel of the platform. Challenges We Faced Throughout the development process, we encountered several challenges: Design Consistency : Ensuring a consistent and appealing design that aligns with the sustainability theme required multiple iterations and careful planning. Data Privacy : Deciding to store data locally presented both opportunities and challenges, particularly in ensuring that user interactions were saved reliably without compromising performance. Time Management : Working under tight deadlines for the hackathon pushed us to efficiently allocate tasks and troubleshoot issues quickly.
