Home Page Gallery Search Tool Plant Information Logo Inspiration Our inspiration for this hackathon was derived from our interest in bringing awareness to the environment and its issues, our interest in gardening and taking care proper care of plants, as well as the programming abilities that our group members posses. We chose to create this website to provide people with the basic information of how to take care of plants to encourage them and show them that it is not as difficult as it would seem, we also did not want the information to be too complicated so that it would not intimidate anyone potentially interested in plants. What it does There are many people who own a plant but don't know how to take care of it. The solution we created is this website. It specifically tells you the amount of water you need for your plant using a search bar. How we built it We used a combination of html and css for our website. In addition to this, we decided to include javascript for our search bar. Challenges we ran into -couldn't figure out how to use the 'enter' key for the search function -project had trouble to load in fully once we were sending it to each other -problem resizing images with the css -problem moving button vertically with the css Accomplishments that we're proud of We managed to accomplish many great things with this project, but there are three main achievements that we are the proudest of. The first one is the video as we do not have much experience regarding the creation of one and were not very sure on how to proceed with it initially. The second one is the search bar as quite difficult create do the complexity of it (involved a variety of variables, arrays, and methods). And finally, the plant database as it took quite sometime to assemble and sort as a result of the quantity data that it posses as well as the fact that it needed to properly sorted and organized. What we learned We learned a lot about front end/styling work in web development. We learned that data collection and analysis take up a significant amount of time. We got to learn lots of spiritual knowledge during the project. We also learned a lot about different plants, the environment and how to take care of it. What's next for Natural Finds Adding more variety of plants into our database to inform our clients. Improving the use interface of our website. Making our code less spaghetti than it already is. Adding a system which identifies endangered plants using images and machine learning. Adding a system which can identify any plant from a picture using machine learning. We believe that Natural Finds can be a very useful asset in for every plant lover and can help the environment. <div
