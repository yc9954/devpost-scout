## Body

GIF Inspiration Inspired by Two-Timin' Towers, this is a special tower defense game where you as the player have to run around on the map building towers. What it does It's a video game. How we built it The game was built with Ubisoft API using C++. Challenges we ran into Had to do all the coding and the "art", it was tiring at the end but exhilarating most of the time. Ran into some bugs when stress testing, the reason turned out to be the order in which entities and their components update, lesson learned! Accomplishments that we're proud of I'm happy that I finished a relatively complete game over the weekend and had all the features planned implemented. What we learned I learned a little bit about drawing pixel art and got to know game engine architecture a little better. What's next for Tower Defense Cleaning up duplicate code, fixing the code that was rushed in the end, and polishing the level design. <div
