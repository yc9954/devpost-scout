Dark Mode Light Mode Trade on SushiSwap from deSocialNet Explore Page Store Page Florida Alaska Virginia Inspiration I wanted to create the landing page for crypto, a sort of ecosystem, that brings all the users of the crypto world into a decentralized platform where users can talk to one another and work together to build a more open and free platform. What it does It is a decentralized and open source social media platform that allows users to share, post, comment, follow, and message with other users. The other part of the project is a fully decentralized NFT game that allows users to create their own NFTs and create new and exciting interfaces for this game or just play the game and try to earn crypto! How we built it The smart contracts were written and tested using the remix platform. The main interface was built using bootstrap, Moralis, Javascript, HTML. The interface is then hosted on a namecheap server as a simple html file. All of the photos, images, and files are hosted via IPFS through Moralis to give a more authentic user experience. Challenges we ran into I tried to fit the entire social media platform into one html file to make it super easy to host yourself. Obviously with the complexity of a social media platform, the code quickly grew in size where it became difficult to navigate. I ended up resorting to use Ctrl+F to navigate through all the code because using my mouse became much to difficult. Other than that though, the process was very smooth due to the great work by the people at Moralis. Integrating smart contracts into the website was never so simple. Accomplishments that we're proud of Fitting everything into one HTML file that has the complete functionality of what you would come to expect from a social media platform. It was a lot of long hours coding away at night and on the weekends and seeing everything come together is really truly something special to see. What we learned Moralis truly made the process of building the project so simple and easy. I was further able to grow my knowledge of Solidity and Javascript since I started this project. What's next for deSocialNet / Breakin: The Game The Ethereum blockchain is far too expensive and slow for this project to run on mainnet. The next step for deSocialNet would be to launch it on a much faster and cheaper blockchain or possibly a L2 scaling solution. This would make the social media platform much cheaper and faster to use. I would also like to build out a much nicer interface for the game. <div
