## Body

Inspiration Learning. That's the main motivation behind this work. Both postman and Github APIs are new to me so what's better than creating a collection of Github APIs in postman to make our lives easier and learning both at once. What it does It's a public workspace with different collections of github APIs. How we built it I learned about how to work with postman, create workspace, collections, etc. and explored Github APIs for extracting information from repositories and then tried combining the two. Challenges we ran into I had a hard time exploring Postman. Also since it was the first workspace by me so I had several issues with getting it up and working. Accomplishments that we're proud of Hey, it's finally working! And maybe it can help someone. What we learned I learned a lot about postman like how to create an workspace, collections, collaboration in workspace and also about APIs provided by Github. What's next for Github Extraction I will be adding more different collections into this workspace. <div
