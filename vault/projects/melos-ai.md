## Body

Melos AI: The Sound of Vision 🎵✨ Inspiration The idea for Melos AI was born from our passion for combining music, art, and technology to create something truly unique. We've always been big fans of wallpaper engine, scouring for the most aesthetic wallpapers. But deep down we knew wanted more than just the visual aspect. We wanted to match that aesthetic with music that would further enhance the feeling of being immersed with an image. We wanted to turn visuals into personalized soundtracks, making every image a gateway to a musical journey. Platforms like TikTok and Instagram inspired us to integrate trending music, giving users a chance to explore sounds that resonate with the latest trends. What It Does Melos AI transforms images into music recommendations: Users upload an image. AI analyzes the image and generates a descriptive mood. The mood is used to create an AI generated song using the Beatoven API. Users can preview, share songs (Linkedin, X, Facebook) or add them to Spotify/Apple Music. It’s a seamless way to bridge visual art and sound, all while staying on top of music trends. How We Built It Frontend : Built with React.js for a responsive and interactive UI. - Integrated a song preview feature for easy playback. Backend : Developed using Node.js , handling API calls, AI processing, and secure OAuth flows. We made use of Clerk authentication to make sure users who want to access all features in the future will be able to do so. AI Model : Leveraged an image processing model to analyze user-uploaded images and generate descriptive moods. APIs : Used the Beatoven API to generate real world songs based on moods. Social Integration : Simplified sharing features to enable quick posting on platforms like Instagram. Challenges We Ran Into AI Fine-Tuning : Matching image-generated moods with relevant songs required significant testing. Time Constraints : Balancing feature completeness with hackathon deadlines was a constant challenge. Accomplishments That We’re Proud Of Successfully integrating multiple APIs to create a smooth user experience. Developing a functional prototype that transforms images into music. Building a visually appealing and intuitive interface within a short timeframe. Creating a unique project that bridges the gap between art, technology, and music discovery. What We Learned How to seamlessly integrate AI and APIs into a cohesive product. The importance of prioritizing features that enhance user experience. The value of collaboration and time management in fast-paced development. What’s Next for Melos AI Phase 2 : Introduce AI-generated music recommendations tailored to users' preferences. Enhanced Algorithms : Improve the mood-to-song matching system for better accuracy. Collaborative Playlists : Enable users to create and share custom playlists. Expanded Integrations : Add support for more music platforms and trending apps. Mobile App : Develop a mobile version to make the experience even more accessible. Melos AI is just the beginning of a creative journey that connects visuals, sounds, and emotions. We’re excited to see where this project will take us next! <div
