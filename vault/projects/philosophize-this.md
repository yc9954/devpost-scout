## Body

App Interface Input example Output Inspiration I post Question of the Day on Nobody's Society, a Discord server, daily. We try to philosophize on topics of day-to-day importance, life importance, or just for fun. Anyone can submit these questions. This app is directly inspired by my work there! What it does The app asks you to name a Philosopher of your choice or choose from given examples. It then asks for the user's thoughts and retrieves an answer based on the user's specific situation or thoughts as would have been answered by the specified philosopher! Features Though this app was initially built to inspire philosophical discussions, it can do much more than that! You can talk to your favorite characters, actors, influencers, pokemon, or even animals! Just mention their name and the user should be able to talk to them. How we built it This is a net-new application, created from scratch by PartyRock by Amazon Bedrock Playground! I started by playing around with widgets and getting a hang of Playground. Then I tried to implement my everyday work into it. Challenges we ran into I would've loved a feature to choose from select options. This would make the app interface easier and prevent misuse. For now, I wasn't able to implement it. Accomplishments that we're proud of A WHOLE NEW SHARABLE APPLICATION BUILT FROM SCRATCH What we learned The possibilities are endless with generative AI.
