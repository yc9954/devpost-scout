Inspiration This project always fasinated me as to how does things work to make a bot, how complex it must be. After making it myself I can now understand how easy it actually is. What it does Cosling is a bot that helps students through their joining and onboarding process and guides them with aal the important info. How we built it I've built Cosling on the Kore.ai bot builder's platform which makes thing so much easy with all the features it provides. Challenges we ran into There was a yes-no question I wanted to add, I tried adding it with a confirmaiton task but it gave different results than expected. Accomplishments that we're proud of I feel really acomplished that I've made a bot all by myself and am also participating in a hackathon as its my first one. What we learned I now realize that not stoping while doing a project will make the project better. I've also learnt that making bots is similar to watering a plant, how much ever you feed it, it'll grow that much.
