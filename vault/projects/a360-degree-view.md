# Accelerize360 Profit Pulse

> The purpose of this project was to show that not all sales are good sales. Enabling users by highlighting where profitability is gained or lost, and recommend actions to improve margin.

## Body

We were inspired by the opportunity to explore a new tool and collaborate as a team. This hackathon allowed us to bounce ideas off each other, learn together, and expand our knowledge of Tableau NEXT. Our project is an interactive dashboard that provides insights into sales and profit margins. Users can quickly analyze sales performance across categories, regions, and time period, helping identify trend, opportunities, and area for improvement. The dashboard was built leveraging Data Cloud, Tableau Next, and Heroku. It integrates multiple visualizations, interactive filters, allowing users to perform not only diagnostic analysis but also prescriptive analysis. We are proud to have created a fully interactive, user friendly dashboard that highlights key business metrics and allows for dynamic exploration. We gained valuable hands-on experience with Tableau NEXT enhancing our technical skills. Through this project, we gained practical experience using Tableau NEXT and Data Cloud features to manage and visualize data efficiently. The new tool of Tableau NEXT was a challenge at first, but quickly proved to be very similar to existing team experience across CRM Analytics and Tableau Classic.
