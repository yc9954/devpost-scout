project information (read from NFT) Inspiration I wanted to create a product that helps people, but that was accessible for anyone. I always had an idea of a type of marketplace / charity but with non centralized technology which, in my opinion is very, very important for this type of project! Simultaneously, I feel like Flow blockchain has many advantages for NFTs and I was curious on how developing on a chain other then ethereum was like. And so I decided. What it does Allows anyone to get funding! If you had a genius idea and need money to make it real, just publish it on crowdapp and wait! If someone also believes in your vision, they can help you and you can later know who helped you because of NFTs! Without even knowing they have NFTs (if they don't understand blockchains). But it can do this whilst abstracting blockchain concepts and saves as records of the contributions as an NFT to allow endless NFT functionalities but for projects! How we built it I started with a simple NFT website. With it I started implementing features I wanted one by one. Additional parameters in NFTs, a timestamp, log in / out, viewing NFTs, creating NFTs from custom inputs, and creating NFTs on existing contracts that represent projects! Challenges we ran into I had a hard time setting up a development environment with a completely local workflow. Meaning local blockchain, wallet, contracts ect... I felt it was hard to learn and fix errors I didn't understand because there are very few questions online on indexable websites (like stackoverflow). Accomplishments that we're proud of Each little accomplishment was precious. Each feature I added that after many efforts worked was all I could ask for. What we learned I learned a lot of how the Flow blockchain works, which revealed some disadvantages / problems with ethereum - it gave a new perspective. I feel more confortable with css, js and react pages in general. What's next for FundFlow The sky is the limit! When each person has an NFT representing what they helped, there can be a reward system, loyalty, re-seling of NFTs, royalties and much more!
