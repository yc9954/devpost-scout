## Body

Inspiration We build this project to explore the potential for adding shader modifications to Google Maps Photorealistic 3D Maps in order to make the Google Photorealistic 3D Map API more suitable for rendering certain landscapes where it is less beneficial to show the entire terrain, and instead just a small section of it. What it does Highlights Ski Routes, combined with a vintage aesthetic. How we built it React and Google Maps API with custom shader injection. Challenges we ran into Not knowing how perform custom shader injection. Learning the Google Maps API Accomplishments that we're proud of It is a nice effect! What we learned I may consider using the Google Maps API in future, normally I use deck.gl What's next for Terrain Highlighting Modifications Adding a backend, and seeing if its possible to do this in a less hacky way. <div
