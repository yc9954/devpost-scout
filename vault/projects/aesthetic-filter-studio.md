## Body

Inspiration People asking me about UI styles I'm using in my projects on X - how did I prompt them, what's this style called - now they can jump start it themselves! What it does It's 12 popular UI styles displayed - user can switch between styles to see differences, design philosophies and download specific, simple CSS file and a style-specific prompt for their own projects! How we built it One-shot with bolt.new, with a bit of help from Claude to bulletproof the one-shot prompt. Challenges we ran into Making it just one-shot :) Accomplishments that we're proud of That all of the styles are looking solid, and at least showcase the differences between them really well - if not used 1:1, it can definitely guide a user towards the aesthetics they want. What we learned Small changes in a prompt can bring huge differences in a result. What's next for Aesthetic Filter Studio After hackathon, maybe a bit more comprehensive solution, with colour/font pickets, shadow/padding sliders - but I'll need more than one prompt for this :) <div
