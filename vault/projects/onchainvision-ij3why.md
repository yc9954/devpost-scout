## Body

Inspiration Mobile is the new web and web3 must adapt the only way to do a nice connection is through deeplinks between dApps and Wallet is important to have the two separated to let the wallet focus on security and let the dApp do whatever he wants. We successful created an mobile DEX aggregator on TRON with on chain data that connects seamless with any wallet. What it does We now offer the same opperations in the only mobile dApp on TRON that connects using deeplinks to TronLink but also using WalletConnect to TrustWallet, Token Pocket and any other wallet compatible with TronNetwork: 🔁 exchange aggregator 💸 send payments TRX/ TRC20 📊 displaying data such as history trading (charts, transaction list) 🕵 analyzing smartContracts 🧪 interacting with smartContracts ⚡ rent Energy before any transaction 🌟 do not go through in case an transaction is about to fail What is new TronLink Integration 🆕 Evaluation of smart contract if they have energy paid by the smart contract 🆕 SunPump smart contract router added users must pay only 1% of energy fees 🆕 Now the app supporst BigDecmials and BigInteger that means that even the smallest penny will be changed for you 🆕 For transfer TRC 20 now you have the possibility to transfer faster by pressing ‘Paste address’, ‘Max’ button to transfer the entire amount and you can also see the token balance How we built it Kotlin+ Compose on Android python plus Django on server side Challenges we ran into No previous history for such projects so we did not have any templates or anything like that. Accomplishments that we're proud of We successful made all the operations works smoothly both TronLink and WalletConnect. We added Advance Charts by TradingView We integrated SunPump Router so users can pay only 1% What we learned That users are the key piece for a successful project What's next for OnChainVision We want to add also bandwidth cost We plan to add multi routing <div
