## Body

Inspiration Using Postman is all about getting things done faster in a more reliable manner. Now that vaccination period started, a lot of people don't get their vaccine when they request so they need to reschedule their program and stay more than at risk than they should. A sick person has only one wish, so we want to keep our elders/people that are not used with technology healthy and help them get a vaccine as fast as possible. What it does Is uses the Romanian platform for vaccination to edit your account, add new users, schedule an appointment, do edits and get the status of you request. How we built it First manually taking the requests, then using the satellite function and editing the request to work smart ;) Challenges we ran into The account creation is backed by Google's captcha, so good luck breaking that. Also I don't want to create a security issue out of this. Accomplishments that we're proud of I tried this with my neighbour and he got an appointment. He is not sure how I made it so fast but he ain't that curios to find out :) What's next for Vaccinated in time because of Postman Maybe propose these APIs to the govern to improve their platform since it got some bugs and when you work in a medical sector you need to be as precise as possible.
