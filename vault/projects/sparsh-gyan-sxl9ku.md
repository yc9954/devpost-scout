## Body

Inspiration The inspiration behind sparsh Gyan came from observing the lack of accessible digital learning tools for specially-abled children. Many existing platforms are not designed for inclusive education. This motivated me to build a technology-driven solution that ensures education for all. What it does sparsh Gyan is a digital education platform designed for specially-abled children. It enables interactive and accessible learning using a combination of hardware-based interaction, web technology, and intelligent personalization. How I built it I built sparsh Gyan using Arduino for interactive learning inputs, a MERN stack for the web platform, and Python-based machine learning to adapt and personalize educational content based on user interaction Challenges I ran into Designing an inclusive system for diverse abilities was challenging. Integrating hardware with web and machine learning components while keeping the platform simple and accessible required continuous testing and iteration.
