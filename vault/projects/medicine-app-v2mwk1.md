## Body

Inspiration Access to clear and simple medicine information is important for everyone. Many people take medicines without fully understanding their uses, side effects, or how they work inside the body. This project was inspired by the idea of creating a simple digital guide for medicines where users can quickly learn about common drugs, health tips, and how medicines travel through the body. The goal was to make medical knowledge easier to explore in an interactive way . What it does Medicine App is a web-based application that helps users explore medicine-related information in a simple interface. Main features include: 💊 Medicine Information – basic details about medicines ⚠️ Side Effects Section – common side effects for drugs 🧠 Health Tips – helpful tips for everyday health 🔬 Medicine Pathways – visual flow showing how medicine works in the body 📚 Medicine Classification – different types of medicines 🔍 Search and navigation system for easy exploration The app presents information in cards and interactive sections , making it easy to read and understand. How we built it The project was built as a front-end web application using: HTML for structure CSS for styling and UI design JavaScript for dynamic features and interactivity JavaScript is used to: Display medicine data Filter health tips Generate medicine pathway diagrams Control section navigation The interface uses a sidebar navigation system with interactive content sections to create a clean and user-friendly experience. Challenges we ran into Some challenges during development included: Designing a clear UI layout for multiple medical sections Creating dynamic JavaScript features for filtering and displaying information Building visual medicine pathways that explain how drugs travel in the body Organizing a large amount of medicine data in a simple format These challenges helped improve both JavaScript logic and UI design skills . What we learned Through this project, we learned: How to build interactive web applications using JavaScript How to organize medical information in structured datasets How to design clean UI layouts for educational tools How to implement dynamic content rendering The project also helped strengthen understanding of bioinformatics and medical data presentation . Future improvements In the future, this project could include: Medicine interaction checker Dosage calculator Drug database integration AI-based medicine recommendations Mobile-friendly design These features would make the app even more useful for students and the general public. <div
