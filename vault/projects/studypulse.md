## Body

Inspiration Students don’t work the same every day. Mood, energy, and stress change constantly. We wanted a tool that adapts to the student instead of demanding perfection. What it does StudyPulse creates a dynamic daily plan based on your tasks, priorities, mood, and energy. It includes, A smart Today’s Focus Plan, Priority engine + Eisenhower Matrix, A persistent gamified Pomodoro (Focus Garden), A full Notes tab with drawing tools and resource attachments How we built it I used React + Vite, custom logic for task scoring, sliders for mood/energy, localStorage for persistence, a custom canvas for drawing, and animated UI components for smooth interactions. With the help of ChatGPT and Lovable. Challenges we ran into Balancing mood/energy with task priority, building a persistent timer, creating smooth sliders and animations, fixing drawing accuracy, and making the Eisenhower Matrix expandable. Accomplishments that we're proud of A fully adaptive planner, a persistent gamified Pomodoro, a clean animated UI, and a full notes workspace with drawing—all working locally with no backend. What we learned How to blend productivity + wellbeing, how impactful smooth UI/UX is, and how to design adaptive task logic that actually helps students.
