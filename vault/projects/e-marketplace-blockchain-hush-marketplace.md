## Body

Project Flow Genesis Authentic: Don’t Just Trust. Own the Truth. Inspiration In today’s e-commerce world, trust is fragile. How do you know a product is genuine? A seller reliable? A transaction secure? I asked myself: Why settle for trust, when you can own the truth? Genesis Authentic was born from this idea—a marketplace where ownership, authenticity, and transparency live on-chain. Users can own products digitally as NFTs, while still having the option to claim them physically. What it does Genesis Authentic is a Web3 e-commerce marketplace where: Users can own products digitally as simple NFTs Physical possession is optional Transactions are secure, transparent, and on-chain Key Insight: Every product is an NFT on-chain, meaning ownership is immutable, verifiable, and transferable, even if the physical item hasn’t yet changed hands. How we built it Blockchain Layer: Built the modular pallet-marketplace using Substrate, Polkadot, Rust, FRAME Managed NFT-style product ownership, listing, buying, redemption, and admin roles Frontend Layer: React app integrated with Polkadot.js for wallet interactions, transaction signing, and product management Deployment & Tools: Docker for containerized builds GitHub Actions Build Tools: Cargo, npm Future Layer: Integrate fiat-to-onchain layers for direct fiat purchases to a user’s on-chain wallet. Challenges we ran into Synchronizing the frontend with on-chain transactions in real time Designing NFT-style ownership with optional physical fulfillment Planning for modular, decentralized governance Each challenge became a lesson in balancing security, UX, and blockchain efficiency. Accomplishments that we're proud of Successfully built a trustless, transparent e-commerce platform Implemented NFT-style digital ownership of real-world products Created a modular pallet capable of handling manufacturers, listings, and marketplace admin roles Enabled future-proof architecture for fiat integration and decentralized governance What we learned Blockchain and frontend synchronization requires careful event handling Modular design simplifies testing and scalability On-chain ownership opens new possibilities for digital-physical hybrid products Balancing UX with blockchain mechanics is key to adoption What's next for Genesis Authentic Marketplace Fully decentralized marketplace governance Seamless fiat-to-chain integration for mainstream adoption Scalable NFT-style product ownership across multiple manufacturers Enhance UX to bring Web3 e-commerce to everyone—crypto-native or not 💡 In short: “Don’t just trust. Own the truth.” <div
