## Body

Inspiration whenever we try to do some work we schedule it for some time but it either exceeds or it takes less time in order to overcome such defaults we are trying to make a timeline management system that helps you to manage your time within a specific time. What it does It mainly deals with time management and tells us how much time it took to complete work. But at first, the user needs to log in to our web page. If the account is not there then the user needs to first sign up. How we built it we have used Django for the registration and login system. Challenges we ran into The most challenging thing was creating the dial to count the time taken to complete a work. Accomplishments that we're proud of we are proud that we were able to create a login and log out page respectively for the time management system which helps us in analyzing the work we have done by just looking at the taskbar. What we learned we have learned about web page development.
