Landing Page Decoryn Studio Decoryn Studio workspace Testing Output Admin Dashboard Inspiration Decoryn Studio was created because many people struggle to visualize room redesigns before starting renovations. Most AI interior design tools only generate images without helping users understand realistic budgets, renovation planning, or implementation steps. I built Decorin Studio to solve that problem. that not only generates redesign visuals, but also helps users plan renovations more practically through budget estimation, renovation planning, and actionable reports. What it does Decoryn Studio is an AI-powered interior redesign platform that helps users visualize room redesigns within one integrated workflow. Users can: upload a room photo, choose an interior design style, set a budget level, select room mood preferences, generate AI-powered redesign visualizations, receive budget estimations, view renovation timelines, get furniture recommendations, and export professional redesign reports as PDFs. How we built it Decoryn Studio was built using MeDo as an AI-powered full-stack app builder. I used MeDo to build: the landing page, dashboard, authentication flow, credits system, AI redesign workflow, redesign history, and PDF reporting system. During development, I used iterative workflows with MeDo through natural language conversations to continuously improve the UI, mobile responsiveness, and overall user experience. I also used MeDo Skills and AI workflow integrations to help create a more integrated redesign experience inside the application. Challenges we ran into One of the biggest challenges was keeping AI redesign results realistic while preserving the original room structure and layout. Other challenges included: making the redesign workflow feel natural, maintaining UI and UX consistency, integrating budgeting and renovation planning, and creating PDF reports that remained clean and actionable. Accomplishments that we're proud of One of the things I’m most proud of is transforming Decoryn from a simple AI image generator into a more practical and usable AI renovation planning platform. I’m also proud of building: an integrated redesign workflow, budgeting system, renovation action plans, PDF reporting, credits system, and a SaaS ecosystem that feels like a real product. What we learned While building Decoryn Studio, I learned that the most impactful AI applications are not only visually impressive, but also genuinely help users solve real-world problems. I also learned how MeDo can significantly accelerate UI iteration, workflow development, and user experience improvements through natural language workflows and AI-powered development. What's next for Decoryn Studio An AI-powered interior redesign platform In the future, I want to expand Decoryn Studio into a more complete AI-assisted renovation planning platform.
