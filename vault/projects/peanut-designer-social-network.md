## Body

peanut project cover Inspiration As someone who love design, I used dribbble.com a lot to share my work. Imagine how could would it be if my portfolio is NFT by default and I can own my artwork and identity. What it does It allows designers, artists to upload their work. The website will mint their work as an NFT, for others to collect. Additionally, it is a great way for design lovers to find inspiration. Also for collectors to find valuable artwork. How we built it VueJS + TypeScript for the website Lens Protocol for the smart contract part. AWS Lambda function & AWS RDS & OpenAI Clip for Machine Learning model inference and store result IPFS (NFT.storage) for decentralized storage Challenges we ran into A lot!!! I did not know typescript and lens protocol API, so I learned from scratch. Also I built by myself, that is a lot of work. Accomplishments that we're proud of Being able to ship this out is a great achievement. What we learned Lens Protocol, TypeScript What's next for Peanut - Social Network for Designers Add machine learning capability in a decentralized fashion. (Smart contract for training, model runs in browser for inference) Improve stability, fix minor bugs. <div
