## Body

Tagging intents in wit.ai Inspiration At work, I often have to open a new tab to check what's next on my agenda. It would be nice if I could just ask someone (or something), without the hassle of opening my browser, typing in the calendar url,... What it does Calendar buddy proactively answers questions about your calendar items. How I built it By training a wit.ai application to recognise my questions. Wit.ai is called from a React application built with the NextJS framework, deployed on Vercel. Challenges I ran into Finishing the UI Getting used to XState for state management Accomplishments that I'm proud of Finishing my first online hackathon What I learned Wit.ai is pretty awesome, easy to use State management with XState What's next for Calendar buddy Finish the UI implementation Add a Google Calendar integration Add voice control support (ask questions by talking to your Calendar buddy) <div
