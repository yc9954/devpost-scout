## Body

ThinkTankEDU: Collaborative Educational Platform Inspiration I wanted to create a tool where students, teachers, and even teaching professionals can brainstorm their ideas and creativity together, and work collaboratively on their ideas. With the help of AI, it provides opportunities to explore topics, solve problems, and work on projects like never before. I got this idea inspired by Ideamap.io and HyperWrite's Brainstorming Tool. What it Does This project is a free open-source platform that: Lets students and teachers collaborate in virtual rooms with tools like whiteboards, chat, and video. Provides role-based AI assistants that guide learning, answer questions, and give feedback. Gamifies the learning experience with badges and rewards to keep things exciting. Summarizes each session with key points and follow-up suggestions for easy review. How We Built It Frontend : We used NextJS for the user-friendly interface. Backend : We used Supabase for easy backend integration. AI Models : GPT-based models help with problem-solving, session summaries, and guidance. Collaboration Tools : We used WebRTC and the Stream Video React SDK for cool features like real-time video, audio, and chat. Challenges I Faced Even though I have been working on this project since January 11th, I'm yet to finish it. The project is still in the building phase and incomplete. Due to some time delays, I haven’t been able to complete the work yet. Accomplishments We’re Proud Of The one thing I am happy about is that I didn’t drop the idea or randomly copy a project from GitHub. I have put 100% effort into this project, so I won’t give up and will try to finish it this week. What I Learned Build projects for fun and passion, not just for money. What’s Next for ThinkTankEDU I want to first finish the pending work, and these are the features I will add in the future: Add more AI roles, like a “Project Manager” or “Brainstorming Coach.” Integrate support for more languages and diverse learning styles. Expand gamification with more challenges and achievements. Launch mobile apps for easier access on the go. I want to make it a successful open-source project with all features completely free, without any subscriptions or hidden costs, and create a real impact on students and education. <div
