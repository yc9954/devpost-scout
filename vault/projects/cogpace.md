## Body

Novus AI dashboard — product analytics for CogPace (Mind the Product hackathon) Inspiration Study tools forget how you worked; phones steal focus without a model. Cogram Open is local-first software Open Innovation — Frozen Memory keeps procedural session notes in the browser; an MFA-lite pacing gauge shows when peripheral salience would capture attention vs task pull. What it does Save Frozen Memory notes (localStorage only) Live pacing gauge from task strength S, phone distance, and salience No cloud required for the demo; privacy-friendly for students How we built it Vanilla HTML/CSS/JS + localStorage. Pacing uses F_att ~ S/r² intuition from my MFA attention research — software-only, not robotics.
