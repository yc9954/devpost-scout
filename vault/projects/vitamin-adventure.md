Better to watch on Laptop 🫠 Inspiration 💡 The inspiration for Vitamin Adventure came from the need to educate children about the importance of essential vitamins in a fun and engaging way. This is especially important for children from underdeveloped/poorer countries where education about nutrition is necessary. I wanted to make a simple game that would introduce young children to 4 of the common vitamins: A, C, D and B12, to help them understand their benefits and sources in a creative and fun way. SDG Goals Alignment 🎯 SDG 2: Zero Hunger: This game aims to educates children about essential vitamins and their nutritional sources, promoting healthy eating habits, striving for ending all forms of malnutrition. 🎯 SDG 3: Good Health and Well-being: This game teaches children the importance of vitamins, which will help to prevent deficiencies that lead to health issues like weakened immunity, poor vision, and stunted growth. 🎯 SDG 4: Quality Education : This game provides interactive, engaging education on nutrition and healthy habits, making learning fun and accessible for children, especially in underdeveloped regions. 🎯 SDG 10: Reduced Inequalities : The game can be used in schools, science centers, and mobile learning platforms to educate children in low-resource settings, helping bridge health education gaps. What it does 🏆 Vitamin Adventure is an interactive game that teaches kids about the importance of Vitamin A, Vitamin C, Vitamin D, and Vitamin B12 through engaging mini-games. Each game highlights the effects of these vitamins on health and how to obtain them from food and (in the case of Vitamin D) sunlight. Expectations 🔥 It is my hope that a game like this can be played by children from underdeveloped societies so that they can learn about essential vitamins. I also think it can be displayed as an exhibit in interactive science centres for young children. Children below age 12 can play the games and learn about vitamins in a fun way. How I built it 🛠️ Frontend: Built with React, using React Router for navigation. Styling: Custom CSS with animations for interactivity. Game Logic: Each vitamin-themed mini-game has unique mechanics, such as collecting foods, jumping, and racing. Educational Content: Factual information is woven into gameplay to make learning seamless and enjoyable. Challenges I ran into ⚠️ Balancing fun and education: Ensuring the game remains enjoyable while delivering valuable knowledge. Time limitation: Due to the time constraints, this is only a rough prototype. So much more can be done to improve it. What's next for Vitamin Adventure 🚀 More vitamins & levels: Expanding the game to include more essential nutrients. Certificate: After completing all the levels, the user can email a certificate to themselves as a mark of completion! More effects and attractive UI: The current features are very dry and bare bones. In further development there can be more special effects and sounds and music as well. Mobile app: Deploying the game to an app for wider accessibility - will require reworking some of the game logic to be suitable for mobile. <div
