The game includes single-player and multiplayer modes, allowing you to go head-to-head with friends or challenge yourself solo. Cards come in multiple hilarious themes, all while keeping a light-hearted, meme-inspired design that draws on brainrot culture. Whether you're playing as a lone Sigma or flexing as a Chad in multiplayer mode, Flip-N-Rizzz is all about having fun while testing your memory. How I built it Built with Flutter, Flip-N-Rizzz integrates a robust structure using Dart for smooth gameplay and responsive UI. The game logic was implemented to handle both single-player and multiplayer modes, ensuring seamless interactions between players.The design was influenced by meme culture, with cards featuring quirky, brainrot-themed artwork. Challenges I ran into One of the main challenges i faced during the development of Flip-N-Rizzz was managing the state in Flutter. Since Flutter is not inherently a game engine, handling the game's dynamic state proved to be more complex than anticipated. As a game, Flip-N-Rizzz requires frequent updates to the game state—such as when cards are flipped, matched. Managing this efficiently while ensuring smooth performance across different game modes was a significant challenge.
