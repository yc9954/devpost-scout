## Body

Inspiration We wanted to create a simple, mobile-friendly game that’s instantly fun but also has depth. Inspired by classic timing-based jump games, we aimed to make something easy to pick up, yet hard to master, with endless replayability. What it does Jump Quest Kit lets players tap and hold to charge their jump, then release to leap across randomly generated platforms. Landing in the center of a platform awards extra points. Each run is unique thanks to procedural platform generation, making the game endlessly replayable. How we built it We designed a lightweight system optimized for mobile controls. Platform generation, jump mechanics, scoring, and audio feedback were modularized so creators can easily swap platform models, landing effects, and sounds (jump, land, game over, charging) to customize the experience. Challenges we ran into The main challenge was balancing timing and distance . Too short a jump made the game frustrating; too long and it became too easy. We also had to ensure the procedural platform generation was fair while still unpredictable, keeping the gameplay challenging but fun. Accomplishments that we're proud of We created a game that is intuitive and highly replayable, while also being fully customizable for creators. The combination of simple mechanics, scoring depth, and procedural platforms makes it a robust kit for mobile game development. What we learned We learned the importance of modular design for customization. By separating audio, visuals, and platform logic, we made it easy for creators to remix the kit and create unique versions without modifying the core mechanics. What's next for Jump Quest Kit We plan to add more platform types, special effects, and scoring bonuses.
