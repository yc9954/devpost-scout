Log In Page - Light mode Log In Page - Dark mode Home Page - Light mode Home Page - Dark mode Bank Account View - Light mode SpyMode Transactions Page - Send Money - Light mode Transactions Page - Send Money Dialog - Light mode Transactions Page - Transfer Money - Light mode Account Page - Light mode Inspiration Our project was inspired by Desjardins' core values, such as security, inclusivity, and accessibility. The name of our application is a twist between Desjardins and the theme of the project pitch. What it does Our application is a banking app, where the user can transfer money from one of their bank accounts to another, and can send money to someone else. This is done while adapting to the user's environment, while showing our creativity. The following are the core features of our application: If the phone sees that more than one person is looking straight at the screen, the page goes into secret mode, where spy mode is a text-to-speech banking service. The ambient light in the user's environment will dictate the theme mode of the user's application. When the user is in motion, they will be immersed in a jungle-like environment. Furthermore, the application will show the Home screen while disabling any other navigation buttons, ensuring security. How we built it We built our mobile application using Node.js , React Native , MongoDB , BlazeFace , WhisperAI , Expo Go , and its different audio and movement libraries. Challenges we ran into We were new to a lot of the tools we used, so it was harder at first. We also had some OS limitation issues, where some functionalities worked better on Android than on IOS , and vice versa, so we had to do a lot of workarounds. Accomplishments that we're proud of We really like how everything is interactive and gamified. We never made an application that adapts to our environment. What we learned We learned a lot more about mobile development. What's next for Desjungles Add more security and optimization of our features.
