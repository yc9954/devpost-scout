## Body

AI-powered STEM learning hub with quick access to all features. Overview of Lumora’s core AI learning tools. Step-by-step AI explanations for STEM questions. Personalized AI-generated learning plans. Interactive simulations with real-time AI explanations. Simplified STEM learning for better accessibility. Inspiration We wanted to solve the problem of difficult and non-personalized STEM education. Lumora was inspired by the need for interactive, simple, and adaptive learning using AI for students globally. What it does Lumora is an AI-powered STEM platform with tutoring, study planning, lab simulations, and accessibility mode, helping students learn interactively through explanations, personalized paths, and visual experimentation tools. How we built it We used React and Tailwind CSS for the frontend, Node.js for backend APIs, and structured AI prompts to power tutoring, study planning, and simulation explanation features effectively. Challenges we ran into We struggled to unify multiple AI tools into one platform, design structured and consistent AI responses, and build meaningful simulations without complex physics engines while keeping everything simple. Accomplishments that we're proud of We built a fully working AI learning platform integrating four features, designed a clean and accessible UI, and created an interactive STEM learning experience that feels cohesive and practical. What we learned We learned how structured AI prompts improve educational quality, how UX design impacts usability, and how modular architecture helps integrate multiple features into one scalable learning system.
