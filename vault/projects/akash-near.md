Akash-NEAR Akash-NEAR This project contains everything you need to deploy a NEAR node on Akash network from scratch. Akash is a distributed peer-to-peer marketplace for cloud compute. NEAR is a development platform built on a layer-one blockchain. There are three different types of NEAR nodes , and you can run them all on Akash in a single set of deployment files. Features Super-fast blockchain data download using aria2 . Supports all types of NEAR nodes. Supports custom INIT commands. Simple yet powerful configuration options. Dockerfile and run.sh are included for easy future update and maintenance. <div
