Namespace Activities Properties of activity OutPut Situation: The Graph representation is an important one in the Excel while presenting the reports. It has many kind of graph. And also I have seen the challenge in the Uipath RPA. Solution: I have developed the package with activities called Excel Graph (Chart) Activities . It solves the problem of the above situation. Below the activities details. 1. Bar Chart . 2. Column Chart . 3. Line Chart . 4. Pie Chart . Features: Add chart title for the chart. Copy the graph as Image in a file. Data labels type is an enumeration [ShowNone,ShowValue,ShowPercent,ShowLabel,ShowLabelAndPercent,ShowBubbleSizes ]. Add the lead lines for the chart. Option to the separator for the data label. Show the bubble size for the data label. Show Category Name for the data label Show the legend – True to show the legend to the chart. Show the percentage for the data label. Show the series name for the data label. Show Value for the data label. Fix the Size of the graph (with Height, left, top and width). Future: Have to add more functionalities in the activities. Flexibility and Usability: This is the power of UiPath . It is very flexibility to the developers to develop the custom activities. After the development, it is very easy to use it.
