## Body

Inspiration I got inspiration from seeing big companys with a lot of empolyees and their sustainability and motivation due to lack of professional l personal assistance in sight. What it does It is an eco system that can be personalised for any company, that connects people from the same workspace by giving them tasks that enlarge their motivation and sustainability. It also can be used for solving issues in the workspace. Every employee can also ask some professional infos that are connected to the company. How we built it I made an application that has a log in screen that requires a backend server that we also launched. I also connected chatGPT with an openai library in Pyhton and used my prompt engineering skills to make it more suitable for the purpose of the application. There is already finished UI/UX for the chatbot and the window with the tasks and the photo window for the validation of the tasks. # Challenges we ran into We ran into challanges with the backend server, because to connect it with chatgpt and the application i had to learn some new concepts. Accomplishments that we're proud of I am proud of the backend server that i made because i have never made the server that i made on this hackathon. What we learned I learned how to make backend servers. What's next for LEO - your best personal assistant What makes my project unique is a task-reward concept that makes employees want to do the tasks that the integratet chatgpt with prompts is generating. And next i want to make the rewards more desirable, so like asisas kicks or nike kicks or else.
