Main Menu Simon (Memory) Spot The Difference (Attention) Unjumble (Reason) Times Table (Function) Inspiration We decided to target the themes of "Wellness Tech" and "Social Impact." Our main focus was to create an easy-to-use web app that improves the ability of the brains of seniors. What it does Cognified is a basic app that contains simple games that are specially designed to improve a different specific aspect in cognitive function. We made games to target 4 crucial cognitive elements: Memory, Attention, Reasoning, and Function. Here are the games we have designed: Simon ---> Improves memory and has an added bonus of both visual and auditory feedback. Spot The Difference ---> Improves attention as well as incorporates counting, which is also a crucial task in a senior's day-to-day life. Unjumble ---> Improves general reasoning and also includes language, which is another crucial cognitive ability. Times Table ---> Improves function by combining the previous 3 aspects of cognitive ability, plus the additional aspect of learning, which the senior did in their elementary school days. How we built it We built this app using HTML, CSS, and JavaScript. We turned the app into Android and iOS using the Capacitor framework.
