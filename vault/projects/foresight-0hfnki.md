GIF GIF GIF Inspiration My main inspiration to start developing this game is to prove to myself that I can make a enjoyable game for myself as well as others. What it does Foresight is a 2D game in which the player have pre-input the moves that they are going to play and watch the game unfold once the level starts. The player would have a complete view of the map, based on which they have to pre-input the player moves and press start once ready, after that the game character would move on the pre-inputted path navigating through the level to the next one. How I built it I am using the good old Unity game engine for the development of this game, with the C# language. Challenges I ran into My biggest challenge so far have been Graphics/Art for my game, as I am a solo indie dev with no teammates, I not only have to code but also make art for the game.
