logo Inspiration The project was sterted from the ideea of having a news bot that can be used by anyone without any cost. With this app people will be able to search and follow only the things that they are intrested in. What it does It extract and dissects the latest news using the power of AI. How we built it We built this application using 2 programming languages: PHP & Python.The reason we chosed php was for having the app in a web environement. Python is being used for extracting the content and dissecting it using the power of AI. Challenges we ran into One of the most important chanlange that we have run into was extracting the content and cleaning it. For this we used a python library called newspapper3k and event driven design pattern. Curentlly the project manager (Stefan Izdrail) is looking into creating a multisistem distrubution channel for the data extraction using AWS Lambda. Accomplishments that we're proud of We are happy and proud of the fact that this is using the power of machine learning to create summaries and extract the sentiment of text. What we learned We have learned how to combine 2 different programming languages and doing NLP using the power of Python.
