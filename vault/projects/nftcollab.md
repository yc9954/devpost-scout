basic interface for gltf uploads concept of the seed example how 2D could be translated into 3D (real collaboration case) Inspiration The core Idea Is to build decentralized studio where people can develop 3D characters and environment together. What it does This is seed to make the core Idea life. Where anybody, even If they can't paint or do 3D stuff could start from character (or anything) description text, then artist add a drawing based on this text and the 3D artists add 3D models, skeletons, animation loops e.t.c. How we built it I used Cosmos Archway because of It's core rewarding developers. It allow to make a model when developers would be motivated develop contracts and interface and make such a big Idea life. Challenges we ran into At this moment It's a bit hard to deploy wasm sm-contract to Archway directly from front-end. Accomplishments that we're proud of The Ui reflects the core Idea of the project and could be the seed of the big tree. What we learned I leaned a lot about web 3.0, how It's powerful and cool and how It could change the world. At the technical side I learned a lot about react, next.js, rust, ipfs, smart-contracts types (as cw721 * cw20) and more.
