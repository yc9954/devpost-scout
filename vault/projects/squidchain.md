Home Page Privy.io Connect Wallet Explore Page Game Page - 1 Game Page - 2 Game Page - 3 Aurora Block Explorer ( Squidchain network ) Inspiration The Web3 Squid Game is inspired by high-stakes survival games, but with a twist—AI agents are both the players and the moderator. The goal was to create a decentralized, autonomous, and fair competition where AI decision-making and blockchain technology determine the outcome. What It Does AI-Moderated Gameplay – The game is entirely managed by an AI moderator. It oversees eliminations, rule enforcement, and game progress. Three Rounds of Competition: 1️⃣ Transaction Round – Players must send Aurora ETH; the last to do so is eliminated. 2️⃣ Alliance Round – Players pick a team; one team is safe, while the other is eliminated. 3️⃣ Final Web3 Challenge – The first to interact with a smart contract wins. Smart Contract-Managed Game State – All eliminations and results are stored on Squid Chain (Aurora-based blockchain). How We Built It Blockchain – Aurora Virtual Machine (Squid Chain) Smart Contracts – Solidity (Handles game logic, eliminations, and rewards) Backend – Next.js server functions (Manages AI interactions and game state tracking) AI Agents – Covalent AI Agent SDK Frontend – Next.js (For selecting participants and tracking game progress) Challenges We Ran Into Ensuring Fair AI Decision-Making – Designing unbiased AI behavior for eliminations. Blockchain Transaction Speed – Handling real-time eliminations with smart contracts. Gas Optimization – Efficiently managing transactions on Squid Chain. Accomplishments That We're Proud Of Seamless AI and Web3 Integration – AI agents interacting with smart contracts in real-time. Fully Decentralized Game Logic – No human intervention needed once the game starts. Optimized Smart Contracts – Gas-efficient and secure execution of eliminations and transactions. What We Learned How to use AI agents in decentralized applications. The importance of gas optimization in blockchain gaming. How to orchestrate smart contracts and AI models together. What's Next for SquidChain More AI Personalities – Different AI strategies for players. New Game Modes – Expanding beyond the three-round format.
