Shivarthu: Blockchain based governance and funding system. Inspiration To develop a blockchain based governance and funding system. What it does The goal of the project is to build democratic elections and provide funding to different local projects or work. It's secured by game theory, to minimize corruption and to have optimum price discovery of the projects. How we built it Its build substrate framework and reactjs Challenges we ran into Substrate is a very robust framework with a high learning curve. It took time to learn and implement features like loose coupling, runtime api and rpc. Accomplishments that we're proud of Almost half of the project work is complete. What we learned I learned a lot about substrate framework during the project, and like the framework a lot to develop blockchain apps.
