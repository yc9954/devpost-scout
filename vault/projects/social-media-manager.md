## Body

postman workplace Inspiration As a person who made automation of diverse social media for marketing purposes on companies i saw all the diverse APIs and natures that one has to work with. Wouldn't it be easier to post from a centralized platform for each media (Facebook, Twitter, etc)? This is an approach to merge all this in a single place with Postman's Workplaces. What it does This public Workplace has a collection for each social Media. In the Facebook Collection you can create posts and upload photos via APIs to your facebook page. In the twitter Collection you can use the twitter API to create different tweets. How we built it Created a public workspace to manage all these APIs. Challenges we ran into Battling with access tokens on social media. It was missing better documentation for the APIs, could not find for example openAPI docs or something of the sort to make a faster development. Accomplishments that we're proud of Made a base for any person who want to manage and test its social media, this could help developers and social media managers all over the world. What we learned How to mix and configure APIs workflow through postman, it's very powerful and we could make awesome things with it. What's next for Social Media Manager Complete integration for both Twitter and Facebook APIs, then instagram. Make a better documentation on the collections and workplace. <div
