## Body

Inspiration I have a legal background, so I wanted to create something close to my experiences. A big part of the legal field is construction and property law. So I thought what would an unscrupulous contractor do? And the rest led to Suspicious Skyscraper. What it does It is a game where you have to build the tallest structure in the city. You have to use the inventory available to build a structure. You have only 90 seconds. A new post is automatically created every day. Players can earn highs scores. How we built it I build this using JS and Phaser. Challenges we ran into Determining the appropriate game engine was difficult. Additionally, integrating with Devvit was a challenge, especially communications between the application and webview. Accomplishments that we're proud of As my first game, this is something I am proud of. I worked really hard for this and it was a great learning experience. What we learned So much about game philosophy, development, and deployment. What's next for Suspicious Skyscraper I look forward to continue improving on the game, creating seasonal events, and custom opportunities for the most frequent players.
