## Body

Inspiration I wanted to create a fun and fast-paced quiz game powered by AI, where players test their knowledge, think quickly, and earn points for correct answers. The goal was to make learning engaging while adding an element of challenge through a timed format. What it does Players have 135 seconds to answer 25 questions. Each correct answer earns points. AI dynamically generates new questions to keep the game fresh. How we built it During the development of MindCraft AI Quiz Game, I learned: How to design a real-time quiz system with score tracking. Implementing a 135-second timer for added challenge. Optimizing user experience with seamless question transitions. Challenges we ran into Optimizing AI-generated questions for accuracy and variety.
