## Body

Axie Infinity Dashboard (Phantom & Ronin wallet backed up to same seed phrase) Choose Network Modal Home Page Connect Phantom Wallet Inspiration Compound Finance is a crowdsourced repository of fungible assets that anyone can access. The inspiration for Neftify is to do what Compound Finance does, but for yield generating NFTs. What it does Neftify crowdsources game NFTs and loans them to players. Lenders earn a share of play-to-earn rewards, while players can participate in the decentralized game economy. How we built it For the logo, we used Fusion 360, and for the design, we used Figma to create the frontend mockup. For the frontend, we used vue.js, tailwind.css, headless UI, tailwind UI, and web3.js, web3modal.php, and solana-web3.js. We will be using Metaplex to launch our own self-hosted NFT storefront for tokenized real-world assets. Challenges we ran into We ran into issues while integrating Phantom wallet with creating a signed message and using the resulting signature to verify the message using the publicKey. Accomplishments that we're proud of We bootstrapped a working platform with a 1,000+ member community, ~$30K gross monthly revenue, and 153 real users in our first month-and-a-half of operation. What we learned A lot. It's called TweetNaCl because the whole library fits into just 100 tweets. What's next for Neftify We plan to add markets for Solana-based play-to-earn games like Star Atlas and DeFi Land and explore the tokenization of real-world capital goods (on Solana) to generate yield and stream it back to the wallet holding their token representation.
