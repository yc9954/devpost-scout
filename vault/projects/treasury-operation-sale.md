## Body

Inspiration When the support team said it is difficult to extract data from poor quality where as our volumes were high pertaining to specific supplier, we tried to find other ways to extract data from IQ Bot mapping the labels differently. What it does Extracts data from PDF Invoice where document document quality is less and no proper labels to be mapped. How we built it We used keywords that are available in document instead of actual label to extract data Challenges we ran into It was difficult into table format where we don't have the source data in the PDF as table with proper headers. What we learned Though if we don't have proper labels to be mapped to extract data, we can use the repetitive keywords by which we can extract data using IQ Bot.
