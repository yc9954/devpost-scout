> This is a web game where users can learn grammar and vocabulary from different languages like spanish and french from flashcards and then complete a quiz to test what they learned.

## Body

Inspiration I was inspired by dualingo. I was in ESL growing up and I learned how to speak english from coursework books. I find it easier to learn a new language grammar from flashcards and quizzes. What it does the web game tests your knowledge using quiz after you study from flashcard. How we built it I built it using mathematica and javascript. I created a dictionary of grammar, vocab and conversation in french and spanish and i created a api on the wolfam cloud. Challenges we ran into the challenge that i ran into was fetching the api. I ended up just downloading it on the project folder. Accomplishments that we're proud of I am proud of completing the project fully. What we learned I learned that you can learn a lot from a simple web app! What's next for Language Learning Game next, I will implement a multiplayer mode for collaborative learning! <div
