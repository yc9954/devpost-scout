## Body

Login Page Investments Transactions Dashboard News Inspiration: Seeing our peers struggle with managing their finances inspired us to create PocketPal. We realized that jotting things down or talking about them could solve half of the problems. With this idea in mind, we set out to simplify money management and ease associated stress. What it does: PocketPal is more than a typical spreadsheet. It offers intuitive tools like tables, charts, and graphs to help users visualize their financial data. From tracking transactions to managing investments and balancing accounts, PocketPal provides valuable insights into users' financial status. How we built it: Our journey with PocketPal started with exploring new technologies. We considered Python but ended up diving into Node.js to broaden our skills. We began by setting up databases for efficient data storage. Then, we carefully developed a range of features, ensuring smooth integration. Finally, we focused on designing an intuitive user interface for an enhanced user experience. Challenges we faced: Generating graphs was a major challenge. Manual data entry for visualization took up a lot of time. Integrating email services was trickier than expected, but we found Nodemailer to be reliable and flexible. Accomplishments we're proud of: Our robust email service and sophisticated graph generation capabilities are our biggest achievements. These features not only improve user interaction but also offer clear and insightful visualizations of financial data. What we learned: Our journey taught us a lot about Node.js and MySQL. We improved our coding practices for better readability and maintenance. What's next for PocketPal: We plan to continuously improve PocketPal by enhancing functionality, refining user input processes, and expanding the user interface. Error handling will be a priority for reliability. We also aim to introduce a public chat feature, making PocketPal a comprehensive financial management platform.
