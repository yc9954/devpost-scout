ContextQA Logo Problem-1 Shift-left strategies Inspiration Software development teams use three or more tools for software project management, test management, and requirements management, creating an alignment issue between team members. Also, due to a lack of visibility and programming skills required to identify quality issues early in the process, non-programmer team members cannot help improve quality. I wanted to solve software quality-related problems using automation and team collaboration rather than adding more processes. JIRA platform has full capability of connecting dots. So, I came up with a product called ContextQA . Improving software quality is directly related to the visibility and traceability of open problems and current development work. What it does The ContextQA is an end-to-end software testing solution that aims to provide visibility and empower Jira users to collaborate in creating software test automation to deliver products faster with higher quality . This tool creates test automation using AI-based Low-code | No-code | Pro-code features. Features UI Testing API Testing Performance Testing Load Testing Native JIRA Integration CI/CD Integration How we built it ContextQA developed a unique AI-driven platform that performs UI Testing, API Testing, Performance Testing, and Load Testing without writing code. Playwright framework is used to perform UI automation. Platform apps currently running in AWS . Challenges we ran into There are limitations to using UI Kit. There were so many errors we got during development for which documentation is not available. Also, we were not able to add a great visual interface as we chose UI Kit to move forward with. Accomplishments that we're proud of Generate test automation using No code | Low code | Pro code from JIRA is an extremely powerful feature that we are proud of. The same test automation can be used to run performance testing and load testing. Due to native JIRA integration, all quality-related information can be added to JIRA issues in real time which will provide greater context to developers. What we learned We developed the JIRA app for the first time using the Forge framework. This option opened so many opportunities for us to link other parts of the software developments with JIRA and provide a single pane of glass for product development, delivery, and maintenance. What's next for ContextQA integrate the ContextQA app with Attlasian's release management and service management tools to provide more context to developers, SRE, and support teams that can help teams to resolve issues faster and help with continuous deployments. <div
