## Body

Inspiration To manage any kind of pandemic in the world that is possible to happen. Both patients and administrators will be able to contribute and access the system to manage the pandemic (CoronaVirus). What it does Basically, this project is about managing any kind of pandemic that can happen in the world. But for now due to the current Covid-19 pandemic we will be focusing on that. To manage any kind of Pandemic we need some basic element. Those are mentioned below as features of our project. Here, anyone can find ICU, Medical Facilities, Blood Bank, Vaccine Details, EDoctor and can stay up to date about the pandemic’s current situation. This system interface will be user friendly and easily accessible. How we built it Details of the Features: I. E-Doctor: Here, you will find the symptoms of the Virus (Coronavirus), its primary treatment and the necessary steps that should be taken. II. ICU: Here, you will be able to find the total number of ICU list and its Hospital name, Location, Tele-phone numbers and the vacancy list. III. Blood Bank: Here, you will be able to find the total number of the blood donor list and their name, Location, Contact numbers and past date of donation. IV. Medicine Facilities: Here, you will find the Name list of medical stores that provides door to door service, Location (branch) and their Cell numbers. V. Vaccination: You can get to know about vaccine availability. VI. Pandemic Updates: It will keep you updated about the number of people affected people, recovery rate and the death rate per day.
