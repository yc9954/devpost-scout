# Dungeon Fitness

> Dungeon Fitness is a unique mobile web app that gamifies exercise through RPG-inspired workouts. Choose your own adventurer class and unlock a curated set of thematic exercises today!

## Body

Home Screen Inspiration Finding a new way to gamify exercise by using RPG elements to reframe workouts What it does Has the user take a test to assess their "stats" (Strength, Dexterity, Constitution, and Intelligence) to help provide an idea of where one may be lacking. This then provides a UI to allow class selection (Ranger, Barbarian, Monk, Mage, etc.) to allow the user to see a curated list of workouts best suited towards the class they want to train for. How we built it Using a common technology that everyone wanted to use (Next.js) and taking our experiences of playing RPGs and exercising, we took those experiences to distill down the core elements we wanted to include such as: a fitness test, class selection, stats, and multiple workouts consisting of different types of exercises per class. Challenges we ran into Learning a new technology in a limited time-frame, dealing with different schedules, and communicating how we wanted each piece to fit together. Accomplishments that we're proud of Having something that provides a foundation for our idea and being able to have everyone contribute and have the app still look cohesive due to using a design framework What we learned Don't try to learn a new library in a time constrained manner and using a design framework provides lots of value.
