## Body

Cloud Engineer Partner Inspiration This application is inspired by the author's work as a Cloud Engineer combined with generative AI. What it does This application accepts user input in the form of domain expertise and the desired name. Then, we can chat with the partner who is our assistant to solve problems related to AWS Cloud Computing. How we built it We made this application using Party Rock, which is an Amazon Bedrock Playground product, using several foundation models that have been provided Challenges we ran into The challenges we faced while creating this application were finding a suitable model, especially the Chat feature, which requires the AI ​​partner assistant to have skills based on user input. Accomplishments that we're proud of We ask applications to create Terraform scripts to solve common problems as a Cloud Engineer, namely creating Terraform scripts. Then, we do several follow-up prompts to maximise the resulting script. As a result, the terraform script provided is good enough as a baseline according to the problems faced by users. What we learned In making this application, we tried several models, especially for chatbot features and descriptions, which require 2 different foundation models to get optimal output. What's next for Cloud Engineer Partner Currently, the output produced still needs improvement. Hence, many areas can still be improved, such as further fine-tuning or trying other models that are more suitable based on the cases in our application. <div
