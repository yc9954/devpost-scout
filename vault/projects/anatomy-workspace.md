## Body

Inspiration We wanted to build an anatomy API while learning more about what Postman can do. There's so much functionality there that we hadn't utilised before. What it does Mock server used at the start of development. Collection of requests used with the anatomy API. Monitoring to ensure API is working as expected. How we built it We used a Postman Workspace to help during the full lifecycle of our Kotlin & Spring anatomy API. Challenges we ran into Learning about all of the functionality Postman workspaces provide but there was a lot of useful information online for this. Accomplishments that we're proud of Building the API end-to-end & having a useful workspace now. What we learned All about Postman workspaces, mock servers & monitoring.
