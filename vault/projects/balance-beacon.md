Front Dashboard Breathing Exercise Daily mood tracker Quick acces to helpline and Notes Dashboard Create Alter Journal Page Text Editor All Notes Mood Tracker Page Emotion trigger form Seek Helpline All Alters Exercise Grounding techniques user profile visual chart represenation Menu Note popup Support channel journaling Inspiration Dissociative Identity Disorder (DID) presents unique challenges, including memory gaps, emotional regulation, and focus issues. We wanted to create a supportive, easy-to-use digital tool that helps caregivers track emotions, manage triggers, and encourage mindful engagement. What it does It provides a quick access to the caretaker of the patient to enter the emotions and triggers of the patient then visualize the effects in the chart form, on weekly and daily basis. A dedicated platform for the patient in need of grounding to focus on just one thing by giving the patient some exercises that can be beneficial for both their attention and grounding. Following are some features: Mood Tracker: Helps users to input their emotions and the reasons for those. Generates some charts on the basis of those. Journal: A creative outlet where users can write thoughts, feelings, and reflections. Users can access and review their past notes in real-time whenever needed. Support: A Support feature providing quick access to helpful resources and grounding exercises. Essential mental health links for immediate guidance and self-help tools. System Profiles & Customization Users can create System Profiles to document their alters, add descriptions, and assign personalized colors for each identity. Profile: The Profile Settings allow users to enter personal details and preferences. Dashboard: The Dashboard displays the user’s name, creating a tailored and familiar experience. Acts as the central hub for all key features, ensuring seamless navigation. How we built it Tools Used: Firebase Authentication & Firestore for real-time data management. React & Node.js for a seamless, interactive user experience. Data Visualization Tools to create accessible mood-tracking charts. Team Contribution: We built Balance Beacon in a Team of 3 people. Tayyaba – Led the development, integrating Firebase and implementing the system’s core functionalities. Zoya – Conducted in-depth research on existing DID-related apps, helping us enhance Balance Beacon with more engaging and effective features. Maryam – Designed the UI/UX, ensuring that the platform is visually appealing, user-friendly, and accessible for DID systems and their caregivers. Challenges we ran into Setting up Firebase Authentication & Firestore efficiently. Handling real-time data fetching and managing promises. Presenting mood tracker data in a simple, understandable format for users. Accomplishments that we're proud of Successfully integrating real-time mood tracking for caregivers. Creating a structured distraction-management system with beneficial exercises. Designing an intuitive UI/UX that prioritizes ease of use for DID systems. What we learned Optimizing Firebase operations for better performance. Enhancing UI/UX accessibility for mental health applications. The importance of data-driven insights in emotional tracking. What's next for BALANCE BEACON Implementing a secure community support feature for DID systems. Adding a notifications option that gives reminders for healing and grounding. Adding a feature of safety plan for ease of use and quick access in crisis. <div
