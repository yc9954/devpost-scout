## Body

Home page Exercise description page Category selector Video Recommender Similar Equipment If you don't make time for exercise, you'll probably have to make time for illness. I built this app to keep everyone fit and stay healthy in their life. Well for this purpose I built this website and this website will tell you about various exercises related to various body parts, with various equipment and it also tells you about similar exercises related to the other exercises and the video demos of those exercises. I built this website with the help of React js, Rapid API, material-UI, etc. While building this website, I faced some challenges like keeping the data in check, making the website fully responsive to work on all kinds of devices, and trying to fix a lot of bugs while working with the API like empty data or wrong data and various other things. Well, there are challenges while building a website but after facing many problems and going through a lot of hard work we managed to build the website and make it bug-free, fully responsive, and adding more than 1300 exercises to work with. I learned a lot of things building this website as I got the know the various exercises that a person can do with various equipment, and on the dev part, I got to know how to use Rapid API and how to call an API in a React project.
