AI FOR THE WIN!!!! Creating a Job Post using user based choices Generating Timetable using user based choices Generateing Horoscope by selecting multiple options All the features Submission Categories (WPPOIL) Would Piss People Off on LinkedIn ($25) : 🎯 This project perfectly aligns with the satire this category celebrates. I Laughed (New Hackers Prize) : 😂 Submitting as a "new hacker" who has attended fewer than 5 hackathons, this project aims to bring smiles and giggles to everyone. Inspiration The idea for LinkedOut was born out of pure exhaustion from scrolling through LinkedIn posts filled with corporate jargon, over-the-top humblebrags, and endless hustle culture motivational speeches. 😩 It was either create a parody app or cry into my coffee. ☕ I chose to laugh. LinkedOut became a space to mock these trends while delivering some much-needed humor to break the monotony. 🎭 What it does LinkedOut features: ✨ Horoscope Generator : Your LinkedIn archetype determines sarcastic and hilarious predictions. 💼 Job Post Generator : Craft snarky, exaggerated job posts poking fun at unrealistic corporate demands. 🕒 Timetable Creator : Ridiculously detailed hustle culture schedules that mock toxic productivity. It’s an app that makes you laugh at the absurdities we encounter in corporate life. 😂 How I built it Frontend : 💻 Crafted using React, TailwindCSS, and Next.js for smooth interactivity. Backend : ⚙️ Flask APIs to process requests and generate witty responses. Tools : 🛠️ Integrated Google Generative AI for sarcastic brilliance. AI Models : 🤖 Navigated through Hugging Face to find suitable models, only to realize my computer thought running them was a bad joke. 🙃 Challenges I ran into Building LinkedOut was like juggling flaming swords. 🔥 From frontend-backend integration issues to the painstaking hunt for the right AI models that my laptop could actually run—this project had me on the edge. 🧨 Deploying and debugging under time constraints felt like an emotional workout. 💪 I’m officially dead, but it was worth it. ⚰️😂 Accomplishments that I am proud of 🎉 Completing a functional app that’s not just useful but hilariously entertaining. 🚀 Figuring out creative workarounds for hosting challenges while staying focused on core features. 🤩 Learning to laugh through the pain of endless debugging sessions. What I learned This project taught me: 💪 Resilience : Because the code will break, and you just have to keep going. 🛠️ Adaptability : Trying out different AI approaches and learning from each failed attempt. 😅 Humor : A dash of humor makes every challenge a little more bearable (even when debugging at 3 AM).
