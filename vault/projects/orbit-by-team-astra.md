View Accounts Create Account Transaction Agenda View Schedule New Transaction Home Sign Transaction Add Name Calendar Dashboard Settings Review and Create Orbit Wallet Add signers and Threshold Inspiration The idea for Orbit emerged from the increasing need for organizations to manage their finances collaboratively and securely. Traditional financial management systems often lack transparency and require trust in a single individual, leading to inefficiencies and potential fraud. Additionally, we observed that existing interfaces were not very web2 friendly; users found it challenging to navigate complex systems for payment reminders. Inspired by simpler, more intuitive interfaces like Google Calendar, we aimed to create a solution that enhances security, promotes teamwork, and simplifies budget management with a familiar and user-friendly design. What it does Orbit is a multisig wallet designed for organizations to manage their monthly budgets and scheduled payments collaboratively Orbit addresses key challenges in organizational financial management by streamlining the use of multisignature wallets. Our unique selling proposition is the innovative Calendar UI, which integrates directly into the multisig wallet. This feature allows users to visualize scheduled transactions, set approval deadlines, manage notifications, and enhance team collaboration, making the management of shared funds more efficient and transparent.. Key features include: Multisig Security : Requiring multiple approvals for transactions significantly reduces the risk of unauthorized access. Smart Scheduling : An interactive calendar displays upcoming payments, allowing for easy visualization and planning. Budget Mastery : Organizations can set, track, and adjust their monthly budgets effortlessly. Collaborative Decision-Making : The platform fosters transparency and teamwork, ensuring all members are involved in financial operations. How we built it The development of Orbit involved a structured approach: Front-End Development : We designed a clean and intuitive user interface with a responsive layout to enhance user experience. Back-End Development : We established wallet architecture and created smart contracts to manage multisig transactions. Integration : We integrated a scheduling interface that allows team members to set up monthly payments in a user-friendly calendar format. Voting Mechanism : A voting system was built to ensure all transactions are approved by the required number of signatures before execution. Challenges we ran into Throughout the project, we faced several challenges: User Interface Design : Balancing aesthetics with functionality to ensure an intuitive user experience required multiple iterations. Smart Contract Security : Signature Verification on chain was very painfull as we were getting different hash due to some minor issue which took a look of time. Team Coordination : With a small team, coordinating efforts and responsibilities to meet project deadlines was a challenge. Accomplishments that we're proud of We are proud of several key accomplishments: Successfully creating a fully functional multisig wallet with a seamless user interface. Implementing a unique calendar feature that allows for easy scheduling and visibility of payments. Conducting thorough testing and security audits, ensuring that our platform is secure and reliable. What we learned The development of Orbit taught us valuable lessons: Importance of Collaboration : Effective communication and teamwork were vital for overcoming challenges and ensuring project success. User-Centric Design : Prioritizing user experience in our design process significantly impacted the overall functionality of the application. Smart Contract Best Practices : We gained insights into secure coding practices and the importance of rigorous testing in blockchain development. What's next for Orbit Looking ahead, we have ambitious plans for Orbit: Launch and User Testing : We will launch the platform and gather user feedback to refine and enhance its features. Feature Expansion : Implementing additional features based on user needs, such as reporting tools and enhanced analytics for budget tracking.
