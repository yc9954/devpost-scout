## Body

Elevator Pitch: A web app used to train reading and speech fluency. About the Project Inspiration We got inspiration for creating a speaking test from typing tests and it follows the same concept of having to type/speak a text within a certain time limit. What it does This web tool is used to calculate how fast, fluent, and accurate we can read by conducting a short test and multiplying our word per minute by our accuracy to give a final score. Improving reading fluency is also shown to improve our reading comprehension so this web tool also helps us improve our reading ability. How we built it We first designed the layout of the pages which we wanted so that we all knew what we wanted to build and how we wanted it to look. We split the work up with some working on the background and navigation bar, the components, and the back-end. We communicated with each other and were able to work productively together. Challenges we ran into It was our first time working with APIs, and we spent a lot of time doing the basic setup in order to start using the API. We also struggled with using Git, as it was our first time using it. Accomplishments that we're proud of This was out first time using Git with a project, so we were pretty glad that we were able to navigate it relatively easily. This was also our first time using a speech to text API, so we are also proud that we were about to get it to work, albeit after lots of bugs and hours of coding. There was also one member of our time who was a first-time hacker, so we were glad that we had the chance to work with and train her for future hackathons. What we learned We learned how to use APIs such as Symbal.ai. We also learned to use git to push and pull code from github. We also became more proficient in React and were able to create a unique UI. What's next for Fluencity We are aiming to improve the UI for the testing screen so that it highlights words that the user has pronounced incorrectly. We also want to implement other modes as well, such as singing or rapping, which will give users a song or beat to sing along to. For the singing mode, we also want to add a note indicator to let the user know if they are off pitch or not. In the future, we also want to add the ability for users to add their own text to get tested on. Also, we want to improve the leaderboard feature so that all users will be able to see and share their achievements. <div
