# ViraTrace

> Infection Model that goes beyond the first degree of interaction, allowing for up to 3x increase in detected cases for any contact-tracing tools that use it.

## Body

ViraTrace is a contact-tracing solution centered around a unique logical model that allows accounting for multiple degrees of interaction. This means it detects up to 3x more active cases than the standard approach employed by PEPP-PT, DP-3T, Google & Apple, etc. Recently integrated into the official Indian contact-tracing app "Aarogya Setu" We have two short term goals: Get the infection model implemented in more/all contact tracing apps; Build an alternate technical architecture based on Trusted Execution Environment (Secure Enclave) servers which allows additional data analysis resulting in the following value propositions: Protect high-risk individuals (sick, elderly, etc) by designing a network topology that only allows safe interactions.
