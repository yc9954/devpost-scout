## Body

Fire meets gasoline ! Diesel Attack NFT Collection Machine Hunt Weapon NFT Nautilus Ship NFT Ravenous town Sparky rain Deep lurker Who calls excavator ? Inspiration Our team has been developing mobile and browser F2P games for more than 7 years already. When the first popular games based on cryptocurrency began to appear, we saw an extremely interesting opportunity. Crypto Heroes, Era7, BrownDust, etc. - are few examples of Web3 games containing solid and entertaining gameplay. And we decided to give it a shot, we chose hackathon track Web2 to Web3 because we already have a beautiful post-apocalyptic world of Diesel Attack, world inhabited by wonderful mechanisms and bring it to Web3. How we built it Welcome to the steampunk world. Diesel Attack - is a RPG 2D-sidescroller game, with a simple entrance point and intuitive navigation system, but with deep character development (spoiler alert: your character is a diesel machine); offers gameplay that make player face a lot of challenges - experience gaining, obtaining unique weapons and rare grades, progressing through the storyline and of course, killing terribly beautiful bosses. An open economy based on NEAR will allow players to exchange weapons, ships, accelerate progress and increase engagement due to the real value of items. Technologies we used The game itself is built on the Unity Engine Smart contract is implemented using NEAR SDK NFT arts are hosted on IPFS thanks to Nft.storage Backend API server is running on Fastify (Node.js framework) AWS EC2 and Route53 for backend server and landing page hosting and availability Accomplishments that we're proud of After learning about the hackathon, in just three weeks we were able to port existing game with traction Diesel Attack to Web3, while integrating NFT smart contracts on the NEAR blockchain and lay the foundation for an open world economy system (players will be able to buy and sell NFTs representing ships, weapons, etc).
