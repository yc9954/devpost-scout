## Body

logo word cloud in postman named entities Inspiration We are passionate about NLP and want to help in democratising it. We took this opportunity to make simple collections for developers to use. What it does The workspace contains two collections. The first one contains APIs built using the spacy and textblob libraries. The APIs run tokenization, lemmatization, named entity recognition, sentiment scoring and plot a word cloud. The second adds on Wikipedia library using some APIs of the first. How we built it We used flask to build the APIs and stored them as postman collections. Challenges we ran into Setting up monitors and getting an image to render in the response field of postman. Accomplishments that we're proud of Building working APIs. What we learned Postman Workspaces, collections and mock servers.
