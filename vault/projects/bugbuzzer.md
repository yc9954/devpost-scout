## Body

BugBuzzer Inspiration The problem we are solving is that in current tech forums, developers invest their time to contribute and help other builders but in return, they are being given an illusion of getting value in the form of “Upvotes, Rating/Reputation” and real value is being taken by platforms only. What it does BugBuzzer is token gated community platform for Developers and Organizations to Crowd source Bug Reporting, Technical Q&A forum and one on one live tech support. It enables developers to gain value for their expertise by giving answers in tech community forums and created token gated community to provide personal tech support to NFT holders. People can ask questions and can get the solution of their Bugs in nearest time. How we built it In this project we have used solidity to create smart contract for the NFT membership which is deployed on polygon mumbai network. Used different authentication methods like web3 auth, login with Unstoppable domain, login with Worldcoin etc. Used covalent to get the number of NFTs. Stored data of ipfs. Challenges we ran into So the most challenging part was nft readership. Got so many issues while implementing that. Accomplishments that we're proud of Implementing the nft readership and give options to the user based on nft they hold was the part we proud of. What we learned While building bugbuzzer we learned a lot. We learn how to create something which is based on the nft user hold so learned how we can create different token for the different developers and builders. <div
