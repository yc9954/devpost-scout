## Body

Inspiration In life people want to avoid threat and bully or bad people. Thus, we want to build a game about courage and being able to avoid the bully. What it does Main character has to avoid the bully as many times as he can. He should not move when there is no bully. If main character moved when there is no bully, the game is over. When there is bully, the main character can move. Each time the main character can avoid the bully, he gains one point. If the main character meets the bully, the game is over. The score will be displayed when the main character loses.
