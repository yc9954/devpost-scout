## Body

Inspiration What inspired us to make this project could be best described as frustration. Times when we searched google endlessly for the right place to get dummy data or didn't know what to use to get them, set reminders for work with no hassle, Secure some information and having a place that provide the information about dependencies without searching endlessly on google. What it does Solace is a many-in-one API that aims to simplify lives of all developers and help them focus on things which is important. 1) Reminders: Easily set up reminders, add a date, time and the reason for the reminder and thats it when the clock hits the said date and time, a personalised email pops up in your inbox reminding you about that task you set up and keeps you on schedule 2) Dependency Trackers: Ever wanted to be the first one to receive updates about your favourite npm package? Well Solace not only gives you all the information about a npm package but also gives you a way to track these dependencies and whenever the package undergoes a change in version , an email is triggered right into your inbox notifying you about the change and giving you all the latest info about it. 3) Data Vault: Get you very own vault where you can store any data you want without the fear of it being stolen or lost. Solace provides you with any number of vaults you wish and gives you a unique vault ID for each vault you create, all the data you store is cryptographically encrypted with the famous 2-way AES 256-bit encryption so that only you can read/edit this data whenever you need it 4) Dummy Data Generator: Solace let's you easily generate out 1000s of dummy user profiles within milliseconds, it can also generate full length addresses, emails, uuids, Lorems, Full length Company profiles and even Custom dynamic data How we built it We had a Top-down approach to our work. As we began working on this project we came across our own ideas and started implementing them into our project. We think it's the perfect approach to help aid the very thing we were doing: Developing Challenges we ran into We faced quite a few problems during our time developing this api. Some could be attributed to a lack of consensus, direction or sometimes even our impatience and dumb mistakes. One Example that sicks is probably the has a mixture of frustration and laughter attached to it. At we reached the end of our stamina working towards completion a mistake by one of us could not be more comical as we spent hours scouring to fix what we did. But moments like this brighten our day and we ended up with a funny story to talk about after. Accomplishments that we're proud of Im proud that we managed to make something we personally would use and that inherently was a massive driving factor for our project. What's next for Project Solace We plan to add many more modules in the future which enhance the working and serves as a even more powerful and useful API for anyone out there.
