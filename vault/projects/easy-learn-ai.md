## Body

Inspiration Students often struggle with long study materials, unorganized notes, and a lack of personalized learning support. We wanted to create a tool that makes learning simpler, faster, and more interactive — directly inside the browser. That idea became Easy Learn AI, your AI-powered study companion. What it does Easy Learn AI helps students learn smarter by offering instant features like topic explanations, summaries, quizzes, study plans, page analysis, a clean dashboard to track progress, and a distraction-free focus mode — all inside one browser extension. How we built it We built Easy Learn AI using HTML, CSS, JavaScript, Chrome Extension APIs, and an AI/LLM API. Content scripts handle webpage interactions, background scripts manage communication, and the UI is built as modular pages (sidebar, dashboard, focus view). AI features power the explanations, summaries, quizzes, and study plans. Challenges we ran into We faced challenges integrating multiple tools without affecting browser performance, creating a smooth sidebar UI, managing data flow between background and content scripts, and maintaining a clean, distraction-free design while packing in many features. Accomplishments that we're proud of We successfully built a complete learning assistant inside a browser extension. Key achievements include creating: ✔ Smart study plan generator ✔ AI summaries and topic explanations ✔ Auto-generated quizzes ✔ Clean dashboard for tracking progress ✔ Focus mode for distraction-free study Turning all of this into a simple, user-friendly tool is something we’re very proud of. <div
