## Body

Inspiration Several projects have a similar need of generating PDF documents like invoices, reports, etc. PDFit attempts to utilize open source iTextSharp and provide API service for any application. What it does Generate PDF formatted files from content of other formats - HTML, URL, Excel How we built it Leveraged open source iTextSharp libraries and developed a web service using Microsoft .Net Core technology. Challenges we ran into Implementation of error-handling, request limiting, and handling CSS styling in HTML content for PDF generation. Accomplishments that we're proud of Any other project do not need to worry about PDF generation. What we learned PDF file handling, Web Service development. What's next for PDFit Implementation of PDF generation for Excel and Word documents. <div
