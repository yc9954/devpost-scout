Landing Page Transfer funds using Custodial Account Transfer funds using Non Custodial Account Execution of Transfer Inspiration We wanted to buy crypto without using centralized exchanges What it does THEO is enables seamless B2B transactions with privacy solution based on Double Hashing It allows 2 parties to communicate and transfer funds in a secure and private manner. Theo also brings the concept of B2B contracting and payout to the Hedera network, adds the immutability of utilizing an stablecoin, USDC, and ensure confidentiality of both parties by using Double Hashing How we built it We used React for front end Circle API - Custodial Account Hashpack - Non Custodial Account Firebase - Backend Privacy of Transactions - Double Hashing Receipt of Transactions Storage - Filecoin (web3. Storage) Hedera Blockchain Challenges we ran into We had challenges regarding using the Circle API especially in terms of sending Stable coins to Hedera Wallert Accomplishments that we're proud of Created an MVP and ability to work with the Circle API What we learned We learned from a technical aspect how to use the Hedera blockchain using Hashpack and the circle API Soft skills: We also learned to work in a fast paced environment where diversity is key. We have a team of Blockchain Developer, Front End and Project Management. This allowed us to be more emphatic and trust the expertise of each other. What's next for THEO We created a very simple MVP and we want to proceed creating zk snarks instead of Double Hashing. However, due to time constraints we we unable to do Zk Snarks We will also talk with prospective Investors for Funding opportunities to continue the project. It is also important to receive feedback from Users (Companies) who are interested in creating using the platform.
