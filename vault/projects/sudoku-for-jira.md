## How they structured the write-up

- just a simple sudoku game that uses jira api to get ticket information and then based on these infos sets up the difficulty and the number of hints used by the user for each level
- we only used react and forge, we wanted to use forge components to build the entire game but that was difficult for us
- consuming jira api was the most challenging part. because we only work on confluence so we had a rough looking for the best way to save and update the highest_score between users
- designing such a game even if it's simple was a joy. because the two of us didn't know anything about games before this hackathon except how to play them.
- we have tried to build a game with phaserjs but we weren't able to complete it, but we learned a lot of things about the game industry and how games developers should think, and many concepts like colliders and physics
- what's next for sudoku for jira
