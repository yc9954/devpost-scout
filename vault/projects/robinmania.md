in-game marketplace Exploring the map Fighting Monsters Minting the Silver Sword Dungeon Main Menu RobinMania Inspiration In recent years, we’ve witnessed a big leap in the gaming industry, the introduction of play to earn concept, which was later identified as the best recipe to actually turn a game into pay to win. Crypto whales and developers are mostly using this opportunity to pump and dump, leaving players with big losses and with unsatisfying gaming experience. What we built/ What it does Robin Mania is a community driven 2D multiplayer RPG game combining adventure, action and story into one place. You can join with your friends or discover new ones in the game to do quests, challenges and interesting battles. The game items are NFTs that you can freely trade, buy or sell with anyone on the blockchain. You can also participate in decision making through our DAO. How we built it We made 3 smart contracts using hardhat for development, testing and deploying on test network. One smart contract is for the game items, one for the NFT Marketplace and another for auctions. We also built some game features using Unity game engine and we made our own plugin to interact with the blockchain through webGL. Accomplishments that we're proud of We have made 5 items so far, one of which is a key that will allow you to enter the dungeon. You can also skip the minting part and check the vendor to see if anyone is willing to sell his items. We have also built a fully functional marketplace using ReactJS for the front end and EthersJS to connect to the blockchain. Challenges we ran into As this is a two-month project, we weren’t able to accomplish everything we’ve set and we certainly weren’t able to build a community and get feedback. But we will continue to work on the project and we set this road map. What's next for RobinMania The first thing on our list is making a DAO for the game, this includes making the game token and allocating 23% for the DAO treasury and getting early funding. In parallel we will be optimizing the game, adding multiplayer features, ERC721 NFTs for characters, upgrading the map and receiving feedback from the community. The second step will be deploying a beta version for the public on mainnet, gathering initial player base and marketing the game. The third step is getting the game token listed on major crypto exchanges. And the last step is making the project more and more community driven and decentralized allowing players and DAO members to make decisions. What we learned We acquired professional knowledge of how to create a completely functional marketplace using cutting-edge technology. We got the chance to learn more about tokenomics, NFT standards, and how to use them in the GameFi ecosystem.
