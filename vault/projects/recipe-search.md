## Body

Select three ingredients! Get the list of recipes which include the specified ingredients! Preparation time! Inspiration No idea what to cook for dinner led up to this project idea. What it does It helps hungry developers find a recipe which includes the three ingredients which they specify. For example: Type "sugar" in the first textbox, "milk" in the second and "honey" in the third. Press "GO" and choose from a list of recipes availabe! How we built it The iOS application was build using Swift. Challenges we ran into Some recipe's websites show an error due to the recipe being present in the API for all recipes, but once calling the API based on the recipe ID and name an error would be shown. Still need to work on this! Accomplishments that we're proud of It works! It took some time to figure out how to do it, but it finally works! What we learned That connecting API to mobile phone apps is very useful, powerful and rather easy to make. What's next for Recipe Search Removing the recipes which don't exist (even if the first API call shows them). <div
