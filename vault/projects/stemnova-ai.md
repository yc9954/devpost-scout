## Body

Inspiration We were inspired by the fact that many students struggle with STEM subjects because learning is often the same for everyone, even though every student learns differently. Some students need extra explanations, some need practice, and others need visual learning. We wanted to create a solution where every student could have access to a personal tutor anytime, anywhere. What it does STEMNova AI is an AI-powered STEM learning platform that helps students learn subjects like Math, Science, and Coding in a smarter way. It provides personalized lessons, instant doubt solving, adaptive quizzes, and interactive practice based on each student’s learning level. It makes difficult topics easier to understand through step-by-step explanations. How we built it We built STEMNova AI using: Frontend: React.js for a clean and interactive user interface Backend: Node.js / FastAPI for handling requests AI Models: OpenAI API / LLMs for tutoring and explanations Database: Firebase / Supabase for storing progress Visualization Tools: Chart.js and simulation libraries for interactive STEM learning We designed the platform to track student progress and recommend lessons based on weak areas. Challenges we ran into Making AI explanations simple enough for different age groups Creating personalized recommendations accurately Managing response speed while using AI APIs Designing an interface that is easy and fun for students to use Balancing educational guidance without giving direct answers only Accomplishments that we're proud of Built a working AI tutor for STEM subjects Created adaptive learning paths for students Added instant doubt solving with clear explanations Designed a scalable platform that can help students globally Combined education and AI into one impactful solution What we learned We learned how powerful AI can be when used for education. We also learned the importance of user experience, personalization, and making technology accessible. Building STEMNova AI taught us teamwork, problem-solving, and real-world product development.
