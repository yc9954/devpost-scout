## Body

Inspiration This project was inspired by the Truflation index and the use cases It could have. What it does It's a lottery that generates random tickets in a known range using ChainlinkVRF. At the end of each week the smart contract will make select the closest ticket to the Truflation index of that day and pay the owner of that ticket. How we built it The dApp to uses the Truflation's inflation index and ChainlinkVRF. It's built with ReactJS and Moralis API working Polygon Testnet. It's also using the Finity design system, implemented with Tailwind.
