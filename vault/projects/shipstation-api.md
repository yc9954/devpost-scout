## Body

ShipStation is a shipping software that helps in processing and shipping orders from all the most popular marketplaces and shopping cars using all top carriers. This API collection helps those who want to integrate their store or app with ShipStation. What it does This collection provides different APIs to interact with different ShipStation functionality, like get available carriers, create order, create labels, get rates and many more.
