## Body

Inspiration I always wanted to help content creators, that's the reason I created Smart Sharer. What it does Smart Sharer can share the content of our community members on Twitter and by sending the newsletter. How we built it I used Postman, javascript, and API's to build this Public Workspace Challenges we ran into I didn't use the SendGrid API before, this was the challenge I ran into. Accomplishments that we're proud of I made something that's really useful for community members and helps them to share their content that's what I am really proud of. What we learned I learned about how to make API calls conditionally, how to work with postman monitors, and how to save API keys securely inside the environment variable.
