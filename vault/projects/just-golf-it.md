## Body

Inspiration I enjoy brain teasers, challenges and when the mini golf idea hit me it was obvious it would fit in for a daily casual challenge to solve! How we built it I used unity to make the game, I quickstarted the project with some similar project from the asset store and I got started pretty fast! Challenges we ran into The main challenge was the procedural generation: trying to generate a course that would look good and be playable and fun every single day! Accomplishments that we're proud of Proud to deliver a new game to reddit! What we learned I learned about reddit games through this hackaton and it turns out to be well built for web based game I believe and I will very likely continue using it!
