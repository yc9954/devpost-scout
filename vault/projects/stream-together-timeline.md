## Body

Stream Together Timeline Promo Inspiration I really liked the discontinued Moments feature, so I built Stream Together Timeline to be kind of an automated version of Moments, but for Stream Together . The inspiration behind Stream Together Timeline came from the first hand knowledge on how easy it can be to forget those special collaboration moments that happen on stream and the desire to preserve those moments for the entire community in a way that doesn't require any work from the streamer. What it does Stream Together Timeline keeps track of your Stream Together sessions, including the participants and any clips generated during these collaborations. It displays this information in a timeline that both the streamer and the community can access , offering a user-friendly way to look back at shared moments. The timeline can be viewed directly in a Twitch panel or through a dedicated, fully hosted webpage that can be shared with the community. Accomplishments that we're proud of We’re proud of creating a tool that directly enhances the way streamers and their communities interact with Stream Together. The integration with both a Twitch Extension and the StreamRoutine hosted webpage are key achievements, allowing the timeline to be accessible both on and off the Twitch platform. What we learned This is the second extension that I created for the hackathon, so it was an easier process this time. I was able to re-use code from the previous extension, plus I was able to generalize several of the functions, such as managing the theme of the extension and determining the layout we were in (panel vs. component vs. overlay). So, I'm happy to be able to both manage the code for these two extensions easier as well as be able to crank more extensions out in the future with less time required.
