## Body

Inspiration The inspiration for "Bug Blast" comes from the desire to create a fun and engaging game that combines elements of strategy and skill. The idea of using a cannon to fight against bugs is inspired by classic arcade games, where players use various weapons to fend off waves of enemies. Overall, the game is designed to be a fun and challenging experience that will keep players engaged for hours. What it does "Bug Blast" is a game where the player controls a cannon at the screen's center. The goal is to use the cannon to fire mortars and kill bugs that appear on the screen. The player controls the angle of the cannon using a mouse. How we built it The app was mainly built with React for the user interface and PixiJS for rendering the game. Challenges we ran into The main challenge faced was the initial setup of the forge to start the build. I ran into an issue where the game was supposed to be a separate micro frontend and had issues trying to set it up. Ultimately, I ended up with a monolithic design for the game. Accomplishments that we're proud of This is my first time building a game. I have always wished to create one, but I didn't know how to. Once I learned about Jira, I was able to manage many goals, and finally, I built my first game. What we learned Mostly working with Forge, I initially started using forge UI and later moved to a custom UI. Overall I learned how to create a forge app. Work with documentation. What's next for Bug Blast Hoping to improve the experience by adding many features and making the app an official Jira app. Making it more fun and enjoyable. <div
