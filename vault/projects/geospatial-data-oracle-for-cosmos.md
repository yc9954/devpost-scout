## Body

Inspiration We were inspired to work on this project by the latest report from the IPCC on climate change. We wanted to build an oracle that can provide data to power carbon markets and ESG projects. We also wanted to build the tools to make it easy for developers to work with our oracle and the data it provides. What it does Our oracle provides satellite data from some of the world's top data providers and makes this available in a way that blockchains and smart contracts can use it. How we built it We built the geospatial analytics engine on Google Earth Engine. Challenges we ran into Getting the solution we built locally to deploy to the cloud. Accomplishments that we're proud of Building a working geospatial oracle and connecting it to Cosmos. What we learned We learned a lot about integrating Cosmos with the Chainlink network.
