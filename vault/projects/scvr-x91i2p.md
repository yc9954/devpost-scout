Inspiration All our have came to Junction from Moscow Technology University(MIREA). At the second course we were max interested in VR technology. And one idea of global social VR network come to use. From that time we step by step moving to reach this epic goal What it does Our project is multiplayer VR shooter with using Microsoft Mixed Reality headset. How we built it We built it under ASP.Net Core 2.0 and TypeScript with Babylon.js for front on Azure service. Challenges we ran into ENTERTAINMENT. MICROSOFT WEBVR CHALLENGE Accomplishments that we're proud of Our accomplishments is the combine of WebVR, Lenovo explorer Mixed Reality device and Azure service in one complex solution. Secondly we've deeper learned how to build Web Application based on ASP.Net Core 2.0.
