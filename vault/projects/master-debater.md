## Body

Inspiration We are from the same high school debate club. Due to the current pandemic, we are unable to meet each other, so debating has been infrequent and done on platforms that weren't designed for the purpose of debate. We have tried some platforms that were created specifically for debate, but the UI and the overall experience are underwhelming and outright frustrating for most of our teammates. That leads us to the creation of the Master Debater, a platform that will revolutionize debate. What it does Our product is a platform for which debate groups and communities are able to freely use for their debate activities which may have been inhibited from debate on-site. How we built it We planned out the system upon which we are to model our data around effectively to allow for smooth and convenient transactions. We implement a Javascript framework in which we chose Angular which was built on top of a cloud serverless backend to provide the database to manage our user's data. Challenges we ran into Git is a tool that our team members have used individually but have never learned to use to collaborate together on a project. Accomplishments that we're proud of We were able to implement the voice chat functionality right near the end which we thought we were not going to be able to do. What we learned This project deepened our understanding of the usage of git in team collaboration projects along with the usage of javascript frameworks and how they can be used to interact with serverless cloud infrastructures.
