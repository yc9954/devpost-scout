Kotal Logo Inspiration We want to end centralized API Gateway and node as a service We want to be OpenShift of the Blockchain ecosystem We want to be Gitlab of Blockchain Ops We will do it What it does Deploy nodes, expose API endpoints, stake across multiple Blockchain protocols with little or no DevOps experience using simple API and UI.
