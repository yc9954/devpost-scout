Inspiration The inspiration for "Curse Runner: The Maze Escape" came from a combination of classic maze escape games and the "curses" library in Python. The idea was to create a game that was simple to play but challenging to master, and that could be run entirely in the terminal using the "curses" library. What it does "Curse Runner: The Maze Escape" is a game where the player must navigate through a maze and reach the end without touching the walls. The game is played entirely in the terminal and uses the "curses" library to create a dynamic and interactive game environment. How we built it The game was built using Python and the "curses" library. We started by creating a simple maze generator that would randomly generate a new maze every time the game was played. We then added collision detection to ensure that the player could not move through walls, and created a scoring system that rewarded the player for reaching the end of the maze quickly. Challenges we ran into One of the biggest challenges we faced was getting the game to run smoothly in the terminal using the "curses" library. We had to spend a lot of time tweaking the code to ensure that the game would run smoothly on different terminal sizes and screen resolutions. Another challenge was making the game challenging but not too difficult. We wanted to create a game that was fun to play but also required some skill and strategy, so we had to spend a lot of time testing and adjusting the game difficulty. Accomplishments that we're proud of We're proud of the fact that we were able to create a fun and challenging game entirely in the terminal using the "curses" library. We're also proud of the fact that we were able to create a dynamic maze generator that would generate a new maze every time the game was played. What we learned Through building "Curse Runner: The Maze Escape", we learned a lot about the "curses" library in Python and how to create interactive games in the terminal. We also learned about the importance of balancing game difficulty and creating a fun and engaging user experience. What's next for Curse Runner In the future, we plan to add more levels and game modes to "Curse Runner: The Maze Escape", as well as more features such as power-ups and obstacles.
