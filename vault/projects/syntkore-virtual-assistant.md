## Body

Inspiration IT support team is receiving hundreds of tickets daily to reset the password, unlock the account, fix the issue in the hardware and software. If we somehow automate this process, then we can reduce the work load considerable amount. What it does SyntKore Virtual Assistant is specially designed to handle all IT and HR related queries and share the relevant documents, create ticket in service-now in both as web and MS team. How we built it We have integrated this bot with MS team and Service-Now for easy access to the end user and we also enabled the French language support to help the non-English speaking users. Challenges we ran into We were facing issue in integrating our chatbot with service-now and also faced challenges to enable the multi-language support as translation is not working for button prompt. Accomplishments that we're proud of As part of this implementation, we have successfully launched this chatbot in MS team and Integrated with Service now ticketing tool. What we learned We learnt how to improve the user experience with Multi-lingual support, MS team integration and etc. What's next for SyntKore Virtual Assistant This is just a proto type.
