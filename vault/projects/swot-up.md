User Dashboard Authentication Inspiration Ever spent hours highlighting notes, rereading PDFs, and still feeling unprepared? Same here! That’s why we created Swot-Up —your ultimate study buddy. Born from the chaos of juggling coursework, tight deadlines, and trying to retain all the things , Swot-Up automates flashcard creation, making studying smarter, faster, and dare we say…fun? With the power of AI, we’re here to save you from the drudgery of endless note-taking. Let’s make studying feel less like a chore and more like a win! 🚀 What It Does Swot-Up transforms your study material into bite-sized, interactive flashcards. Whether it’s text you typed in or PDFs you uploaded, our AI works its magic to analyze, summarize, and create question-answer pairs to help you retain more in less time. Plus, it’s all stored securely in your account for easy access anytime, anywhere. Learning has never been this simple—or this smart! How We Built It Here’s the tech stack that brought Swot-Up to life: Languages & Frameworks : Python, TypeScript, JavaScript, React, FastAPI, Next.js Cloud & Databases : Supabase for secure user auth and data storage, GROQ AI for powerful flashcard generation APIs : GROQ Inference API and Supabase Auth API to keep everything running smoothly Challenges We Ran Into It wasn’t all smooth sailing (it never is, right?). Here’s what we tackled: AI Tuning : Making sure the flashcards were relevant, concise, and actually helpful. Let’s just say, our AI went through some serious training! PDF Parsing : Extracting clean text from messy PDFs was like trying to unscramble eggs—tricky, but we got it done. User Authentication : Seamless login, sign-up, and secure user storage with Supabase wasn’t easy, but totally worth the effort. Every challenge taught us something new and made Swot-Up better for you! Accomplishments That We’re Proud Of Smarter Studying : Successfully combined AI and UX to turn any content into actionable flashcards. Secure Storage : Built with Supabase, your flashcards are safely stored and ready whenever you need them. Interactive Design : Created a clean, responsive interface with Next.js and React that works beautifully on all devices. Flashcard Magic : Transformed the tedious task of studying into a fun, gamified experience. What We Learned Building Swot-Up was an incredible learning journey. Here’s what we gained along the way: AI is Awesome : Leveraging GROQ AI to generate intelligent, concise summaries was a game-changer. UX Matters : A smooth, intuitive interface can make all the difference for users. Security is Key : Supabase helped us ensure user data is safe, secure, and always accessible. What’s Next for Swot-Up! We’re just getting started! Here’s what’s on the roadmap: Personalized Study Paths : Use AI to suggest flashcards based on your progress. Mobile App : Take Swot-Up on the go with a sleek mobile app experience. Collaborative Learning : Share flashcards with friends or classmates to study together. More File Types : Expand beyond PDFs to include PowerPoint presentations, Word docs, and more. With Swot-Up, the future of learning is bright, exciting, and oh-so-efficient!
