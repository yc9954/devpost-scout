Inspiration We would like to create a great product that helps company, individuals, and teams to boost the productivity of their work. Our product helps users manage productivity by noting down what needs to be done first, prioritize work through the note taking services. We also provide virtual consultation about how to boost work productivity using our online virtual assistant that was built using wix-fetch, wix-secret-backend, and GPT-3. How we built it We built using wix-data, wix, velo, wix-chat, wix-fetch, wix-data, dynamicdataset, wix-secrets-backend, wix-storage, openweathermapapi, openai and GPT-3. We used wix-chat as well We built the temperature fetch using wix-fetch and openweatherapi We built the office location using wix-data and dynamicdataset We built the note taking work using the wix-storage We built our virtual assistant using wix-fetch, wix-secrets-backend, and openai GPT-3 Feedback and Improvement We got feedback from judge and we changed our project completely with new features of Wix such as incorporating wix-fetch, wix-secrets-backend, and openai GPT-3 to build the virtual assistant Challenges we ran into We had challenges to learn wix and velo to build a SaaS app. We tried our best to make things work together.
