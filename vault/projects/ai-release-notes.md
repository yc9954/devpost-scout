AI Release Notes - the game-changer in software updates. Customize your release notes with just a few clicks. Ready? Let the AI do the magic. Make sure release notes fit your needs and publish them anywhere you want! AI RELEASE NOTES 🙌 What inspired us During everyday work there are tasks that are tedious but important. Sometimes we forget about them because of a constant flurry of tasks. One of such tasks is creating release notes for new versions of the app. But to create them in a short time and with low effort? This is where the AI Release Notes application presented by our team comes to the rescue! ✅ Key features Possibility to choose versions and issues that contain the most important information No need to search for information in issues and versions ourselves, AI does it for you Ability to choose the type of text formatting (html, markdown, etc.). Possibility to choose what details should appear in release notes Different text styles depending on the document's recipient 👨🏻‍🎓👩🏻‍🎓 What we learned Above all, we have learned that a common goal strengthens relationships in a team, even one formed a few days before work begins. Before Codegeist, we didn't know each other, but that didn't stop us from developing high-level communication. On the development side, we learned how to use AI in business applications and how to use webtriggers in the Forge. ⚙️ How we built our project Project built on the Forge platform, extended with atlaskit components with customUI views. We used the OpenAI API as a connection to AI. While working on the components for the views, we used the storybook. In parallel, the work of optimizing the corresponding prompt for AI was going on. 💪 The challenges we faced It will be no surprise that our biggest challenge was time. How to create a helpful and functional application in a short amount of time? Of course, the most important thing was the commitment of the team, which worked tirelessly for many hours in close cooperation. Above that, it was a mystery to us how to connect with AI and use this connection effectively. <div
