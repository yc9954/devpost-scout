## Body

Homepage Inspiration We realised we only knew about negative information (e.g. infected people), and we wanted to bring some positivity to the world. What it does The website contains optimistic information about the covid-19 situation. How we built it We built it using Next.js, Now, Firebase, and Tailwind.css. We used sentiment, an open-source library, for the sentiment analysis of the news. Challenges we ran into Sentiment analysis isn't easy. Accomplishments that we're proud of Being able to go from idea to the first release in a couple of days.
