## Body

home page location drop down selecting location selecting an article bookmarks view Inspiration After seeing a large number of media outlets reporting biased news, often sensationalized, with clickbait titles, we thought we really need an independent media platform that can provide a seamless great experience so that the youth can become more aware of politics, law, administration etc. to help them make informed decisions. What it does It is an app, which after you login, lets you view custom curated articles, from India at large or at the local level. How we built it The app was built using flutter. Sawo-labs was used for authentication. The backend consisted of a rest api built using node.js and express, with mongodb as database and connected using mongoose. We also use dotenv to hide the keys and passcodes. The rest api was deployed using heroku and we used http requests to the endpoints to receive data and display images. Challenges we ran into Differentiating ourselves from our competitors to provide good quality ad free news but with a solid revenue model. Had to figure out how to connect to and use clusters on Mongodbatlas to add data. Took time to integrate backend and frontend Accomplishments that we're proud of Creating a prototype of a whole news app in around one day, implementing very different technologies and stacks, deploying, integrating and making it work. Especially with using new technology, example like sawo-labs. What we learned How to build a fullstack mobile app, create a frontend, backend, deploy and integrate everything, do authorization and come up with revenue models, market analysis, competitor analysis etc. What's next for Politika Expand the core editorial team. Find and curate large amounts of unbiased content. Expand to new areas.
