# pong

> Pong game with no score count or winners or losers, we are all winners in this game, except for when you lose. When you do lose, the game shuts off with no warning whatsoever.

## Body

The game screen Inspiration I thought of all the times I played pong, It always hurt when as a child I saw "GAME OVER" when I lost, so, I made a pong game where it is not possible to win, but also possible to lose, and even if you do lose, it does not call you a loser or say "GAME OVER" What it does It is just a pong game, but for Lazy People like myself. How I built it I built it using Pygame (LoL). Just modified the base boilerplate code you see on the Pygame website to make this very basic game. Challenges I ran into I had to make it look authentic, it took a while to figure the measurements out as I had gone completely based on feel. Accomplishments that I'm proud of I made it look exactly like the original game, but with the adjustments of "GAME OVER" removal, and also the capability to beat the Computer Player is removed. What I learned I learnt that I can make a game pretty easily using Pygame. What's next for pong Maybe I'll modify it to a first-person POV? Maybe I will add guns to it?
