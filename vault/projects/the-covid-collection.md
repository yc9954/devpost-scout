Workspace Overview List of Requests Example request and description Example request and description Workspace monitoring Inspiration COVID-19 has upended businesses, organizations, and billions of people worldwide. While many useful dashboards from the CDC and Johns Hopkins University exist, I wanted to create a centralized workspace where developers can easily access public API's that organizations have made available. What it does The COVID Collection aims to provide a centralized source of public API's to facilitate new, exciting software development projects based on COVID-19 data. Furthermore, workspace monitoring provides detailed uptime information at the top of every hour. How we built it The COVID Collection was built using Postman's workspace capabilities in addition to API's provided by the following organizations: The COVID Tracking Project COVID-19 API The unofficial Johns Hopkins University API Challenges we ran into I initially received a CORS policy error using the COVID Tracking Project API within the Postman web app when requesting data. Fortunately, I was able to request data while using the Postman desktop application. Accomplishments that we're proud of I am proud to bring a useful, technical solution to market that can be utilized by developers everywhere. I am proud of what I believe is a seamless, intuitive workspace for developers seeking to use their technical abilities to help public health. What we learned While I have used the Postman desktop application, I was not aware of the workspace capabilities with in the web app and I am glad to have experience using it. What's next for The COVID Collection For more up-to-date, local information, The COVID Collection focuses on U.S. data. Should it prove successful, I hope to integrate more local information from other countries worldwide. <div
