Galaxy Gurdians Inspiration The idea is inspired by the fact that a day will come when Humans will destroy the earth and its environment and will fight with other aliens to capture their land for survival. What it does Embark on a thrilling space adventure in this action-packed video game. As the captain of your own spacecraft, you'll navigate through mysterious alien worlds. How we built it It is built using Python and Pygame Library, this game was built keeping this hackathon in mind, but the introduction to Pygame has opened numerous other use cases which can be used to quickly make some useful applications and revolutionize the way young and curious minds think. Challenges we ran into Being such a useful library, not many applications have been built around it, but thanks to Pygame Hackathon for giving all the developers this opportunity to try some interesting things around this library. Accomplishments that we're proud of Made my first ready-to-use game for Pygame Hackathon, which I will play whenever I get time. What we learned Building a Game, Using Pygame Library.
