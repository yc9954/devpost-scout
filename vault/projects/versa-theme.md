## Body

Inspiration The Goal of the theme is to create a flexible theme that does not have "single-use" Modules for example for "Teams" or "About" modules. I also did not use Jquery and tried to have the CSS as low as possible to help with performance and core Web Vitals Ratings. The them is built with Tailwind CSS 2.0 and Alpine JS for Modals and Tabs <div
