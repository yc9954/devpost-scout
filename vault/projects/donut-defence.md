## Body

Inspiration I wanted to make a multiplayer game that is both easy to get into and hard to master. I settled on a connected lens in which you and a friend defend a donut against waves of enemies. What it does The user places a donut and then the user needs to defend it from being eaten by waves of monsters. Sometimes a monster will drop a power-up when destroyed to help the user out. How I built it This was built using lens studio. Challenges I ran into The major challenge was creating a lens which was easy to use and set up whilst having varying difficulties. I got around this issue by spending lots of time working on the UX and having multiple different difficulty modes. Accomplishments that we're proud of Creating a connected lens which works well and is fun. What I learned I learnt a lot about developing good UX for lenses.
