Blockcash mobile App Inspiration Celo is a mobile first blockchain, and as a mobile developer I loved the idea of bringing blockchain to the mobile. What it does It provides a better user experience in accessing different protocols in the Celo echo system like Moola and Ubeswap. How we built it We used React Native for the mobile development Challenges we ran into Releasing in the Apple Store was blocked, due to a few requirements from Apple like showing the partnership agreement with Moola, The App required Valora wallet to be downloaded as Blockcash did not have an in-built wallet. So to use the App another App need to be downloaded (Valora). According Apple guidelines, this violates their policy. ## Accomplishments that we're proud of We successfully released on Google Playstore and integrated with Ubseswap to show token balances and prices. ## What we learned Releasing in the gated environment like Apple store or Play store is not always easy and we have to follow their rules. 2.Faced some advanced integration issue with Celo for React Native ( https://github.com/celo-org/use-contractkit/issues/21 ) What's next for Blockcash DeFi Hub Ubeswap token swap and the integration of our auto-compounding protocol. <div
