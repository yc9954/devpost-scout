## Body

Home Page Contest types Stake to participate Generate image Leaderboard Inspiration AI is a human's assistant. But many people are wasting potential by not using it to the full potential. The prompts lacks quality and description. WhoIsTheBoss(WITB) is an attempt to change this in a fun and engaging way. Our mission is to make everyone a prompt master while helping them earn money. What it does WITB is a Prompt2Earn game, a new kind of game platform where creators participate in various challenges to earn rewards. Here's the flow for an example daily contest: User pay the participation fees Get 3 tries to generate image using AI Each image is then compared with Photo of the Day to calculate closeness score At the end of the day, participant having highest closeness score wins Note: This is the beta 1.0 version which deals with images. The later version will also have contests for videos, audios and 3d objects Features: Daily contests based on difficulty level of the images 1v1 battles based on random easy images How we built it We are using NextJS for building the platform, OpenAI dall-e-3 for generating images, MongoDB for storing some information, WalletConnect to connect wallet and the smart contract is deployed on Aurora Challenges we ran into Calculating the closeness score is still a challenging part. Accomplishments that we're proud of Creating a new way to educate people. Also proud of how fast we shipped this whole product. What we learned DB caching, product designing and management. What's next for WhoIsTheBoss Launch our own token $WITB. Make it cross chain. Multi-media contests apart from text-to-image.
