Book Notes App on PartyRock AWS Inspiration I create and give presentations every month. I have been searching for a tool to help me summarize long form content into the materials that could be used in a 5-10 minute long presentation by entering in a book's title What it does The user inputs a book's title and the number of bullet points for the summary. From this input, the generative AI creates a summary of the book, The first 5 bullet points in the summary are expanded below the summary to include a text explanation and a matching image. A set of starting questions and a closing quote for a presentation are also generated by the AI. How we built it The Book Notes App was created from scratch using the PartyRock interface. Challenges we ran into The PartyRock GUI works well and is easy to use. The GUI is not optimized to eliminate repetitive work, such as allowing the user to cut and paste widgets. In the Book Notes App, there are 10 widgets that are slight modifications on 2 widgets. However, each widget had to be created from scratch. Accomplishments that we're proud of The PartyRock GUI worked really well and was easy to use. What we learned Much work has been done on generative AI which will make content creation much faster and smoother.
