Introduction screen Profile page Homepage Grammar correction Text improvements Improvement modal Review & Speak Past Essay Report Inspiration I scored less marks in the SAT English section so I researched how to improve my reading comprehension and vocabulary quickly. I then made this technique and my English improved a lot. What it does The app has three features: Grammar correction: AI understands the text and checks for grammatical errors, gives also the category of the error Text improvement: AI checks for fluency, clarity, and vocabulary improvements and suggests them to the user. Retention: The user will need to rewrite and read aloud the essay to incorporate all the improvements How we built it We both used Flutter and FastAPI for the backend. For AI we used open-source APIs and AWS textract for Handwriting to text. Challenges we ran into Oh so many. One bug took an hour, but anyways we learned a lot. Some of the mind-boggling challenges: Using AI Learning FastAPI in an hour Building Grammarly style UI ## Accomplishments that we're proud of Worked for 42 hours (adjusted for sleep and food) Learned advanced flutter Learned FastAPI ## What we learned The most important thing we learned is perseverance in troubling times Such times came when we didn't know what to do to a problem or how to implement something Learned advanced flutter concepts like Riverpod and advanced widgets etc., building complex UI How to integrate AI in apps. ## What's next for Improveng We have several things planned for it to become a startup venture: -> Improve UI/UX -> Use complex AI to improve stuttering while speaking etc. -> Compare essay with speech to find pronunciation errors -> Build a chatbot AI fine-tuned to generate questions and increase retention of improvements -> Add pricing for revenue This app is definitely going to be a hit for English exam test-takers. <div
