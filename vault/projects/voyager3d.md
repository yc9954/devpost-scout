Voyager3D Inspiration The inspiration for Voyager3D came from my love for travel and the challenge of making trip planning more engaging and immersive. While traditional maps are informative, they lack the excitement and depth that is needed to plan a trip. And that's what I aim to solve with Voyager3D! What it does Voyager3D is a photorealistic 3D maps application designed to enhance navigation and trip planning. Users can explore the world in 3D, research places of interest, and plan routes with ease. How we built it Voyager3D was built using Google’s Photorealistic 3D Maps API and the Google Gemini API. I integrated the Google Maps Routes API to allow users to generate precise directions and visualize routes in a 3D space with custom polylines. Challenges we ran into One of the biggest challenges I faced while creating Voyager3D was learning how to leverage the Photorealistic 3D Maps, as well as learning how to use Google Gemini. Before this project, I had never used either of them, but I've learned a lot and gained a deeper understanding of how to integrate cutting-edge technologies to create an immersive user experience. Accomplishments that we're proud of I'm proud of creating an application that bridges functionality and aesthetics, offering a visually stunning way to plan trips and use Google Maps. What we learned This project was a great opportunity to learn and work with new technologies. Diving into these new tools taught me how to harness their capabilities to build immersive and interactive applications. What's next for Voyager3D In the future I plan on expanding Voyager3D's feature set to support collaborative trip planning, allowing multiple users to contribute itineraries in real-time.
