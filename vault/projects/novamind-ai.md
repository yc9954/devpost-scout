## Body

Novamind AI dashboard photo Inspiration Novamind-AI was inspired by a problem many students face every day: studying is not just about finding answers, but staying focused, understanding difficult concepts, and building better learning habits. Many AI tools can give quick responses, but students often need something more supportive — a system that helps them think through problems, stay away from distractions, and feel less stuck when learning. We wanted to build an AI companion that acts less like an answer machine and more like a focused learning partner. The goal was to create a tool that supports students while they study, guides them through confusion, and helps them stay on track. What it does Novamind-AI is an AI-powered study and productivity companion for students. It combines multiple tools into one learning environment: A Socratic Tutor that guides students through problems instead of simply giving the answer. An AI Lab Supporter that helps students understand concepts, organize their thoughts, and get support while working. A productivity-focused Chrome extension that detects distracting sites like YouTube, Instagram, or Discord and helps students refocus. The main idea is to help students learn actively. Instead of replacing thinking, Novamind-AI encourages better thinking. How we built it We built Novamind-AI as a full-stack web application using modern web technologies. The frontend was designed with a clean and focused interface so students could use the platform without feeling overwhelmed. We used Vite for a fast development setup, Tailwind CSS for styling, and Supabase for backend features such as authentication and data storage. The AI features were designed around student support, tutoring, and productivity, with the goal of making the assistant helpful without encouraging passive learning. We also worked on a Chrome extension that can detect when a student is visiting distracting websites. This allowed us to connect the learning platform with real browsing behavior, making Novamind-AI more than just a chatbot. Challenges we ran into One major challenge was designing the AI so that it would guide students instead of just giving direct answers. We had to think carefully about the user experience and how the assistant should respond in a way that encourages learning. Another challenge was connecting different parts of the project together: the web app, the AI tutor, the Supabase backend, and the Chrome extension. Each part had its own technical details, and making everything feel like one complete product required a lot of iteration. We also had to balance ambition with practicality. We wanted Novamind-AI to feel futuristic, but still realistic enough to build and improve step by step. Accomplishments that we're proud of We are proud that Novamind-AI became more than just a simple AI chatbot. It grew into a student-focused learning system with tutoring, support, and productivity features. We are also proud of building a project that solves a real problem we personally understand: students often struggle not because they are incapable, but because they get distracted, confused, or overwhelmed. Novamind-AI directly targets those pain points. Another accomplishment is the Chrome extension idea, because it extends the platform beyond the website and helps students during their actual study sessions. What we learned Through this project, we learned how important product design is when building with AI. The hardest part is not only making the AI respond, but making it respond in a way that helps the user grow. We also learned how to structure a full-stack AI application, connect frontend and backend tools, and design features that work together as one system. Building Novamind-AI taught us that useful AI products need both strong technical implementation and a clear understanding of the user’s problem. Most importantly, we learned that AI for education should not simply make learning easier by removing effort. It should make learning better by supporting focus, curiosity, and deeper understanding. What's next for Novamind-AI Next, we want to improve Novamind-AI into a more complete learning companion. This includes making the Socratic Tutor more personalized, improving the productivity extension, and adding better progress tracking so students can see how their focus and understanding improve over time. We also want to make Novamind-AI more adaptive, so it can respond differently depending on the student’s goals, subject, and learning style. In the future, Novamind-AI could become a full AI-powered study environment that helps students plan, focus, learn, and reflect — all in one place.
