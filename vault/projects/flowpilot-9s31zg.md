Home Page Signup Page Login Page Dashboard Workflow Builder Workflows Tasks Approvals Invite User Inspiration Many organizations still manage workflows using spreadsheets, emails, or manual coordination, which leads to delays and lack of visibility. We wanted to build a centralized system that automates workflows and improves operational efficiency. What it does FlowPilot allows organizations to visually design workflows, assign tasks, manage approvals, and track execution in real time from a single dashboard. How we built it We built the frontend using React and React Flow, and the backend using Node.js, Express, Prisma, and PostgreSQL. JWT authentication with cookies is used for secure multi-tenant access. Challenges we ran into Designing a graph-based workflow engine, managing task state transitions, and ensuring proper tenant isolation were the main challenges. Accomplishments that we're proud of We successfully built a workflow execution engine with approvals, analytics, and a visual workflow builder. What we learned We learned about SaaS architecture, multi-tenant systems, graph-based modeling, and building scalable backend services.
