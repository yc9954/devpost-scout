Movie Search Voting Section Inspiration We usually had hard time picking a movie. That is why we decided to build an application to simplify this process. What it does This application allows to create a movie room where people can join in and vote for a movie to watch. It also has movie search which allows users to find movies more quickly. How we built it We built with VueJS for front-end and python with flask for back-end. Gabriele built back-end movie CRUD operations and me -- Matas -- created a front-end design that operated on back-end. Challenges we ran into It was hard to pick a design that worked well. Accomplishments that we're proud of We have a MVP working that serves as a prototype that we can use later when building a full system.
