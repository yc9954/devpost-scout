## Body

Filter release notes Find release notes of thousands of products Get notifications an reports Save time by having all release notes in one place Inspiration We all read updates of multiple components, services, and libraries, and it is hard to consume them because they have different shapes, audiences and ultimate purposes. We believe there is a place for a platform that helps you stay on top of product updates in the way you prefer and when you prefer. Driving a common standard of release notes. What it does The platform we have built enables the production and consumption of release notes in one place in the way you prefer. Get Release Notes platform provides a flexible, but opinionated standard of release notes. How we built it We had fun building with the Atlassian Forge development platform, which enabled us to deliver our solution rapidly and smoothly. We used Atlaskit with React to build our custom UX and Forge to provide the backbone of the application. Challenges we ran into We had a short ramp-up time with Atlassian Forge and had a few difficulties combining a custom React UI with the Forge app. We tried to build using Forge UI, but it missed multiple things we needed. Parallel development had some issues we overcame by creating a template of the manifest file, and each developer had to register his/her own Forge app. Accomplishments that we're proud of We have a working application that is coming soon to the Atlassian Compass Marketplace. What we learned How to build Compass apps. How to build with the Atlassian Forge platform.
