Just-speak Inspiration All of us always struggle with some kind of transcript work whether it is making assignments, notes, etc. Most of this work requires reading/writing a big amount of text and then cross verifying it that everything that we has written is correct. I believe this is a hectic work so this gave me the inspiration to build this project. What it does The application coverts speech to text and vice versa and gives some cool features to users like cross verifying the long transcript that they have written, send the transcript directly to email or we can also download it. How we built it We built it using different tools but the major of them are alan-ai which makes it possible to work on voice commands, Twilio via which we can send our transcript directly to our email or jsPDF plugins which makes it easier to covert the text to pdf and download it. Challenges we ran into In this 3-day we came across many challenges butI'd like to discuss 2 challenging part : to use devops tools like docker, civo, Kubernetes that I haven't used before. to work alone with the project, when my team mates left me. ## Accomplishments that we're proud of Making this application in 3 days all alone when all my team mates left me was a bit challenging but I've managed to complete it and I've very proud of it. And I've also completed my deployment to civo succefully. ## What we learned This hackathon taught me implementing different stuffs and technologies along learning side by side. I learnt fundamentals of different devops tools like Kubernetes, docker, CI/CD pipelines like Datree, etc. ## What's next for just-speak There are many features that are yet to be implemented such as autocorrection of misspelled words supporting different languages, also we can give users the best experiences by changing the accent and speed for the better.
