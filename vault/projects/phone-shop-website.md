Inspiration About the Project Inspiration We wanted to help local phone repair shops go digital. Many small repair stores still depend on walk-in customers and manual records. Our aim was to create a simple platform where users can book repairs, buy phone accessories, and track orders, all in one place. How We Built It We developed the project using a full-stack web approach: Frontend: HTML, Tailwind CSS, and JavaScript for a fast, responsive UI Backend: Node.js and Express.js for managing booking, user, and product data Database: MongoDB for storing users, products, and appointments APIs: Integrated Google Maps for shop location and tracking What We Learned We improved our UI/UX design and responsive layout skills. We learned how to manage real-time data and handle backend routing. We explored REST APIs and how to integrate third-party services. We enhanced teamwork and time management during development. Challenges We managed user authentication and secure booking flow. We synced front-end data with MongoDB in real time. We ensured the site stayed responsive across all devices. We debugged API calls and optimized server performance. Outcome We successfully built a working prototype where users can: Book phone repair appointments online. Shop for accessories with an add-to-cart system. View the shop’s location on Google Maps. Receive instant booking confirmation.
