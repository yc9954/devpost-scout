Registeration screen login screen Singleplayer Screen Multiplayer Screen What it does Typing Clash is a typing practice web app with a unique multiplayer functionality that sets it apart from other typing practice websites. This feature allows individuals to practice together in real time. We call this a "room," and each room can accommodate up to four participants. How we built it Building Typing Clash was a challenging yet rewarding experience. Initially, we were unsure of how to develop it, but as time passed, we kept making progress. For the frontend, we used HTML, CSS (Tailwind), and JavaScript (React). The backend was built with Express, Node.js, and MongoDB. The multiplayer functionality was implemented using Socket.io, which was integrated into both the frontend and backend. Challenges we ran into We encountered several challenges during development, one of the biggest being implementing Socket.io. Initially, we had no prior experience with it, so learning and successfully integrating it was a significant hurdle. However, overcoming this challenge was a great learning experience for us. Accomplishments that we're proud of After all the hard work we put into this project, we are incredibly proud of the final outcome. It feels amazing to see how far we've come. Looking back at our early days, we sometimes laugh at how uncertain we were in the beginning. The progress we've made and the knowledge we've gained along the way make this achievement even more rewarding. What we learned Building a project requires a deep understanding of multiple technologies, and every successful project is proof of gained knowledge. Throughout this journey, we learned Socket.io, improved our backend development skills, and realized that software development involves much more than just writing code. We also gained a new perspective on AI—initially fearing that it might replace developers, but later understanding that the creative and problem-solving aspects of development make human input essential. What's next for Typing Clash We plan to deploy Typing Clash soon and continue enhancing it with new features. We are brainstorming ideas to make it more engaging and innovative. Our goal is to keep improving Typing Clash and ensure it stands out as a unique and exciting typing practice platform in the near future. <div
