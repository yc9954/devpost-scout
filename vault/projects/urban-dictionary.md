## Body

Inspiration Urban dictionary is a useful website that allows users to search for and contribute to definitions. So I wanted to create an API that does the same. What it does Urban Dictionary API allows you to search for definitions of words, "definitions" include not only literal definitions but also descriptions. As such, "to define" a word or phrase on Urban Dictionary does not necessarily entail providing a strict definition; merely a description of some aspect of the word or phrase could suffice for inclusion in the dictionary. How I built it I used Postman Canary and both urbandictionary.com and rapidapi.com to build the API. Challenges I ran into While making a GET request to rapidapi.com, I was facing some issues regarding the URL. So I ran it on my terminal using CURL and fixed it.
