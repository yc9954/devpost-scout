otp screen after applying coupon login screen worker profile screen cart item total is displayed worker side task tree individual after selecting from shop user dashboard (here we used static images just for design, will be changed in app) shop here there is offer slider (by clicking we will see a tree with offered discount price) user dashboard-1 () Inspiration There is multiple inspirations behind the creation of Me and My Tree mobile application, but the primary inspiration is likely the need for collective action against climate change with lowest effort from individuals What it does User can select from various options for trees provided by Me And My Tree which he/she wants to plant We help them by reducing stress of how to plant a tree and physical efforts in just few clicks We connect this tree plantation process with human emotions like you can plant tree on different life occasions like Birthday, Anniversary, Demise, etc. How we built it With in 4 hrs at starting of league we designed 4 pages (login/signup, Home/Dashboard, Shop, Profile) in figma. Later on before lunch we created login/signup page and after that other pages. Then we Brainstormed for backend database and created a raw database in MySql. After creating database we connnected our app with database. Simultaneously other members started designing other pages for app. Then we created API's for pages like Cart, Shop, Tree, Send OTP, GetCart, Verify OTP, Empty Cart. After Implementing other designs we integrated remaining API's. While we were building we used ChatGPT and Mentors help Challenges we ran into We faced few issues while Integrating API's Accomplishments that we're proud of We are proud of the learning experience that we've got through building this app and the service that we aim to provide to the end user once we go live, all while improving the green cover around us. We feel we are working towards a better future and helping in accelerating employment rates in our area. What we learned From the basic time management to every minute detail of debugging and bug fixes, its clear to say that we've learnt a lot from this journey that we might not be able to learn so quickly in regular environments. Development with React Native and fixing broken API requests due to server errors and working towards a unique design and then implementing it are some learning through our journey. What's next for Eco Hackers We wish to continue working on Me And My Tree and more similar apps to come, and always work towards a better future for all of us!
