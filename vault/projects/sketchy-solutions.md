## Body

Inspiration I wanted to create a game where the primary input was more than just a button press or a comment, but still drove discussions and community engagement. Inspired by other drawing games on reddit, but containing all submissions to a single post while allowing users to come up with their own ideas. What it does Players come up with a scenario that needs solving. "How do I make $1,000,000 by tomorrow". Post viewers come up with insane inventions to accomplish the OPs goal, and draw them out using a marker and adding in stickers from a built in library. The top voted inventions are displayed on the invention board for other viewers to quickly see and have a chuckle. How we built it Built with react and devvit, with open source stickers Challenges we ran into Drawing as the primary input is hard. Many hours spent tweaking the invention editor to make it low friction for any user to create what they are imagining.
