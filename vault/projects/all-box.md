Login Website customization My sites Sample Landing Site Inspiration The inspiration behind All.box came from the need to create a user-friendly platform for selling Unstoppable domains. The goal was to simplify the process of listing domains for sale and providing a seamless user experience for potential buyers. What it does All.box is a landing site builder for Unstoppable domains. It allows users to create customized landing pages for their domains, making it easy for buyers to contact the seller or proceed to a marketplace to complete the purchase. The platform integrates with various marketplaces like Unstoppable Market, OpenSea, and Name Maxi to fetch domain prices and ensure the lowest price is displayed. It uses AWS also generate short description about the domain name based on its name How I built it The site was built by integrating Unstoppable domain profiles and leveraging various marketplaces to fetch domain prices. Users can easily create a landing page by uploading images, setting a title and description, and configuring DNS records. The site automatically pre-fills the user's Unstoppable profile link and allows for customization of buttons and images. Challenges I ran into One challenge was ensuring the platform could accurately fetch and display prices from multiple marketplaces. Additionally, simplifying the DNS configuration process for users was a key challenge that needed to be addressed to make the platform user-friendly. Accomplishments that I'm proud of I am proud of creating a seamless and automated process for building landing sites for Unstoppable domains. The integration with multiple marketplaces and the ability to automatically fetch and display the lowest domain prices is a significant achievement. What I learned Through this project, I learned the importance of creating a user-friendly interface and the technical intricacies involved in integrating with multiple domain marketplaces. I also gained insights into simplifying DNS configurations for end-users. What's next for All.box The next steps for All.box include adding more customization options for landing pages, improving the mobile experience, and expanding integrations with additional domain marketplaces.
