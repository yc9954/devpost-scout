Creative Score: Redefining Sports Control through Creative Precision Inspiration The inspiration for Creative Score was born from a tangible need in the local basketball courts of Jujuy, Argentina. I observed that operators struggled to manage complex digital scoreboards while trying to keep their eyes on the fast-paced action of the game. I envisioned a solution that could bridge the gap between sports management software and high-precision tactile hardware. A driving factor was the obsolescence of current infrastructure. Most clubs rely on archaic physical boards with limited functionality, connected by fragile UTP cables and connectors that break easily. Furthermore, the prohibitive cost of professional LED screens and proprietary software prevents many teams from accessing quality technology. The launch of the Logitech MX Creative Console was the ultimate catalyst, providing the modularity and customizable LCD keys needed to democratize professional sports control. Project Development The project was built on a modern, scalable architecture: Backend : I utilized Directus as the core database and API engine to manage collections for teams, players, and real-time match statistics. Frontend : I developed a Progressive Web App (PWA) hosted at create.xerex.tech , designed to be displayed on any internet-connected screen. Hardware Integration : I implemented a bidirectional communication layer with the MX Creative Console , where the 9 LCD buttons dynamically represent the players on the court and scoring functions. Challenges Faced Eliminating Points of Failure : The primary technical challenge was replacing unstable wired connections with a cloud-based system that allows for remote management via internet. Visual Versatility : Developing a "Board Designer" that allows for instant modification of colors and styles, ensuring every match is a unique visual experience. MX Creative Console Implementation : Adapting a complex sports suite into a 9-button tactile space required a rigorous "Layer" design that shifts per game state, such as scoring, fouls, and substitutions. Learning Outcomes This project consolidated my belief that true innovation lies in versatility. Thanks to the Logitech MX Creative Console, we achieved a level of implementation ease that allows any local court to be transformed into a professional arena in minutes. I learned that by removing expensive proprietary hardware and replacing it with an intuitive console and cloud software, game control is no longer a technical limitation but a tool for creative sports expression.
