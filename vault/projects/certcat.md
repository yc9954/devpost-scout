Home Page Main Dashboard Pricing Page Template Editor Idea This idea came to me when I was investigating how the hackathons managers made a lot of certificates for the participants, when I researched about it more. I found something unusual, if you do the certificate manually that would be a hectic process and if you use any service out there, they will cost you a lot. That's why I created CertCat . So, anyone can use it for free and check it out. I have also added a limit for the certificates but that is due to resources issue. I hope that It will be successful project and people will use it. Features Some of it main features are described below: You can create different type of templates with QR Codes, Certificate IDs, Event Details etc. It provides different quality of certificate and a fully customizable editor. You can use your very own template to launch campaigns and send certificates. It includes Preview Certificates Feature, You can use that to check the certificate before sending to the users. It also includes Email Sending feature you don't have to connect your email, CertCat will take care of it. After your certificate are sent out you can share on LinkedIn, Download PDF, Share it with people with never expiring links. You can also verify it with a special certificate id assigned to each certificate. Technologies Frontend: Next.js, React, Tailwind CSS, Lucide React Backend: Next.js API Routes, Firebase Admin SDK Database: Firebase Firestore Utilities: NodeMailer, React-PDF, QRCode, PapaParse Future of CertCat If the project gets users, we can expand our resources and make it more improved by adding more email senders. Increasing the limits of the certificates. Also we can implement more email customization as well. <div
