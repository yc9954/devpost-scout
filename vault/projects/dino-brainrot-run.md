Inspiration Dino Brain-rot run is based off the well known chrome Dino game. Our aim was to create a mix between a quiz and a game What it does Dino Brain-rot is a web based game designed to integrate a quiz throughout the dinos adventure. It aims to raise your blood pressure and works to ensure you lose a couple braincells. How we built it Dino Brain-rot was built using open source Dino run code so we had our foundation. We built upon this by combining HTML, CSS, and JavaScript to provide you with the brain-rot questions and added functionality Challenges we ran into Time Constraints: Balancing feature implementation within the hackathon timeframe. Brainstorming ideas: As each team member has different interests and skills we struggled to land on a project that was sizeable and incorporated all our ideas together. We took an agile approach reworking our attempts and ideas into something that was achievable for everyone Accomplishments that we're proud of Successfully integrating questions throughout the game. Participating in our first Hackathon! What we learned How to effectively build upon existing code we hadn't encountered before and transform it into something new. The importance of clearly put your thoughts and ideas across Teamwork and time management in a high-pressure environment.
