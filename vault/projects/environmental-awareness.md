## Body

I've always been passionate about the environmental science field as well as computer science, so why not combine the two? Creating this website allowed me to express my ideas and interests for others to learn from. The website has two parts: the quiz and the information. The quiz is a short side component that suggests which topic one might be interested in learning about and taking action against. The information part includes facts, causes, effects, and solutions to pollution and nonrenewable resources on different pages of the website that can be reached through the navigation bar in the center of each page. The website helps spread awareness about the topics and also urges action. I built it using replit.com. A challenge I ran into was not including too much information on each page. Having too many words on the screen makes it overwhelming and somewhat unappealing, so I had to make sure I only included relevant and important information. I'm proud of the quiz since I'm relatively new to Javascript and the quiz works. Small victories :). I'm also proud of the accessibility features incorporated! Each image has an alt text that can be read by screen readers for those with vision impairments to understand the whole website! I definitely grew and refined my HTML and CSS skill set by developing this website, as well as JavaScrop through the quiz! In the future, I would want to expand the website to have other issues apart from environmental topics. Maybe a different website about social justice or mental health issues, etc. Through this project, I was able to learn more about coding and it inspired me to create more. <div
