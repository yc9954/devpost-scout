Social Media Data Gathering Tool Inspiration Organisations use social media for reaching out to their customers and spreading the word about their product. But, pointlessly shouting into the void will not yield any results. Social media analytics give us a basic idea of how our social media presence if affecting our business. What it does This postman collection has APIs that get information from social networking sites like Reddit, Twitter, Facebook, Instagram and LinkedIn. The data retrieval can be automated, and the retrieved data can be put into good use through data analysis. How we built it Social Media platforms provide developer APIs for easy access to public and private data, we have collected for all the sites and created a postman collection in a public workspace. Challenges we ran into I had a hard time understanding OAuth authentication used by Facebook and Instagram. Accomplishments that we're proud of I am proud that this project will be used for powering open source projects.
