# A-eye Assistant

> Disabled people often end up relying on others for help but now they can rely on this website. This website takes pictures and reads out the text on it allowing the visually impaired to "see".

## Body

Inspiration Many people with disabilities don't like the idea of relying on others for everything and not being able to do anything themselves. This website lets the hopes of some of those people come true. This website allows visually impaired people to understand what the text says just by taking a picture of it which can allow them to do things themselves they never would've been able to do before. What it does The website takes in user input in the form of a picture and uses different processes to analyze that text and read it out for the user. How we built it We built it by using python along with some libraries like pytesseract, flask, OpenCV, and pyttsx Challenges we ran into It was really difficult in implementing ML of identifying the feature and converting it into an audio file. Accomplishments that we're proud of we learned how to apply computer vision models for text detection and use text to speech as well as transporting files between python and html What we learned We learnt about computer vision, ML and mostly understood how technology can help people with disabilities if rightly implemented.
