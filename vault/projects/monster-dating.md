## Body

GIF You are beautiful! Inspiration Monster Dating has been an idea I've been cooking on for a long while. Imagine a dating app that lets you make romantic connections or attack others. What it does Monster Dating is a playful social dating simulator where you build your own custom monster and venture into a world full of other creatures looking for connection or a fight depending. Attack or love, just like real life. How we built it Initially I used Game Maker to build this then shifted to React. Devvit is always fun to work with and makes making games like these a lot of fun. Challenges we ran into LOL ! Ha ha. So many fun puzzles to solve. The vison for this game has always required a very large scope. One of the most challenging things was deciding how to make the game play simple, fun and enjoyable while keeping some balance. With edits being pushed right to the last minute, not having time to balance the game economy is a hurdle. I'm looking forward to seeing some chaos. I had to trim some of the fun comparison, likes / dislikes logic and Monster profiles. The ridiculous dates didn't get added either so I hope players can imagine this game being awesome. Monster states for dates, animations for reactions and results had to be sidelined but the idea is still there. Accomplishments that we're proud of I've been working on an art style that is comforting, I feel like a lot of it is coming together. I leaned into AI a bit more with some code things that helped a lot. The idea of this game is so much fun and it's nice to get a taste of it out there. What we learned Oh so much stuff! I really learned a lot about Game Maker and building more robust async games on this platform. What's next for Monster Dating I'd love to get the experience more polished along with the economy. It would be nice to go back to Game Maker workflow and utilize some fun features there. <div
