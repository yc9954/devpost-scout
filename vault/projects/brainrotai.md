And our AI tool helps them with just that. ⚙️ What it does ⚙️ BrainrotAI is a chatbot (**cough gemini wrapper) that helps you learn the basics of skibidi. Like what does skibidi even mean!?? It uses the best in the world perplexity AI Gemini with pre-defined system instructions to act like your genz best friend that will save you from ALL CAPS. Whether it's translating, learning new vocab, or just being your bro, it does it all, and it is all just a very sophisticated LLM model trained on an exclusive database with the alpha sigma gama's of skibidi that we trained in an hour a wrapper. 🛠️ How we built it 🛠️ Nothing, just a simple TypeScript frontend, web sockets, express.js, gemini API key, one AWOL teammate, used the GOAT'd Next.js to write production-grade code, realizing Vercel serverless doesn't support active web sockets, and the end semester exams that the two teammates who worked have. 😣 Challenges we ran into 😣 Integrating the frontend and backend with web sockets by configuring CORS Policy, debugging to find out Vercel doesn't support active web sockets. 🎉 Accomplishments that we're proud of 🎉 We now know what skibidi means (not really because no one does) 📚 What we learned 📚 **Vercel serverless doesn't support web sockets and skibidi has no real meaning but it's the ✨vibe✨ . ⏭️ What's next for BrainrotAI⏭️ Building out a full blown database of the slang and an AI RAG agent that gives kai cenat the sigma energy.
