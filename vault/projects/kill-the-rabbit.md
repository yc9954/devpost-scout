Rabbit is approaching Missile launcher is ready Explosions on the Rabbit Chased by the Rabbit Now with the butterflies trap The rabbit is looking at the butteflies Satellite is orbiting Inspiration One day I watched a youtube clip that in Australia too many numbers of rabbis causes big problems in echo system. So many pepole are hunting rabbits. I was inspired by this idea that harmless rabbit can acatual damages to the nature. What it does It was the first animation that is created with Ai and unreal engine in Korea. How we built it We used classic motion capture style to get all the detailed motions and then using unreal engine we were able to pull off cool animated animation. Then we convert every single frame into ai to have hand-drawn touch using image to image method of stable diffusion. Also we used the same method to show rabbits emotional chage using image to image method. When the rabbit is calm the images that rabbit shows nature elements. But he gets upset his body shows snake skins, scary faces and other elements that provoke viewers. Challenges we ran into When we first started this project Ai was early stage. Even generative video was not open to public. So we had to come up with seamless adoptation of using Ai to the animaion. So we used the image to image method. It turned out to be OK for us. Accomplishments that we're proud of Back it 2023 no one has ever done something like what we created. Combining ai and unreal engine together. And it sill holds up. What we learned We learned that small numbers of people is no more problem when you want to make animations in Ai era.
