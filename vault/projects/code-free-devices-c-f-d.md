Area where the platformer examples are Showing settings for the Asset Spawner CFD What are CFDs Code Free Devices are a series of modular devices which allow creators to create gameplay without any typescript coding! Every device can communicate with one another using a simple channel system. Inspiration Other UGC game platforms like Little Big Planet or Fortnite Creative tend to have some sort of codeless gameplay system but Horizon Worlds doesn’t yet have one. We do have a lot of people coming from Fortnite Creative so these devices were designed to be familiar to those creators. But if you’re not from Fortnite they’re still a codeless system that anyone can use. Why CFD I think this system is quite a different approach than using Interactive Assets. It’s different from the Unity Asset Store approach or Interactive Asset approach where you download separate systems that are never quite exactly what you want and they aren't compatible with one another. So then your job is to continuously hack together ways for these separate systems to communicate with one another. So CFDs aim to completely avoid the spaghetti code between different systems.
