## Body

Inspiration We see a need for travel assistants which can understand the end user travel requirements and help them with their bookings - either flight bookings or hotel reservations. What it does The current Travel assistant - TRAVIS helps the end user with making hotel reservations. How we built it We chose Kore as a platform to build the conversational ai assistant and used TRAVEX apis for making the hotel reservations. Challenges we ran into We ran into multiple challenges: Making the Travel api work with Kore platform Deciphering the api output and showing it to the end user in the best possible format for better user experience. Accomplishments that we're proud of Making the assistant more conversational and implementing this feature of hotel reservation end to end. What we learned The awesome features of Kore with Carousal. Kore still need to add more capabilities around process forms. Ideally we would have liked to fetch the country codes and other drop down capabiities from the 3rd party provided via API and be able to show that in the process form of Kore. What's next for TRAVIS We are also working on Flight reservations and eventually would like to see TRAVIS be the real assistant wherein it plans an end to end trip for any enterprise user for any of their travel needs - Personal or Professioanl. <div
