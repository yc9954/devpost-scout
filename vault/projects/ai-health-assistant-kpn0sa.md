## Body

Inspiration We were inspired by the need for quick and accessible health guidance for everyday users. Many people struggle to get reliable health information instantly, so we built an AI-powered assistant that provides basic health advice, symptom analysis, and wellness insights in a simple web interface. What it does AI Health Assistant is a web-based healthcare companion that allows users to describe symptoms and receive instant AI-generated health guidance, precautions, and recommendations on when to seek medical help. It also includes a BMI calculator for basic health tracking and promotes early health awareness. How we built it We built the application using HTML, CSS, and JavaScript for the frontend with a modern responsive UI. We integrated real-world AI using the OpenRouter API to generate intelligent health responses. The system processes user inputs, sends them to the AI model, and displays personalized health guidance in real time. Challenges we ran into Integrating real-time AI responses smoothly Handling API errors and response formatting Designing a simple yet modern user interface Ensuring safe health advice without medical diagnosis Managing prompt design for accurate responses. Accomplishments that we're proud of Successfully integrated real-world AI into a healthcare assistant Built a clean and modern user-friendly interface Created a functional symptom checker with instant responses Developed a working health tracking feature (BMI calculator) Built a scalable foundation for future healthcare solutions. What we learned API integration and prompt engineering for AI models Frontend development and UI/UX design principles Building responsible AI systems with safety considerations Structuring real-world problem-solving applications Improving user experience in AI-based products.
