SignUp Page Singin Page Requests Page AI Roadmap Profile Page Create Circle Dashboard Peers Page Mentors Page Circles page Landing Page MentorCircle Inspiration Many students struggle to find the right learning path, especially in STEM fields where there are countless resources but little guidance on what to learn, when to learn it, and who to learn from. We wanted to create a platform that combines mentorship, community learning, and AI-driven personalization to make learning more structured, engaging, and accessible. What it does MentorCircle is an AI-powered learning platform that helps students discover mentors, join focused learning circles, generate personalized learning roadmaps, and participate in meaningful discussions. Learners can connect with experienced mentors, access curated resources, engage with peers across different circles, and follow customized learning journeys tailored to their goals. How we built it We built MentorCircle using: Frontend: React.js Backend: Django REST Framework Authentication: JWT Authentication Database: SQLite Deployment: Vercel (Frontend) and Render (Backend) AI Integration: AI-powered roadmap generation for personalized learning paths The platform integrates mentor discovery, learning circles, discussion forums, guidance requests, and roadmap generation into a unified learning experience. Challenges we ran into One of the biggest challenges was designing a workflow that effectively balances mentorship and collaborative learning while keeping the user experience simple and intuitive. We also faced challenges related to API integration, deployment, role-based access control, request management workflows, and maintaining a scalable architecture within a limited hackathon timeline. Accomplishments that we're proud of Built a complete mentor-led learning ecosystem from scratch. Successfully integrated AI-generated personalized learning roadmaps. Developed mentor discovery and guidance request workflows. Created learning circles that encourage focused STEM learning. Designed a clean and user-friendly experience that supports both mentors and learners. Successfully deployed the platform and integrated all core features into a working product. What we learned Through MentorCircle, we gained hands-on experience in full-stack development, REST API design, authentication systems, deployment workflows, AI integration, and product design. We also learned the importance of simplifying user workflows and building features that directly support the platform's core mission. What's next for MentorCircle Our future plans include: Advanced AI-powered mentor recommendations. Achievement and milestone systems. Enhanced roadmap customization. Smarter mentor-learner matching. Expanded STEM-focused learning resources. Improved collaboration and community engagement features. MentorCircle aims to become a comprehensive learning ecosystem where students can discover, learn, connect, and grow with the support of mentors, communities, and AI-driven guidance. <div
