## Body

Some screenshots of the app Inspiration I felt like sending locations to more people need to be simultaneously done ,thus helping in faster communication. What it does It sends messages to 3 registered relatives/close friends . It also sends emails to respective HR managers regarding eve teasing,corruption,rape,etc. It has fake siren to alarm the strangers It also has fake alert call ringtone ,so that you can act like you are talking to your parents about the taxi driver's license,etc. How we built it By coding in Android Studio with the help of java in the backend ,frontend in XML and Shared data to store the phone numbers,Google map APIs. Challenges we ran into Many actually, firstly in setting up the app with SOS ,then with google map APIs generating,etc. Accomplishments that we're proud of Could present the app in working state What we learned Try and run the code and store the changes in github for versions.
