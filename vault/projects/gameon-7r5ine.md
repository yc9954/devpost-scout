Inspiration We were both learning front-end but hadn’t made anything fun yet. So we thought,why not create games? We decided to work on two different ones—one about storytelling and one about guessing—and then combine them into one cool project. What it does GameON merges: Sequence Game : Follow the correct storyline to win! Guess Game : A guessing game where you pick a category and uncover hidden images in a grid. Both games are now united in a single app: GameON . How we built it We merged two individual projects: Sequence Game by Shwetha B. GitHub Repository Guess Game by Me GitHub Repository The merged app uses HTML, CSS, and JavaScript, blending the functionality of both games into a single interface. Challenges we ran into Integration Struggles : Merging two games without breaking them? Not easy "Page Not Found Looks like you've followed a broken link or entered a URL that doesn't exist on this site" this EAT my brain Audio Shenanigans : Adding music that works seamlessly across browsers tested our patience. Time Crunch : deadlines.. Accomplishments that we're proud of Successfully combining two projects into one cohesive app. Creating a fun, user-friendly interface. Building something that entertains -hope you right out the game!!!!!!!!!!!!!!! What we learned How to collaborate effectively and combine ideas. Troubleshooting browser compatibility for features like music. Managing time and resources under pressure. What's next for GameON Adding more categories and expanding the game library.
