GIF APIcture Overview Storage Collection Background Remover Collection Image conversion Collection Img Gif and Sticker Generator Collection Simple Image Editing Collection GIF Inspiration As a FrontEnd developer for me using images just as a placeholder or in some places I will require images in a particular resolution or in a particular size, for that simple job opening an editor and resizing cost more time. To overcome it I had created this collection of APIs. What it does The main moto of APIcture is to make image handling easier in the Front End. And it's done by providing many API's within our collections for image manipulation. APIcture can do many useful tasks like, Storing the image Removing the background of an image. All common types of image conventions. Placeholder Image Generator. Image Gifs and Stickers collections. Image Editor How we built it We build this collection with the help of many useful APIs which are particularly best in image manipulation tasks. Challenges we ran into Creating APIs for image manipulation is very tough. Many factors need to be considered. A whole lot of extensions are available for an image. All those were considered while making this project an outstanding one. Accomplishments that we're proud of Converting an idea to reality Besides of many struggles and obstacles I had successfully completed my project. What we learned I learned a lot about APIs and how to use those APIs in postman and run tests with it. What's next for APIcture manipulation As my next step for APIcture manipulation, I'm working with my own powerful image manipulation API and also trying to find many best manipulating APIs for my collections. And to move even further I'm also planning to provide APIs to edit and manipulate videos. <div
