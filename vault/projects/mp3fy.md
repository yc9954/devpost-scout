## Body

Inspiration I was thinking about giving the chance to listen to music free without ads to all people. And I said to myself I will make Spotify playlists downloadable. What it does It gets the playlist's songs via a free API then searches it on YouTube then downloads all songs one by one. How we built it Just with some basic python modules. Challenges we ran into Simulating bash terminal inside a browser. But you can use it also command line it is experimental right now. Accomplishments that we're proud of High-quality mp3 files and easy command line experience. What we learned We learned that python3 is such a great choice for this project. What's next for MP3FY If I make some money from hackathons I am planning to open a website and rent a server for mp3fy.
