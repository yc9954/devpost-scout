## Body

Inspiration Simulearn is an application that focus on how to make education more immersive and interactive . The main inspirations for this project could be the desire to create a more engaging and effective learning experience for students. How we built it Unity software for AR and VR , while we used python and kaggle for emotion detection model. For emotion detection Keras and openCV was used. In Unity we used vuforia for markerbased AR and GVR sdk for virtual reality modules such as teacher training module and some interactive modules for students. Challenges we ran into The model for creating emotion detection was taking too long to be created. The main issue faced was to manage scene inside the different modules. Uploading unity GitHub files as they are too large to push. Accomplishments that we're proud of Provided solution to the problem in such a interactive way that learning can be enhanced. Completed our work in limited time frame. Got good grasp on various technologies used. What we learned Improve our compatibility with AR ,VR and machine learning technologies. Teamwork. Three Members of our team were first beginner so this was a great learning experience for them. What's next for SimuLearn Create more interactive modules which would further enhance learning.
