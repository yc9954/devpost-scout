## Body

Inspiration The idea was to have a simple and easiest way for anyone to upload and make their ideas publicly available. With Filecoin and Web3[.]Storage, this can be made possible. I always tried to build something that'll help people with getting used to decentralised tools/software. The project aims to easily let people understand the potential of Filecoin and decentralised Software. What it does DeBook enables users to create eBooks for free on Filecoin Network (using Web3 Storage) and later be able to share them to friends, family or even later sell it for Cryptocurrency. DeBoook is a eBook marketplace that lets users mint their Books. How we built it The core dependency of DeBoook is Filecoin and web3[.]Storage. React frontend is build from where the users can upload book or read book available to read for free. We also used ConnectKit to enable users connect wallet of their choice. Challenges we ran into As a beginner, It was challenging to use various dependencies and tools. But learnt so many things on how to use these tools. Web3.storage was the sweetest integration that have been done in this project. Accomplishments that we're proud of Successfully shipping an app that lets people upload data to a decentralised network is cool and it was done and moreover this will atleast have some usecase for people if not huge. What we learned How to build for a hackathon from idea to actually shipping and the challenges that you may face while building it which you thought would never be a problem. What's next for DeBoook Adding features like buying book for crypto on the platform and add fiat solutions.
