Key Features Agent Charts AgentPlus Voice Navigate to Object tab Navigate to Record Memory Set stored from Agentforce Retrieve a Memory Set Inspiration I wanted to learn Agentforce, so I started studying and experimenting with it. I saw this as a great opportunity to gain hands-on experience. As I explored its capabilities, I asked myself, “What would make this tool even more seamless for users?” I focused on improving the overall user experience, and not just for specific use cases. So I started thinking about it on a daily basis. That’s how AgentPlus was born. What it does AgentPlus is a suite of enhancements that extends Agentforce’s capabilities by focusing on speed, context, and natural interaction—so users can love Agentforce even more! Its features fall into these main categories: Smart Navigation : New actions help navigate the Salesforce UI across apps, tabs, and records more efficiently. Visual Charts : Agentforce can now respond with interactive charts, making your data easy to visualize during a conversation. Memory Sets : Users can save the context of a conversation—including notes and related records—so topics can be recalled later with ease. AgentPlus Voice : A conversational interface using voice or chat, enabling users to interact with the agent naturally and hands-free. It also supports session continuity across devices. How we built it It’s built entirely using Salesforce Core functionality—no external solutions or services required. That means Flows, Lightning Web Components, Apex, and the Agentforce Builder. Challenges we ran into Agentforce can be tricky at times, and the way to get things working may sometimes be challenging to find. Speech recognition and synthesis also remain inconsistently supported across browsers. Accomplishments that we're proud of Chart visualization works remarkably well in a consistent way. Achieving reliable speech interaction was a challenge, but very rewarding once it worked. What we learned Above all, I learned Agentforce—this was my first real hands-on experience with it. The Speech API was also new territory for me. What's next for AgentPlus Lots of exciting things! Smart Navigation : Navigate to any tab or component. Visual Charts : More chart types, table views, advanced filter logic, improved date handling, Id-to-name conversion, and more. Memory Sets : Add records directly from a record page, support for more data types, etc. AgentPlus Voice : Salesforce Mobile App support, enhanced animations, and more. <div
