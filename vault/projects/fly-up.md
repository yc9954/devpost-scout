## Body

How the game looks Title Inspiration From a nostalgic game on mobile platform called Rise Up. What it does It is a game recreation that focus on protecting avatar from floating obstacles, testing players’ reflexes and timing. How I built it Creating the game was challenging yet rewarding experience and implementing certain features was a learning phase, Animations, Assets, levels were all built without using AI. Challenges we ran into Creating the state machine of the game and managing many objects on screen. This required careful planning and execution to ensure smooth gameplay even on older devices.
