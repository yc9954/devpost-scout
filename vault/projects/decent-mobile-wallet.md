## Body

Inspiration With the rise of Web3 adoption, more people need secure, fast, and easy-to-use mobile wallets to manage their crypto assets. Many wallets are either too complex for beginners. We wanted to build something that is: ✅ User-friendly for both beginners and experienced users ✅ Highly secure to protect assets from unauthorized access ✅ Optimized for the Electroneum Smart Chain to take advantage of low fees and fast transactions What it does Decent Mobile Wallet is a secure, non-custodial mobile wallet that allows users to: 🔹 Store, send, and receive ETN and other Electroneum-based assets 🔹 Easily import and back up wallets using private keys or seed phrases How we built it We developed Decent Mobile Wallet using: React Native for a cross-platform mobile experience (iOS & Android) Electroneum Smart Chain SDK & Ethers.js for blockchain interactions Secure storage mechanisms for private key encryption Challenges we ran into Handling Private Keys Securely 🛡️ – Ensuring private key encryption and secure storage without exposing sensitive data. Optimizing Gas Fees ⛽ – Making transactions more cost-effective by optimizing ETN gas usage. Seamless UI/UX 📱 – Creating an interface that is simple for beginners but powerful enough for advanced users. Accomplishments that we're proud of ✅ Fully functional mobile wallet that enables easy ETN transactions ✅ Highly secure wallet encryption to protect user funds ✅ Beautiful, intuitive UI that makes managing crypto simple and hassle-free What we learned Security is everything – Handling private keys requires strong encryption and best practices. User experience matters – A crypto wallet must be fast, intuitive, and reliable. Electroneum Smart Chain is powerful – Its low fees and EVM compatibility make it ideal for building scalable Web3 applications. What's next for Decent Mobile Wallet 📡 Built-in Swap & Staking – Allow users to swap tokens and stake ETN directly in the wallet. 🔐 Biometric Security – Add Face ID / Fingerprint authentication for enhanced protection. 🎯 NFT & Token Portfolio – Let users track and manage NFTs and ERC-20 tokens within the app. Decent Mobile Wallet is just getting started—we're building the future of secure and easy mobile crypto transactions! <div
