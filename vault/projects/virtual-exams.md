## Body

Inspiration During the covid time when classes have gone online there is no reliable way to conduct test and exams online without leading to cheating. What it does We have created safe, secure and reliable portal to conduct exams where doing cheating is much harder when compared to test and quizzes conducted on google forms. How we built it We built the portal using Java Spring Boot framework and Angular. Challenges we ran into We ran into many challenges while building this like: Not allowing tab switching. Scheduling exams and declaring result on time. Showing student performance graph. Accomplishments that we're proud of A secure and reliable portal to conduct exams. Option for faculty to schedule exams in advance. Showing student performance graph which will be helpful to monitor student performance over the period of time. What we learned We learned how a system like this should be built and what functionality it should have. How can we keep user engaged in our platform. What's next for Virtual Exams Making it more secure by adding proctoring using camera and voice. An option to create assignments and post resources hence removing the need for different platform (like Google Classrooms) for other tasks. An option to conduct classes through it and removing the need for Google Meet and other platforms. <div
