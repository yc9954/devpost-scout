Inspiration I learned JavaScript recently and had been wanting to create a small quiz project but struggled to find the time or motivation to start. However, when I saw this hackathon, I felt compelled to participate and finally bring this idea to life. What It Does The project is a quiz application, but with intentionally frustrating questions and features designed to annoy and provoke people. How I Built It The application was built using HTML, CSS, and JavaScript, with additional styling coming from CSS Bootstrap library. Challenges I Faced One significant challenge was implementing the popup feature. After restructuring my project folders, I forgot to update the CSS file link. This resulted in the popup displaying as plain text. Debugging this issue was hard because the Bootstrap classes were still functioning correctly, hiding the cause of the problem. Accomplishments I Proud Of I’m particularly proud of the unique and challenging features integrated into this quiz. The goal is to create an experience that will annoy and test users’ patience. If I can successfully elicit those reactions, I’ll consider the project a success. Lessons Learned Building this project deepened my understanding of JavaScript and its core principles, particularly through practical implementation and problem-solving.
