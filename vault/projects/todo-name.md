Logo Gameplay Inspiration The main inspiration to build this project was trying to combine gaming and web3. What it does Nervos Lands is an alpha version (prototype) of the blockchain-game village simulator using Godwoken Layer 2 (Nervos Network). The main goal is to develop the economy of your village. To play the game player creates a village. Each village has its own smart-contract address to store data of all attributes, resources and etc. Players can save/load it.
