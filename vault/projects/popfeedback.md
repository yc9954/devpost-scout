## Body

PopFeedback is all-in-one feedback solution for your team , it handles everything so that you can spend time on your product. Built-in UI solution in order to minimize development time Show feedback & bug reports directly in your board One line integration for developers in order to make their life easier Inspiration Launching a product is one thing; however, evolving your product with user feedback is crucial for the long-term success of products. As a lead developer in my team, our most painful problem is effectively collecting feedback and bug reports from our users in a unified dashboard. With PopFeedback, we aim to solve one of the most common problems across IT teams by integrating feedback and bug-reporting tools with Jira boards. What it does PopFeedback enables IT teams to actively collect user feedback and unify it in a single JIRA dashboard. Here is how it works: PopFeedback has customizable built-in UIs. The purpose of these interfaces is to make it possible to collect bug reports, feedback, and reviews from end users. All without needing to build separate UI or backend code from the developers and designers. It only takes a single line of code to implement the PopFeedback framework into their apps! Open source Links Forge-Backend iOS-SDK (Swift) Android-SDK (Kotlin) How we built it PopFeedback uses: Forge modules, Forge admin page, Forge web trigger endpoint, Forge UI elements IOS client SDK (Swift) Android client SDK (Kotlin) Challenges we ran into Offering highly customizable frameworks with one-line integration was a critical value we wanted to provide with this add-on. Due to insisting on making the integration as seamless as possible, the main challenge we had to tackle was connecting multiple platforms, which are Android, IOS, and Force, in a parameterized fashion. Accomplishments that we're proud of We have already received multiple requests from mobile app development companies to integrate the add-on into their products. They wanted to collect user feedback and bug reports from various apps into a single JIRA board. Getting prospective users even at a hackathon stage is one of the best feelings and showcases the demand for the add-on! What we learned We found the Forge solution range quite impressive during our development. For instance, the Forge web trigger API opens the doors to limitless capabilities when integrating anything from the web into the JIRA world.
