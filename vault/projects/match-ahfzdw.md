Match ! Inspiration Cex platform trading What it does Create limit order. Create an order without having the sufficient sum when creating it. Allowing you to create scenarios such as depositing $30,000, creating an order to buy 1Btc at $30,000 and creating a second order to sell 1Btc at $31,000, the second order can only be executed once the first has been filled. How we built it With solidity and react Challenges we ran into Have a real decentralized limit order Accomplishments that we're proud of Execution really decentralized, anyone can call up the contract, so we can automate order creation or match them using bots with no particular rights to the contract.
