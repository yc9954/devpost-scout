## Body

Inspiration Chatgpt can give users explanations on any queries, what if there is a short personalised tutorial on user's query? Would that bring user's understanding and experience to a different level? What it does Give a short personalised tutorial on any academic queries user has, act as an online teaching class, with explanations, examples, practice etc. How we built it It was built in: https://partyrock.aws Challenges we ran into The challenging part was to control the visibility of some of the widgets as for instance, the user doesn't need to see the answers for the practice questions when the user is working on the question, so we had to create some gaps to seperate the answers and the questions so that the user has to scroll down the page to access the answers of the questions. Accomplishments that we're proud of We were able to successfully construct all the essentials for a normal tutoring class, we took in account of all the possible features and sessions. What we learned AI is evolving rapidly and that more technologies like this will be made in the future, in every aspect of our lives, the normal way might be changed sooner or later. What's next for AI Online tutorial More functionalities with subject/course/discipline driven categories, so that there are some basic, general courses already generated under each categories and that the user can choose the course they want to have, or by type in specific query to have their personalised course.
