Inspiration The connection between catgirls and blockchain. What it does We have created a project that allows you not only to have fun with friends and find new acquaintances, but we also showed other developers how games and blockchain can be combined. We showed how you can make a decentralized game. How we built it We considered several options and came to the conclusion that unity is a perfect fit and connects to the mirror. We decided to build on this when creating the game. There were other options, for example - Defold and Nakama, but it would be much faster to develop such a project on unity + Mirror Challenges we ran into We have gone through the difficulties of identifying the best solutions and combining different solutions. Setting up adequate communication was also not easy, but we managed. Accomplishments that we're proud of It works. With difficulty, but it works.
