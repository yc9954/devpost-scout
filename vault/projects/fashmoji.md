About the Project Inspiration The project was inspired by the idea of turning fashion and makeup into a playful form of self-expression. The goal was to create a fun, trend-driven experience where users can experiment with glam looks and feel confident showing off their style through a Bitmoji. What Was Built This project is an interactive fashion and makeover game where players style their Bitmoji using makeup presets, unlock premium looks, and experiment with bold, glittery aesthetics. It focuses on fast creativity, visual impact, and a strong fashion-forward identity. How It Was Built The experience was built in Lens Studio , using scripted makeup presets, modular UI components, and a persistent unlock system to track premium items. Gather more heart wallet points when you capture and share on snapchat . Makeup layers were applied dynamically to the Bitmoji, with careful optimization to stay within Lens size limits while keeping visuals polished. Challenges One of the biggest challenges was time — the project was built in one week after a last-minute decision to fully commit to the idea. Applying makeup correctly on the Bitmoji without visual glitches required multiple iterations, and staying within the Lens file size limit while adding premium visuals and UI elements added extra complexity. What Was Learned This project reinforced the importance of rapid prototyping, optimization, and clean system design under tight deadlines. It also provided hands-on experience with Bitmoji customization, UI state management, and persistence in Lens Studio.
