## Body

Sample screenshot showing the result of SurpriseMeSpotify. A playlist with recommended songs. Inspiration Frustrated by the same music recommendations from Spotify, decided to create SurpriseMeSpotify which recommends songs not based on history but according to your taste. What it does SurpriseMeSpotify recommends music tracks based on the favorite artists provided by the user as an input. Users can fine tune recommendations based on various music attributes like dancability, instrumentalness, energy etc. How we built it This project is built using Postman and Spotify REST API. Challenges we ran into The links in the visualization cannot be opened in an external browser. Postman runner does not show visualizations for the response body. Accomplishments that we're proud of A ready to click, personalized music list with modern interface. What we learned About postman visualizations Pre-Scripts and tests to write custom logic for APIs Postman Runner Linking Postman requests Looping postman requests Setting env variables from code What's next for SurpriceMeSpotify Currenlty this tool uses only 2 APIs. This can further be extended to make full use of all the REST APIs provided by Spotify.
