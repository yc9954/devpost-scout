## Body

Inspiration We were inspired by Dress To Impress on Roblox originally since that's what I was playing when I had brought up the non-technical pathway to my partner. We then decided to add the bunny girl twist since there were extra points for bunny related themes. What it does Bunny Up is a fashion game where the user can dress up their own bunny girl with different skins, hair colors, boots, dresses, and much more! It aims to be a cute and fun experience for everyone to have! How we built it The game is built solely using Figma and this would be on the non-code pathways. It is built by utilizing flows and connections to allow the transition when the user chooses a certain design/part of the bunny girl. This is both of our first hackathons, so please go easy on us! Challenges we ran into -removing the background: for some reason, online background removers don't work for Figma, so I had to research and figure that out for approximately an hour before being able to integrate the art pieces. -layering: the arrows were layered under the images so it wasn't working properly. My last braincell took 30 minutes to figure this out. Accomplishments that we're proud of -the game itself has over 1000 design possibilities! There are currently a 100 in the system since they need to be manually put in (thus some don't work), but by the end of the week, they all should be in! -being able to efficiently program something which includes original art and is able to feel different than most fashion games due to its unique art style. What we learned -Figma is easier than we thought -It actually isn't that hard to make a game without any programming! What's next for Bunny Up -more design combinations! -better backgrounds and designs! -more functions!
