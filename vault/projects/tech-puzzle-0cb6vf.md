## Body

Home Level 3 Level 2 Level 1 Inspiration I have always been a fan of spy movies and computer science trivia. This game is the product of both of my interests. What it does This game provides with a set of clues, instructions and actions in each puzzle. After carefully observing the level you have to deduce your answer. This games hope to give you a huge headache fuel. How I built it I built it using Pygame Framework, Royalty Free Music and assets from opengameart.com and other sources. Challenges I ran into There were a number of times when I got stuck in implementing a feature like making switches in Level 2. and creating a typing section in Level 1. But thanks to the amazing Pygame Hackathon, I was able to solve those challenges. Accomplishments that I am proud of I am proud that I was able to finish this project in the limited time without any prior experience with Pygame. What we learned While building this project I learnt a lot about state management and Object Oriented Design Principals.
