## Body

Inspiration I was thinking about the Pomodoro method, and how it helps people focus and get their work done more efficiently. I realised that young people like me, that are into brainrot content, would very much be motivated by getting this content for progress rewards for completing work. What it does The app asks the user to enter their assignment task and then the user starts writing their work into the app directly. Every 50 words, which is the defined milestone, the user can choose to evaluate their answer. This uses an LLM to evaluate whether the text entered is valid content relevant to the prompt. If it is, the user is rewarded with memecoin cryptocurrency to their account, and is also shown a fresh brainrot joke to keep them entertained. How we built it The memecoin cryptocurrency is implemented using the Internet Computer, which runs a global distributed blockchain for public use. The LLM uses the OpenAI API along with some clever prompt engineering to get appropriate responses. What's next for BrainrotFocus The current iteration is a very rudimentary prototype for the app. The next step for me would be for the website to load brainrot reels directly from Instagram / TikTok, because LLMs aare admittedly not the best at creating brainrot jokes! Additionally, this could be part of a much, much bigger project that could be a creatorspace for brainrot content. Users pay with the memecoin currency in-app to subscribe to creators' content and they can earn this cryptocurrency by doing their work. This way, a major problem students face, doomscrolling instead of locking in, is solved by linking access to content with completing their work.
