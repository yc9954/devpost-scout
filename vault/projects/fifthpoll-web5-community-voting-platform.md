Landing Page Cast Vote Page All Events Page Voting Modal Add Event Inspiration and Vision 😸 The inception of Fifth Poll was fueled by a passion for inclusivity and wanting to simplify decision-making processes within communities and groups. We envisioned a platform where every individual's voice will be heard, irrespective of their background or status. The goal was to create a space where collective decisions could be shaped democratically, fostering a sense of empowerment and engagement among participants. Learning and Problems Faced 🚀 It was very exciting to learn about various alternative voting methods, our current de facto standard of "One Person, One Vote" is being rapidly taken over by other methods and we started this project with the aim in mind to be able to incorporate all these into the fifthpoll application. We were not able to implement all these yet but the learning process was definitely very fun! This was our first time working with web5 and there was definitely a learning curve. learning about these new concepts of Dwns, Dids, Protocols etc was very enticing as this was something very new to us but the ideas proved their usefulness throughout the development process. We faced some problems throughout the development process. We wanted to implement roles and it was definitely difficult but we managed to eventually implement it which made the platform secure as we can pre define who can vote for a given event. Also, we learned about a bug which is fixed in the alpha but the nvm version does not fix it so in the deployment version, voting on other peoples events does not work but voting on your own event does. This bug does not exist in a local environment as you can link to the alpha. Future Scope of the Project 🚀 Alternative Voting | We started the project with the goal in mind to implement various forms of voting methods and let the user choose this during the event customization process when they are starting a new event. Despite the fact that we were not able to do it during the hackathon's time period this still remains as a top priority for our future prospects. Implementing systems like Quadratic Voting, Weighted Voting, Priority voting etc... Groups | We aim to add "groups" which will have saved Dids for events. so in the "Who can vote" section people will be able to add xlsx, csv, json etc. they can save these lists in groups to easily be able to make new events with the same group of people who can vote thus easily allowing community management. User-Driven Development 👥 Central to the Fifth Poll ethos is the acknowledgment that the community plays a pivotal role in shaping the platform. Feedback from users has been instrumental in refining and enhancing Fifth Poll, turning it into a truly community-driven initiative. The commitment to continuous improvement remains steadfast, with the community actively participating in shaping the future of online voting. <div
