## Body

Inspiration I was trying to watch movies, but most of them were behind a paywall. When searching for download links, I found it frustrating and time-consuming to navigate through numerous unreliable sources. This inspired me to create OtakuHaven, a platform to simplify access to quality content. What it does OtakuHaven provides a centralized hub for anime , movie and TV shows enthusiasts to easily discover and access their favorite titles. It saves users time and effort by aggregating reliable links, and more in one user-friendly interface. How we built it We developed OtakuHaven using: Frontend: React.js for building a dynamic and responsive user interface. Hosting: Vercel to deploy the platform with speed and reliability. Challenges we ran into Finding reliable sources for content aggregation without infringing on intellectual property. Ensuring the platform remains user-friendly while implementing multiple features. Accomplishments that we're proud of Successfully building and deploying a functional prototype of OtakuHaven. Implementing a smooth and intuitive user interface with React. What we learned Improved our skills in web development using React and Supabase. Understood the importance of balancing user experience with efficiency. Gained insights into deploying web applications effectively using Vercel. What's next for OtakuHaven Expanding the database to include a larger variety of movies and anime.
