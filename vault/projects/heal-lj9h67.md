## Body

Inspiration Web3 is in trend these days and I'm extremely inclined towards new rising technology. I'm always looking for opportunities to invest in technologies with great utilities and roadmap. Since there are many NFT based projects releasing on daily basis it amuses me to contribute in some of these projects . This project will enable investors to find new opportunities and buy an, lazy mint, sell and transfer NFTs through ERC-721 smart contract. What it does Showcase, mint, sell, buy, and transfer NFTs ERC-721 smart contract Adheres to strict NFT provenance best-practices SEO optimised responsive site Allows "lazy minting" (offer NFTs without pre-minting them; buyer pays gas to mint) Shows links to Opensea & Rarible for secondary sales Re-assignable role for catalog management Configurable revenue shares Configurable royalty Deployable on any EVM blockchain (Ethereum, Polygon, etc) How we built it The frontend is built with next.js and is deployable on Vercel The client app has been tested against Ethereum testnet (Rinkeby) Tech stack used Javascript Solidity Opensea NextJS Challenges we ran into Integrating front end with the smart contracts was the hardest challenge What we learned This project surely exposed me to new opportunities and challenges like learning new frameworks and deploying it on Polygon What's next for NFT-Surface Add multi-chain compatibility <div
