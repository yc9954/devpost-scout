## Body

“From sensor to screen, real-time water quality monitoring using IoT and mobile app integration.” Inspiration Access to safe drinking water remains a critical challenge in many regions. Contaminated water can lead to serious health issues, yet real-time monitoring solutions are often unavailable or expensive. Our project was inspired by the need to create an affordable, scalable, and efficient system that ensures water safety through continuous monitoring. What it does The system monitors essential water quality parameters in real time: pH level Temperature Turbidity These parameters are evaluated against safe standards: Ideal pH range: ( 6.5 \leq pH \leq 8.5 ) Turbidity (NTU): ( T < 5 \, NTU ) Temperature affects chemical reactions and sensor accuracy If any parameter exceeds safe thresholds, the system triggers alerts for immediate action.
