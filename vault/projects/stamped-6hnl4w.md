Sales Pipeline Risk Assessment Client List Page Login Screen Landing Page Entire Front Screen Inspiration Wanted to find a unique problem in the banking industry. We realized the financial institutions struggle with inefficient processing like manual onboarding. We then attempted to solve this problem. What it does Stamped is an intelligent onboarding platform that manages the entire client lifecycle from lead prospecting to full onboarding. How we built it We built Stamped using Next.js 14 and TypeScript for the frontend with a custom component library, integrated Supabase for authentication and database management. Challenges we ran into Creating a multi-role system where each user type (clients, vendors, employees) that had interconnected workflows was extremely difficult. Accomplishments that we're proud of Putting everything in a proper land page and shipping a very challenging project. What we learned We learned how to build complex role-based applications with proper separation of concerns, and gained experience with modern React patterns and TypeScript for type-safe development.
