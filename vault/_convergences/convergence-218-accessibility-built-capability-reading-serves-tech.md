# 3 projects, 3 hackathons, one claim

**Shared vocabulary** accessibility, built, capability, reading, serves, technology

### [[esper-fy6xeh]] — Epileptic Seizure Prevention and Early Response (ESPER)
> rapid brightness changes in video trigger seizures and the web serves them to everyone, so an accessibility harm is built into ordinary content

*ShellHacks 2024* · problem: rapid brightness changes in web video endanger people with epilepsy

### [[vditory]] — VGlass
> assistive technology for blind people focuses on reading and the wider need is acting in the world, so the accommodation stops short of the capability

*Junction 2016* · problem: blind people need to read and to do more than read

### [[spywatch]] — SpyWatch
> lip reading recovers speech where audio is unavailable, so a capability built for accessibility is also a surveillance tool and the same technology serves both

*Hack the North 2024* · problem: speech cannot be captured in audioless environments
