# 3 projects, 2 hackathons, one claim

**Shared vocabulary** access, apis, nobody, public, without

### [[movie-classics]] — Movie Classics
> works in the public domain belong to everyone and are practically unavailable because nobody distributes them, so common ownership without distribution is not access

*Amazon Alexa Skills Challenge: Multimodal* · problem: public domain films are part of the shared cultural heritage and hard to watch

### [[public-workspace-for-nasa-open-apis]] — NASA Open APIs Public Workspace
> public scientific data is released as APIs and used by almost nobody because the first call is unclear, so openness without an entry point is not access

*The Postman API Hack* · problem: scientists and engineers cannot easily test and explore open space data APIs

### [[creative-commons-explorer]] — Creative Commons Image Explorer
> openly licensed media exists in museum collections and is unreachable without knowing the APIs, so the licence is free and the access is not

*The Postman API Hack* · problem: developers with no budget cannot easily find and use openly licensed media
