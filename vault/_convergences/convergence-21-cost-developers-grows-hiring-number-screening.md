# 4 projects, 4 hackathons, one claim

**Shared vocabulary** cost, developers, grows, hiring, number, screening

### [[agentdeck-mission-control-for-ai-coding-agents]] — AgentDeck - Mission Control for AI Coding Agents
> developers run several agents concurrently and switch between terminals to see what each is doing, so supervision cost grows with the number of agents and nothing shows their state at a glance

*DevStudio 2026 by Logitech* · problem: managing multiple concurrent coding agents is chaotic with constant window switching

### [[hiredesk]] — HireDesk
> hiring breaks at scale because screening cost grows with the number of applicants while the number of hires does not, so more reach makes the process worse

*Frostbyte Hackathon* · problem: recruiters receive over a thousand applications per role and spend 60 to 70 percent of their time screening

### [[trial-kjzbys]] — Data Engineer's Buddy
> enterprise data spread across many databases on different systems makes every question an engineering project, so the cost of knowing anything grows with the number of systems

*Building the Next-Gen Agentic App with GraphRAG & NVIDIA cuGraph* · problem: data in large organisations is spread across multiple databases and management systems

### [[c-mon-ai-check-my-skills]] — C'mon, AI, check my skills
> the number of developers grows and screening each one costs the company time, so hiring is bottlenecked on the cost of verifying skill rather than on candidates

*Chainlink Spring 2023 Hackathon* · problem: companies spend increasing resources checking developer skills before hiring
