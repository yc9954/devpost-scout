# 3 projects, 3 hackathons, one claim

**Shared vocabulary** asset, between, change, game, meaningful, progression, token

### [[chinwag-zp4jds]] — Chinwag
> each tool in a production chain is capable and the context that made an asset meaningful is destroyed at every handoff between them

*Global AI Hackathon Series with Qwen Cloud * · problem: provenance is lost at tool boundaries, so the final artifact cannot be traced to its evidence

### [[dynamic-nfts]] — Dynamic Metadata
> an in-game asset that cannot change between sessions cannot represent progression, so the plugin that syncs game state to token metadata is what makes the asset meaningful

*Theta Network 2023 Hackathon* · problem: game actions do not reflect in the assets they should change

### [[tokenrage]] — TokenRage
> an asset that cannot change makes a game repetitive, so progression requires the token itself to be mutable

*Chainlink Fall Hackathon 2021* · problem: NFT games have limited functionality and repetitive mechanics because assets are static
