# 3 projects, 3 hackathons, one claim

**Shared vocabulary** between, crisis, matching, nobody, owns, problem

### [[covidstay]] — COVIDStay
> in a crisis the scarce resource is safe accommodation for the responders, and nobody owns the problem of matching it because it falls between housing and health

*Pandemic Response Hackathon* · problem: an emergency management organisation needed accommodation for high-risk medical staff

### [[navcare]] — Navcare
> a personal support worker's day is mostly travel between visits, so the staffing crisis is partly a routing problem nobody has treated as one

*Hack the North 2022* · problem: support workers spend their capacity travelling between appointments

### [[taxiya]] — TAXIYA (My Taxi)
> a taxi and a passenger looking for each other is a matching problem solved by chance on the street, so the inefficiency is symmetrical and nobody owns it

*Ford Code for Taxicabs Mobility Challenge* · problem: finding taxis and finding passengers both rely on physical proximity and luck
