# 3 projects, 3 hackathons, one claim

**Shared vocabulary** produce, programming, teach, tools

### [[snappier]] — Snappier
> most people cannot automate their work because automation tools require programming — APIs, data mapping, conditional logic — and those same people teach coworkers how to do things all the time

*TreeHacks 2026* · problem: everyone can demonstrate their process and almost nobody can specify it, and automation only accepts specifications

### [[code-by-voice]] — Voice Coder - Alexa Skill
> tools that teach STEM need to be exciting and produce quick results, and traditional programming produces neither for a beginner

*Alexa Skills Challenge: Tech for Good* · problem: the first hour of programming has the highest dropout and the lowest visible output

### [[refinelab]] — RefineLab
> writing assistants produce text and none of them teach the skill, so the abundance of AI writing tools has made improvement rarer rather than easier

*Student HackPad 2025* · problem: students have many tools that write for them and none that analyse their own writing
