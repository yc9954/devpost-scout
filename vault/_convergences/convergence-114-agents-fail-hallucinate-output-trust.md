# 3 projects, 3 hackathons, one claim

**Shared vocabulary** agents, fail, hallucinate, output, trust

### [[mulder]] — Mulder
> the hard part is not sifting hundreds of gigabytes of forensic evidence autonomously, it is producing output you can trust from a system that can hallucinate

*FIND EVIL!* · problem: autonomy in an evidentiary domain is worthless unless the architecture makes a fabricated finding structurally impossible

### [[reflexionos-the-self-improving-agentic-operating-system-s94vle]] — ReflexionOS — The Self-Improving Agentic Operating System
> agents can reason, plan and act, and they rarely improve themselves — most fail silently, hallucinate, or repeat inefficient patterns, and when a task fails the system simply retries

*Frostbyte Hackathon* · problem: failure produces no learning, so the same cost is paid indefinitely

### [[novaflow-ops]] — NovaFlow Ops
> agents fail on trust rather than capability: they hallucinate or act without proof, so the output cannot be relied on even when it is right

*Amazon Nova AI Hackathon* · problem: automation produces results with no evidence that they happened as described
