# 3 projects, 3 hackathons, one claim

**Shared vocabulary** anyone, create, election, identities, many, mechanism

### [[governor-c-sybil-resistant-quadratic-voting-system]] — Governor C: Sybil-Resistant Quadratic Voting System
> quadratic voting is the most developed fair-election mechanism and is defeated by anyone able to create many identities, so its fairness depends on a personhood assumption the system does not enforce

*Chainlink Fall Hackathon 2021* · problem: DAO governance using quadratic voting is exposed to sybil attack

### [[web3-reputation-oracle]] — Web3 Reputation Oracle
> an identity system that lets anyone create identities cannot distinguish a person from a thousand of them, so self-sovereign identity and sybil resistance are in direct tension

*Chainlink Spring 2022 Hackathon* · problem: decentralised identity gives control and provides no defence against sybil attacks

### [[verivote]] — VeriVote
> election fraud in many places is physical rather than digital, so replacing the ballot box with an identity-bound device attacks the actual mechanism of rigging

*Quick Base Virtual Hackathon* · problem: ballot box stealing, stuffing and thuggery in a country of 200 million
