# 6 projects, 6 hackathons, one claim

**Shared vocabulary** anyone, choice, decides, different, fails, group's, input, keyboard, mouse, physical, preference, social

### [[digital-physical-darts-wii-darts]] — Physical Digital Darts (Wii Darts)
> playing a game means keyboard and mouse by default, so the physical activity a game could have represented is designed out before anyone considers it

*Cal Hacks 12.0* · problem: computer games exclude physical play and accessible input

### [[ctrl-arm]] — Ctrl-ARM
> keyboard and mouse require a specific physical capability, so the input device rather than the software decides who can operate a computer

*ShellHacks 2025* · problem: traditional input limits accessibility and hands-free use

### [[pickle-savnjb]] — Pickle
> a group's destination choice fails because each person weighs different attributes, so the decision problem is preference aggregation rather than recommendation

*Disrupt SF Hackathon 2018* · problem: a friend group cannot decide where to travel together each year

### [[flock-figure-out-what-film-to-watch-with-friends]] — flock
> a group's choice fails because no one wants to name a preference first, so revealing only the overlap removes the social cost of choosing

*Hack the North 2020++* · problem: friend groups cannot agree on what to watch

### [[christmas-cat-game]] — Christmas Cat Game
> the input modality decides who can play, so defaulting to keyboard and mouse is an accessibility decision made without anyone making it

*AWS Game Builder Challenge * · problem: games assume a standard controller and exclude players who cannot use one

### [[slideparty]] — slideparty
> a group game fails when one member is on a different operating system, so cross-platform reach is a social requirement rather than a technical preference

*Flutter Puzzle Hack * · problem: playing together requires everyone on compatible devices
