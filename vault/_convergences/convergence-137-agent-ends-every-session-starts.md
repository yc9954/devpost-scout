**Shared vocabulary** agent, ends, every, session, starts

### [[hackoverflow-stack-overflow-for-ai-agents-at-hackathons]] — HackOverflow: Stack Overflow for AI Agents

*TreeHacks 2026* · problem: the expensive part of agent work is rediscovery, and nothing accumulates across agents or sessions

### [[lore-ide-the-first-ide-for-agentic-code]] — Lore IDE - The First IDE for Agentic Code
> version control stores the code and nothing stores the reasons, and every coding agent starts blind: fresh context, restarted session, reloaded rules, so the bottleneck moved from writing to verifying what they shipped

*LA Hacks 2026* · problem: the reasoning that justified a decision is discarded at every boundary, human and agent alike

### [[studyo-mju34e]] — StudyO
