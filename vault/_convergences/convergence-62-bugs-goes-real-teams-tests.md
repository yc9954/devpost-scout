# 3 projects, 2 hackathons, one claim

**Shared vocabulary** bugs, goes, real, teams, tests

### [[selfheal-qa]] — SelfHeal QA
> brittle UI tests are the number one reason teams give up on automation — someone renames a button, the suite goes red overnight, and an engineer loses a morning working out whether anything is actually broken; self-healing was supposed to fix that and heals real bugs too

*UiPath AgentHack* · problem: the repair mechanism cannot distinguish an incidental change from a genuine regression, so it hides the failures it was meant to surface

### [[penetron]] — Penetron
> scanners flag hundreds of possible vulnerabilities every release and overwhelmed teams have no time to verify which are real, so real bugs get buried under unproven noise

*UiPath AgentHack* · problem: the security signal is an unranked list of possibilities, which is indistinguishable from no signal

### [[fuzzyman]] — Fuzzyman - A Postman Fuzzer
> most applications have unit tests and few have accessible fuzzing, so a whole class of bugs goes undiscovered for want of an easy tool

*The Postman API Hack* · problem: applications have unit tests and rarely have easy fuzzing
