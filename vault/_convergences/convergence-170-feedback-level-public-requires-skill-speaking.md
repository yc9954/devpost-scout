# 3 projects, 3 hackathons, one claim

**Shared vocabulary** feedback, level, public, requires, skill, speaking

### [[clear-speech]] — ArticuLab
> public speaking is a skill many seek and few master, in part because improving requires a high level of individualised attention and feedback

*TreeHacks 2023* · problem: the input that produces improvement is a person's undivided attention, which is the scarcest resource available

### [[linguamate]] — Lingomate
> language platforms teach everything except speaking because speaking requires a listener, so the one skill people learn a language for is the one that is not practised

*EducateHacks 2024* · problem: language learning platforms have a gap in speaking practice

### [[reservoir-levels]] — Reservoir Levels
> a reservoir's level is public and nobody watches it, so a shared resource declines with no feedback reaching the people consuming it

*Chainlink Fall Hackathon 2021* · problem: California reservoir levels fell consistently while residents had no connection to the number
