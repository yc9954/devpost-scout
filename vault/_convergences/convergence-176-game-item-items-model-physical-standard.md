# 3 projects, 3 hackathons, one claim

**Shared vocabulary** game, item, items, model, physical, standard

### [[graph-goose-your-teamwork-graph-mapped-to-the-real-world]] — Graph Goose — Your Teamwork Graph mapped to the real world!
> work in manufacturing is tracked as abstract items and the components are physical objects, so the tracker's model does not match the thing being built

*Codegeist 2025: Atlassian Williams Racing Edition* · problem: teams work on complex physical systems tracked only as task items

### [[dna-dynamic-nft-asset-by-lync]] — DNA - Dynamic NFT Asset by LYNC
> an in-game item that cannot change is not an in-game item, so the static NFT standard is why traditional game studios have not adopted it

*Chainlink Fall 2022 Hackathon* · problem: upgradable NFT game assets lack simplified infrastructure and game developers cannot list them

### [[unique-space]] — Unique Space
> an in-game item that can contain other items makes progression physical rather than numerical, so nesting is a design primitive the standard NFT model lacks

*Polkadot Hackathon: North America Edition* · problem: tokens cannot hold other tokens so upgrades are recorded as attributes rather than as parts
