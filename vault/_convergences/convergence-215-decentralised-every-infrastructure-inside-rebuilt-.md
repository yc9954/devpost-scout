# 3 projects, 3 hackathons, one claim

**Shared vocabulary** decentralised, every, infrastructure, inside, rebuilt, storage

### [[fireview]] — Fireview
> every application that stores data ends up building a bespoke internal admin interface, so the same tool is rebuilt inside every product that has data

*Zero to One Hackathon by Convex Vol 2* · problem: teams repeatedly build custom interfaces to view and edit their own application data

### [[shiro-storage]] — Shiro Storage
> decentralised storage requires hosting a node, so an application that wanted to avoid infrastructure ends up operating some anyway

*Chainlink Fall 2022 Hackathon* · problem: IPFS practically requires hosting a service, defeating the point for a contract-only application

### [[metadrive-zbc738]] — Metadrive
> a project needing encrypted decentralised storage has to build it, so the same infrastructure is rebuilt inside every application that needs it

*Polygon BUIDL IT : Summer 2022* · problem: uploading and storing encrypted files in a decentralised way had no ready option
