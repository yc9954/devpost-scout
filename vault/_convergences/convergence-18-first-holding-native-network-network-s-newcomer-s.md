# 6 projects, 5 hackathons, one claim

**Shared vocabulary** first, holding, native, network, network's, newcomer's, paying, requires, token, transaction, without

### [[defi-for-people]] — DeFi for People
> adoption driven by a failing local currency arrives without the literacy to use the alternative safely, so a newcomer's first transaction is their riskiest

*Chainlink Spring 2022 Hackathon* · problem: crypto adoption is surging in Argentina and Chile because traditional finance is broken

### [[ayara-wallet]] — AYARA Wallet
> every additional chain requires the user to first acquire that chain's native token, so the proliferation of chains multiplies a chicken-and-egg problem for every user

*Constellation: A Chainlink Hackathon* · problem: using a new chain requires its gas token which must be bridged first

### [[transatron]] — Transatron
> a newcomer's first asset is a stablecoin and they cannot move it without a native token they do not have, so the first transaction is impossible by design

*TRON Grand Hackathon - HackaTRON Season 6* · problem: new users hold a token on a chain and cannot pay the fee to use it

### [[chainlink-paymaster]] — Chainlink Paymaster
> paying a network fee requires holding that network's token, so a user with dollars and no native token cannot transact at all

*Block Magic: A Chainlink Hackathon* · problem: users must acquire a specific gas token before doing anything

### [[cirotrx]] — CIROTRX
> a newcomer's first transaction requires holding the network's resource token, so the first step excludes exactly the people the network wants to onboard

*TRON Grand Hackathon - HackaTRON Season 6* · problem: novice users cannot transact without holding the network's resource token

### [[linkwallet-jo1p8n]] — LinkWallet
> a user must hold the network's token to pay a fee, so the first transaction is blocked and paying by card through a sponsor removes the prerequisite

*Chainlink Fall 2022 Hackathon* · problem: users must hold a gas token to transact
