# 3 projects, 2 hackathons, one claim

**Shared vocabulary** every, never, passes, scanners, vulnerabilities, wrote

### [[gauntlet-go-safe-or-go-home]] — Gauntlet - Go safe or go home
> agent evaluations tell you whether your agent passes the tests you wrote; they do not tell you what happens when a real attacker shows up with a prompt you never imagined

*UiPath AgentHack* · problem: the safety evidence is bounded by the author's imagination, which is the same boundary the attacker is outside of

### [[penetron]] — Penetron
> scanners flag hundreds of possible vulnerabilities every release and overwhelmed teams have no time to verify which are real, so real bugs get buried under unproven noise

*UiPath AgentHack* · problem: the security signal is an unranked list of possibilities, which is indistinguishable from no signal

### [[stylometry]] — STYLOMETRY
> scanners detect vulnerabilities in code and never ask who wrote it, so a threat that lives in the identity gap passes every gate cleanly

*Google Cloud Rapid Agent Hackathon* · problem: the review pipeline verifies artifacts and assumes the author
