# 3 projects, 3 hackathons, one claim

**Shared vocabulary** away, costs, created, effort, waste

### [[finger-dine]] — Finger Dine - Cook Eat Save
> a recipe calls for a quantity and shops sell a package, so the difference between the two is thrown away and the waste is created by packaging rather than by cooking

*The HCL-Pega Pathbreaker Hackathon* · problem: ingredients bought for a recipe are left over and discarded

### [[onesie-bazaar-share-unneeded-baby-clothes]] — Onesie Bazaar
> baby clothing is outgrown in weeks and discarded because giving it away costs more effort than it is worth, so the waste is created by transaction friction

*Alexa Skills Challenge: Tech for Good* · problem: unneeded baby clothing is thrown away rather than shared

### [[chainpilot-ai-yg2coj]] — ChainPilot AI
> teams waste effort assembling context for models rather than using them, so the fragmentation of the workflow costs more than the capability gains

*Frostbyte Hackathon* · problem: creators, engineers and product teams spend time reconstructing context across tools
