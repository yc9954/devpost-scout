# 3 projects, 3 hackathons, one claim

**Shared vocabulary** bespoke, blocked, contract, integration, requires

### [[dojo-game-launchpad]] — Dojo Game Launchpad
> the barrier to shipping a blockchain game is contract setup and payment integration, neither of which is game development, so the developer is blocked on work outside their craft

*Starknet Re{Solve} Hackathon* · problem: game developers face complex smart contract setup requiring specialised knowledge

### [[jira-hook-ninja]] — Jira Hook Ninja
> integration between tools is written repeatedly as bespoke code because the generic case requires a person who can code, so the connection is gated on engineering capacity rather than on the protocol

*Codegeist 2021* · problem: many applications must communicate with Jira over webhooks and each integration is built by hand

### [[chainlink-iris]] — Chainlink Iris
> getting live event data onto a contract requires a custom build every time, so anything conditioned on a live event is blocked by bespoke integration

*Chainlink Fall Hackathon 2021* · problem: getting live event data on chain requires a custom solution each time
