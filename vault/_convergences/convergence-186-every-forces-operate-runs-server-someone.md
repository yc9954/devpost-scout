# 3 projects, 3 hackathons, one claim

**Shared vocabulary** every, forces, operate, runs, server, someone

### [[evmos-me]] — Evmos.me
> a chain supporting two transaction models forces its users to operate two wallets, so a technical compatibility choice becomes a daily burden on every participant

*Cosmos HackAtom VI * · problem: users must run both an Ethereum and a Cosmos wallet to use one chain

### [[knn3-data-job-management-panel]] — KNN3 Data Job Management Panel
> contracts cannot process data and off-chain computation cannot be scheduled from them, so anything requiring both runs on a server someone must trust

*Chainlink Fall 2022 Hackathon* · problem: developers cannot process on-chain and off-chain data through contracts directly

### [[distributed-external-adapters]] — Hive
> an adapter that only runs in one environment forces every integration through a server someone must operate, so portability of the execution environment determines who can extend the network

*Chainlink Spring 2023 Hackathon* · problem: external adapters cannot run in browsers or native environments
