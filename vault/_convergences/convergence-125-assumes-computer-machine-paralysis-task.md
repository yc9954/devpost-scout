# 3 projects, 3 hackathons, one claim

**Shared vocabulary** assumes, computer, machine, paralysis, task

### [[firefly-adhd-focus-app]] — Firefly - ADHD focus app
> task paralysis is a starting problem rather than a planning problem, and every productivity tool assumes the user needs a better list

*Code with Kiro Hackathon* · problem: the tool addresses organisation when the failure is initiation

### [[hoya-helper]] — Hoya Helper
> a computer assumes a hand on a mouse, so paralysis removes access to the machine rather than to the task

*Hack for Humanity | 2025* · problem: people who are paralysed cannot control technology that assumes physical pointing

### [[ctrlairspace]] — Ctrl+Air+Space
> a computer assumes the user is sitting upright at the keyboard, so the posture people actually adopt makes the machine unreachable

*Hack the North 2020++* · problem: leaning back away from the desk while watching something leaves no way to control it
