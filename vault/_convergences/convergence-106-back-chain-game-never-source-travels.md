# 3 projects, 3 hackathons, one claim

**Shared vocabulary** back, chain, game, never, source, travels

### [[unravel-7ak8lf]] — Unravel
> a classification recorded as uncertain is treated as settled, and when it is later corrected the correction never travels back to the people it was about

*Google Cloud Rapid Agent Hackathon* · problem: knowledge updates flow forward to new cases and never backwards to old ones

### [[a-p1lt2h]] — Synapse
> a claim travels through a citation chain that is a game of telephone where everyone cites the same source, which may have been debunked or never replicated, and the reader has no way to walk it back

*TreeHacks 2026* · problem: provenance of an assertion is technically recoverable and practically never recovered

### [[wc-nft-fantasy]] — WC NFT Fantasy
> a prediction game needs an outcome source nobody can dispute, so the oracle rather than the game logic is what makes on-chain fantasy possible

*Chainlink Fall 2022 Hackathon* · problem: prediction games depend on trusted result reporting
