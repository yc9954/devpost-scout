# 3 projects, 3 hackathons, one claim

**Shared vocabulary** between, context, switch, tools

### [[lumina-ai-ti31qn]] — Lumina AI
> learning has always been a conversation and a sketch on a chalkboard, and most AI tools are voice-only or text-only, forcing the learner to context-switch between them

*DSH Hacks V1* · problem: the explanation and the drawing belong in the same moment and the tools split them

### [[cognilink-ai]] — CogniLink AI
> each switch between AI tools meant re-explaining context and manually stitching outputs

*Student HackPad 2025* · problem: the cost of using several specialised models is paid entirely in the human re-establishing context every time

### [[quickotp]] — QuickOTP
> two-factor authentication moves a code between two applications by hand, so the security measure costs a context switch on every login

*Nosu AI Hackathon $11,300+ in prizes* · problem: logging in requires leaving the browser to fetch a code from email
